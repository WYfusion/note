## 0. 定位

> **一句话**：SoVITS 解码器 = 「**语义 token → 波形**」的声学生成器。v1/v2/v2Pro 采用 VITS，v3/v4 采用 CFM + BigVGAN。

## 2. VITS 架构 (v1/v2/v2Pro)

```mermaid
flowchart LR
	SEM["semantic id"] --> SE["semantic embed"]
	SE --> POST["PosteriorEncoder"]
	MEL["mel-spec"] --> POST
	POST --> Z["z"]
	Z --> FLOW["Affine Coupling Flow"]
	FLOW --> ZP["z' (prior)"]
	Z --> GEN["HiFi-GAN Generator"]
	SPK["speaker emb"] --> GEN
	GEN --> WAV["wav 32k"]

	style GEN fill:\#1d2433,stroke:#f78c6c,color:\#f78c6c
```

### 高颒点

- v2Pro/v2ProPlus：加入 **ERes2NetV2** 说话人嵌入（192-d，预训 VoxCeleb1-O EER ~0.6%）。

- 重建损失：L1 (mel) + KL (z) + GAN (MPD+MSD)。

- 输出采样率：v1 24k / v2 32k / v2Pro 32k。

## 3. CFM + BigVGAN 架构 (v3/v4)

```mermaid
flowchart LR
	SEM["semantic id"] --> EMB["semantic embed"]
	EMB --> ENC["Conditioner (DiT-like)"]
	SPK["ref mel"] --> ENC
	BT["BERT hidden"] --> ENC
	ENC --> CFM["CFM (预测 velocity)"]
	CFM --> MEL["mel-spec (24/48 kHz)"]
	MEL --> BVG["BigVGAN-v2"]
	BVG --> WAV["wav 24k/48k"]

	style CFM fill:\#1d2433,stroke:#bae67e,color:\#bae67e
	style BVG fill:\#1d2433,stroke:#ef6b73,color:\#ef6b73
```

### 训练损失

$$\mathcal L_{\text{CFM}} = \mathbb E_{t, z_0, x_1} \| v_\theta(x_t, t, c) - (x_1 - z_0) \|^2$$

### 推理参数

- v3: NFE = 8, CFG w = 2.0, BigVGAN-v2 24khz-100band-256x。

- v4: NFE = 10, BigVGAN-v2 48khz-100band-512x 原生 48kHz，修复 v3 金属感。
