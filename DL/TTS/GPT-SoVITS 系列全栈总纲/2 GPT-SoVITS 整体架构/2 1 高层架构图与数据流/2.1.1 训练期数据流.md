## 0. 定位

> **一句话**：训练期是「**有 ground truth 的绿路」**、一次前向 + 损失反传，与推理期逐 token 生成被动当不同。

---

## 1. 训练双阶段

```mermaid
flowchart LR
	STAGE1["s1: AR T2S"] -->|"语义 token 学习"| AR_DONE["GPT 权重"]
	STAGE2["s2: SoVITS Decoder"] -->|"声学 学习"| S2_DONE["VITS/CFM 权重"]

	style STAGE1 fill:\#1d2433,stroke:#c792ea,color:\#c792ea
	style STAGE2 fill:\#1d2433,stroke:#f78c6c,color:\#f78c6c
```

- **stage 1**: `s1_train.py` 训练 AR；dataloader 提供（phoneme + BERT + prompt_semantic、target_semantic）。

- **stage 2**: `s2_train.py` 训练 SoVITS Decoder；dataloader 提供（semantic + mel + spk + wav）。

- 两阶段**独立训练、共享 VQ codebook**。

---

## 2. stage 1 详细流程

```mermaid
flowchart LR
	BATCH["batch"] --> PHO["phoneme ids"]
	BATCH --> BERT["BERT hidden"]
	BATCH --> PROMPT["prompt_semantic (句内裁段)"]
	BATCH --> TARGET["target_semantic"]
	PHO --> ENC["t2s_encoder"]
	BERT --> ENC
	PROMPT --> DEC["t2s_decoder"]
	ENC --> DEC
	TARGET --> CE["Cross Entropy (teacher forcing)"]
	DEC --> CE
	CE --> LOSS["NLL Loss"]

	style LOSS fill:\#1d2433,stroke:#bae67e,color:\#bae67e
```

- **teacher forcing**：decoder 看到 ground-truth semantic shift right 作为输入，预测下一个 token。

- **prompt 序列**：同句 wav 的某段手说句作为 in-context example（防信息泄露需化裁段）。

---

## 3. stage 2 详细流程

```mermaid
flowchart LR
	WAV["wav"] --> MEL["mel-spec"]
	WAV --> HUB["cnhubert"]
	HUB --> VQ["VQ Enc"]
	VQ --> SEM["semantic id"]
	WAV --> SPK["spk embed (Pro+ 如 ERes2NetV2)"]
	SEM --> POST["PosteriorEncoder"]
	MEL --> POST
	POST --> Z["latent z"]
	Z --> DEC["Generator (HiFi-GAN/CFM+BigVGAN)"]
	SPK --> DEC
	DEC --> RECONS["重建 wav"]
	RECONS --> DISC["Disc (MPD+MSD)"]
	WAV --> DISC

	style Z fill:\#1d2433,stroke:#bae67e,color:\#bae67e
```

### 损失

$$\mathcal L_{s2} = \mathcal L_{KL} + \lambda_1 \mathcal L_{mel} + \lambda_2 \mathcal L_{fm} + \lambda_3 \mathcal L_{adv} + \lambda_4 \mathcal L_{dur}$$

- v3/v4 额外加 **CFM 损失** 替换 Generator。

---

## 4. 参考裁段 与 推理裁段的不一致

> [!important]
> 
> **训练时 ref 是同一句裁段**（防泄露），推理时 ref 是**不同句的 reference audio**。这是 distribution shift 主要来源。 SoVITS 采用 augmentation（SpecAug + pitch shift） 缓解。
