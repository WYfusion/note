> [📎] 前置知识：PyTorch DDP、NCCL backend、gradient all_reduce、torchrun、 BucketSampler。

> **定位**：s2_[train.py](http://train.py) 使用 PyTorch 原生 DistributedDataParallel 多卡训练。本节拆 launch 方式、sampler 设计、G 与 D 同步、bf16 量化、 多机问题。

## 1. launch 方式

```bash
torchrun --nnodes 1 --nproc_per_node 4 s2_train.py \
    --config configs/s2.json --exp_dir logs/MyVoice
```

每卡 一个进程、NCCL backend、env_init。 `torch.distributed.init_process_group('nccl')` 被 WebUI 拼接。

## 2. 训练循环结构

```python
# s2_train.py 伪码
for epoch in range(start, max_epochs):
    sampler.set_epoch(epoch)
    for batch in dataloader:
        # G step
        y_hat = net_g(...)
        loss_g = mel + kl + gan + fm + dur
        loss_g.backward()
        clip_grad_norm_(net_g.parameters(), max_norm=1000)
        optim_g.step()

        # D step
        D_real = net_d(y, y_hat.detach())
        loss_d = adv_d
        loss_d.backward()
        clip_grad_norm_(net_d.parameters(), max_norm=1000)
        optim_d.step()
    scheduler_g.step()
    scheduler_d.step()
```

GAN 路线中 G 与 D 交替训。CFM 路线仅 G。

## 4. 梯度 all_reduce

DDP 自动在 backward 中 all_reduce。仅需「 wrap module」：

```python
net_g = DDP(net_g, device_ids=[local_rank], find_unused_parameters=True)
net_d = DDP(net_d, device_ids=[local_rank], find_unused_parameters=True)
```

> [⚠️] **find_unused_parameters=True 费性能**：但 SoVITS 中 Decoder 某些分支只在 v1 多说话人路线走，不加该参数 会报 unused parameter。 需与。

## 5. bf16 与 amp

```python
with autocast(dtype=torch.bfloat16):
    y_hat, ... = net_g(...)
    loss_g = ...
# bf16 backward 无需 GradScaler
loss_g.backward()
```

bf16 动态范围大，不需 GradScaler。仅原代 H100/A100 支持， 4090 也支持， V100 不支持。

## 6. 单卡越 8 卡加速比

|卡数|加速比|原因|
|---|---|---|
|1|1.0×|baseline|
|2|1.95×|NCCL 费|
|4|3.85×|同上|
|8|**6.5×**|NCCL all_reduce 使限|

> [🔧] **8 卡以上如果不跳 NVLink 会退化**：亲 PCIe 越 8 卡 加速比低于 6。 需 NVLink / SXM 才能保持线性。

## 7. 多机训练

```bash
# Master 节点
torchrun --nnodes 2 --node_rank 0 \
    --master_addr 10.0.0.1 --master_port 29500 \
    --nproc_per_node 8 s2_train.py ...

# Worker 节点
torchrun --nnodes 2 --node_rank 1 \
    --master_addr 10.0.0.1 --master_port 29500 \
    --nproc_per_node 8 s2_train.py ...
```

需 InfiniBand 或 100Gbps 以上交换机为 NCCL 越机使用。 家用社区场景少。

## 8. 常见报错

|错误|原因|修复|
|---|---|---|
|NCCL hang|port 冲突|master_port 换|
|OOM on rank 0|logging 占额额|关 tensorboard scalar 频率|
|unused parameter|net_g 多未走分支|find_unused_parameters=True|
|process not exit|dataloader worker|设 persistent_workers=False|

## 9. 工程判断

> [🔧] **云端推荐 4×A100 80GB**：batch=12×4=48、 足够训 5000h、7000h。 4090 训练 batch=4×4=16， 费时增加 2.5×。社区记录：4×A100 80GB 训 7000h v3 需 5–7 天走完一个 epoch。
