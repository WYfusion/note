## 0. 定义

> **k-means 伪标签与迭代训练** 是 HuBERT 的独特路径：先在 MFCC 上跑 k-means 生成**伪语音类别标签**，掩码训练 → 用中层表达重跑 k-means 生成更好的伪标签 → 再训。不同于 wav2vec 2.0 的「可微量化器」路线。

---

## 1. 三轮迭代流程

```mermaid
flowchart LR
	IT1["轮 1<br>MFCC → k-means (K=100)"] --> M1["训练 HuBERT-base"]
	M1 --> EXT2["取中层 (6层) 表达"]
	EXT2 --> IT2["轮 2<br>表达 → k-means (K=500)"]
	IT2 --> M2["重训 HuBERT-base"]
	M2 --> EXT3["取中层 (9层) 表达"]
	EXT3 --> IT3["轮 3<br>表达 → k-means (K=500)"]
	IT3 --> M3["重训 HuBERT-large"]

	style M3 fill:\#1d2433,stroke:#bae67e,color:\#bae67e
```

---

## 2. 为什么 MFCC 能启动

- MFCC 是「弱表达」但不是「零表达」。能提供原始音素类别的初步聚集。

- 后续开始“自举”：每轮伪标签质量上升、下轮训练质量也上升。

```mermaid
flowchart LR
	MFCC["MFCC 粗启动"] -->|"伪标签"| HUBERT1["HuBERT v1"]
	HUBERT1 -->|"中层表达"| KM2["重新 k-means"]
	KM2 -->|"更好伪标签"| HUBERT2["HuBERT v2"]
	HUBERT2 -->|"..."| HUBERT3["HuBERT v3 ..."]

	style HUBERT2 fill:\#1d2433,stroke:#ffcc66,color:\#ffcc66
```

---

## 3. 为什么表达转 重起 k-means 会变好

- 中层 (6层) 表达 与音素高度相关。

- 重跑 k-means 后类别与「真正音素」更贴近。

- HuBERT 论文 PER（音素错误率） 从 v1 的 25.9% 降到 v3 的 19.6%。

---

## 4. 与 cnhubert 的关系

cnhubert 使用中文数据在 wenetspeech 上 fine-tune，**不重新跑 k-means**，仅重用原 HuBERT 架构。进件例中 cnhubert 的 9 层被选为 TTS 特征（详见 [[1.3.3.1 第 9 层特征选取的经验依据]]）。
