> [📎] 前置知识：Softmax 函数、熟采样（玻尔兹曼分布）、熝采样分布锐化/钝化、Logit 量级。

> **定位**：拆解采样温度 $T$——公式、实现、与 top_k/top_p 的作用顺序、为什么 GPT-SoVITS 默认 0.7、调参经验。4维采样动作中「最不起眼但最影响听感」的那个。

## 1. 公式

给定 logits $z$，温度缩放：

$$p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

- $T to 0^+$：p_i 趋于 one-hot（贪心）；

- $T = 1$：原始 softmax；

- $T to infty$：p_i 趋于均匀。

## 2. 实现

```python
logits = logits / temperature
```

一行。但温度是「乘法隔离」于 top_k / top_p——需要明确的顺序。

## 3. 采样顺序中的位置

GPT-SoVITS：

```jsx
logits → rep_penalty → / T → top_k → top_p → softmax → sample
```

为什么 `/ T` 在 top_k 之前？**因为 top_k 的「前 k 大」取决于 logit 排序，除 T 是单调变换，排序不变。所以 / T 放哪里都可，但放在 rep_penalty 后面能让 penalty 在各种 T 下效果一致**。

> [💡] **rep_penalty + T 的顺序敏感性**：反过来「先 / T 再 rep_penalty」会让 T 越小、penalty 相对越强——两者变成耦合变量。GPT-SoVITS 选「先 penalty 再 / T」让两个参数在使用者调参时相互独立。

## 4. 为什么默认 0.7

|系统|T 默认|原因|
|---|---|---|
|GPT-2 文本|1.0|多样性优先|
|**GPT-SoVITS**|**0.7**|**锐化分布、提高音色一致性**|
|VALL-E|1.0|论文不锐化|
|CosyVoice 2|1.0|训练时已低随机化|

> [🤔] **T=0.7 意味着什么？** 原 softmax 下某 token p=0.7，$T=0.7$ 后会锐化到 p≈**0.83**，高估快一倍。这是让 GPT-SoVITS 那种「稳重、冷静」听感的根源。

## 5. 调参经验

|T|听感|场景|
|---|---|---|
|0.5|平平、机械|可复现试验|
|**0.7** (默认)|稳、自然|通用|
|0.85|软、多变化|情感表现|
|1.0+|随机、可能出错|不推荐|

## 6. T 与 top_k/top_p 的补偿关系

> [⚠️] **不要同时雪上加霜**：上调 top_k 且上调 T 且上调 top_p → 多样性爆炸→ 听感坏。「要多样性」只需动一个（快達推荐调 T）。

## 7. 工程判断

> [🔧] **调 T 的优先度最高**：问题 → 先调 T 再调 top_k 。`T=0.7±0.15` 覆盖 95% 场景。超出这个范围应检查参考音频质量 / 文本是否过长。
