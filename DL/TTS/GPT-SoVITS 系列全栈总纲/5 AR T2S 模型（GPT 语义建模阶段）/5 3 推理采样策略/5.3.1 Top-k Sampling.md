> [📎] 前置知识：Softmax 分布、Multinomial Sampling、Greedy Decoding、采样多样性 vs 准确性权衡。

> **定位**：拆解 GPT-SoVITS AR 推理采样的「第一道闸门」Top-k——公式、实现、与 Top-p 联动、为什么默认是 15、与文本生成默认 40 的区别。

## 1. 公式

设原始 logits $z in mathbb R^V$，选 top-k 后：

$$\tilde z_i = \begin{cases} z_i, & i \in \text{TopK}(z, k) \\ -\infty, & \text{otherwise} \end{cases}$$

随后 softmax 采样：

$$p_i = \frac{e^{\tilde z_i}}{\sum_{j \in \text{TopK}(z,k)} e^{\tilde z_j}}$$

## 2. PyTorch 实现

```python
def top_k_logits(logits, k):
    if k == 0: return logits
    v, _ = torch.topk(logits, k)
    min_v = v[..., -1, None]                       # 第 k 大的 logit
    logits = torch.where(logits < min_v,
                          torch.full_like(logits, float('-inf')),
                          logits)
    return logits
```

## 3. GPT-SoVITS 默认 `top_k=15` 的优化依据

|场景|常用 top_k|根据|
|---|---|---|
|GPT-2 文本|40|词表太大，默认多样性优先|
|VALL-E TTS|50（论文默认）|语义 codebook 丰富|
|**GPT-SoVITS**|**15**|**语义 codebook 1024、说话人控励需要低随机**|
|CosyVoice 2|25|中途|

> [💡] **TTS 要 “低随机”** 是因为：①同一句话重复生成需保持音色一致；②高 top_k 会让采样中「鬼画符」semantic id 被选中 → 出怎音；③ SoVITS 解码器对 OOD semantic id 鲁棒性差，一个坏 token 就听到哎哦。

## 4. Top-k = 1 的退化

$k=1$ 等价于 **贪心解码**（argmax）：

- 优：重复生成完全一致（适合 deterministic 场景、使用竟体评估）；

- 劣：一旦初始一点偏差会一本道走到黑，复读 / 吞字频发。

> [⚠️] **不要随便 top_k=1**：除非做「可复现试验」，greedy 在 GPT-SoVITS 上听感**明显变差**。

## 5. Top-k 与位子关系的采样顺序

GPT-SoVITS 采样顺序：

```jsx
logits → rep_penalty → / T → top_k → top_p → softmax → sample
```

> [🤔] **为什么 top_k 在 top_p 之前？** Top-k 是「定额净机」（保证准留 k=15个），top-p 是「动态累计净机」。先 top_k 能保证最差情况下仍有 15 个选项。反着来 top_p 可能只留 2-3 个让低多样性场景里其中一个独占。

## 6. 调参影响

|top_k|听感|场景|
|---|---|---|
|**5–10**|最稳、可能重复|有声书 / 配音|
|**15** (默认)|稳与多样性平衡|通用|
|**25–40**|更多变化|情感表现 / 幽默|
|**>50**|可能出错|不推荐|

## 7. 工程判断

> [🔧] **带 BERT 与否会影响选型么？** GPT-SoVITS 有 BERT 特征辅助，logits 分布上「正确 token 的置信度」较高——top_k=15 已能覆盖 95%+ 概率。若是不带 BERT 的 VALL-E，分布更平，k=50 是必要的。
