> [📎] 前置知识：Softmax、Categorical 分布、贪心 vs 采样、Top-k、Top-p（Nucleus）、Temperature、Repetition Penalty。

> **定位**：AR 模型的 logits 出来后，**怎么挑下一个 token** 直接决定了音色稳定性、自然度、和「复读 / 漏字」的概率。本节系统梳理 GPT-SoVITS 默认采样组合及其各自作用。

## 1. 默认超参（`inference_webui.py`）

|超参|默认值|作用|
|---|---|---|
|`top_k`|15|保留 logits 最大的 15 个|
|`top_p`|0.8|累积概率截断到 0.8|
|`temperature`|0.7|logits / T 后再 softmax|
|`repetition_penalty`|1.35|已生成 token 概率乘 1/penalty|
|`early_stop_num`|1600|最大生成长度（25Hz ≈ 64s）|

## 2. 公式一览

记原始 logits $z in mathbb R^V$，温度后 $tilde z = z / T$，softmax 后 $p_i = e^{tilde z_i} / sum_j e^{tilde z_j}$。

**Temperature**：$T < 1$ 锐化分布（更确定），$T > 1$ 钝化（更随机）。

**Top-k**：仅保留 $\tilde z$ 最大的 $k$ 个，其余置 $-infty$。

**Top-p**：按 $p_i$ 降序累加，截到累积 $\sum p \ge p_{\text{thr}}$ 处。

**Repetition Penalty**（Keskar et al., 2019）：

$$\tilde z_i \leftarrow \begin{cases} \tilde z_i / \rho, & \text{if } \tilde z_i > 0 \text{ and } i \in S_{\text{prev}} \\ \tilde z_i \cdot \rho, & \text{if } \tilde z_i \le 0 \text{ and } i \in S_{\text{prev}} \\ \tilde z_i, & \text{otherwise} \end{cases}$$

其中 $S_{\text{prev}}$ 是已生成 token 集合，$rho = 1.35$。

> [⚠️] **正负不同向**：很多人误把 repetition penalty 写成「统一除以 ρ」。**正确做法** 是正 logit 除以 ρ（降低）、负 logit 乘 ρ（更负），保证惩罚方向一致。

## 3. 组合顺序（重要！）

GPT-SoVITS 的实际执行顺序：

```jsx
logits
  → repetition_penalty (针对已生成 token)
  → / temperature
  → top_k (截 k=15)
  → top_p (在 top_k 内再截 p=0.8)
  → softmax → categorical.sample
```

> [💡] **为什么 top_k 在 top_p 前？** Top-k 是硬截断（确定保留几个），top_p 是软截断（按累积概率）；先 top_k 限定候选池，再 top_p 在池内做细筛——既防止低概率长尾，又允许在前 15 个内动态收缩。等价于「两层 safety net」。

## 4. 各超参对生成的影响

|现象|建议调整|
|---|---|
|复读「啊啊啊」|repetition_penalty 1.35 → 1.5|
|漏字 / 吞字|top_k ↑（15 → 25），temperature ↑（0.7 → 0.85）|
|音色飘|temperature ↓（0.7 → 0.5），top_p ↓|
|卡死生成不停|检查参考音频是否有结束气声；调 early_stop_num|
|尾部噪声|强化 EOS 训练，或降低 temperature|

## 5. 与同类系统对比

|系统|默认采样|备注|
|---|---|---|
|GPT-SoVITS v1+|top_k=15, top_p=0.8, T=0.7, rep=1.35|偏保守，音色稳|
|VALL-E|top_p=1.0, T=1.0（论文）|多样性优先|
|CosyVoice|top_k=25, top_p=0.8, T=1.0|中庸|
|GPT-2 文本|top_k=40 / top_p=0.95|文本更激进|

> [🔧] **工程建议**：90% 场景保持默认；做 dataset 标注配音（要稳）→ T=0.6, top_k=10；做有声书 / 旁白（要多样）→ T=0.85, top_k=25。
