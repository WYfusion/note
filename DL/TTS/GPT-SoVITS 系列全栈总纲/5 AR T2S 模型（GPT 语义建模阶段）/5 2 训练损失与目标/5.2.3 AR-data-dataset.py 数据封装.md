## 1. 三元组样本

```python
class Text2SemanticDataset(Dataset):
    def __init__(self, semantic_path, phoneme_path, bert_dir, ...):
        self.semantic_data = pd.read_csv(semantic_path, sep='\t')
        self.phoneme_dict  = read_cleaned_phoneme(phoneme_path)
        self.bert_dir      = bert_dir

    def __getitem__(self, idx):
        item_name = self.semantic_data.iloc[idx]['item_name']
        # 1) phoneme ids
        ph_text = self.phoneme_dict[item_name]
        ph_ids  = phoneme_to_ids(ph_text)
        # 2) BERT feature
        bert    = torch.load(f'{self.bert_dir}/{item_name}.pt')   # [T_p, 1024]
        # 3) semantic
        all_sem = list(map(int, self.semantic_data.iloc[idx]['semantic_audio'].split()))
        # 随机切：ref 与 tgt 不重叠
        ref_sem, tgt_sem = self._random_split(all_sem)
        return ph_ids, bert, ref_sem, tgt_sem
```

## 2. “ref / tgt 不重叠”随机切片

```python
def _random_split(self, sem):
    n = len(sem)
    ref_len = random.randint(50, 250)               # 2–10s
    if n - ref_len < 50: ref_len = max(1, n // 4)
    ref_start = random.randint(0, n - ref_len - 1)
    ref = sem[ref_start: ref_start + ref_len]
    # tgt 取另一段不重叠区间
    candidates = list(range(0, ref_start - 50)) + list(range(ref_start + ref_len + 50, n - 50))
    tgt_start = random.choice(candidates)
    tgt_len = random.randint(50, min(1600, n - tgt_start))
    tgt = sem[tgt_start: tgt_start + tgt_len]
    return ref, tgt
```

> [💡] **为何「同一语句抽两段 ref+tgt」而不是另抽一句？** 这样 ref 与 tgt **同说话人同录音**，背景噪声 / 麦元响应一致——模型会学会「严格复制参考的音色与底噪」。这是 zero-shot 克隆的关键训练策略。

## 3. `collate_fn` 打 batch

```python
def collate_fn(batch):
    ph_ids   = [torch.LongTensor(b[0]) for b in batch]
    bert     = [b[1] for b in batch]
    ref_sem  = [torch.LongTensor(b[2]) for b in batch]
    tgt_sem  = [torch.LongTensor(b[3] + [EOS_TOKEN]) for b in batch]

    # 拼接 ph + ref + tgt
    full_seqs = [torch.cat([p, r, t]) for p, r, t in zip(ph_ids, ref_sem, tgt_sem)]
    full_pad  = pad_sequence(full_seqs, batch_first=True, padding_value=0)
    bert_pad  = pad_2d(bert, max_len=max(p.size(0) for p in ph_ids))

    # target = input shift left
    target = full_pad.clone()
    target[:, :-1] = full_pad[:, 1:]
    target[:, -1]  = -100

    # 屏蔽 phoneme + ref 段
    for i, (p, r, t) in enumerate(zip(ph_ids, ref_sem, tgt_sem)):
        target[i, :p.size(0) + r.size(0)] = -100
        # pad 位也置 -100
        valid_len = p.size(0) + r.size(0) + t.size(0)
        target[i, valid_len - 1:] = -100
    return full_pad, bert_pad, target, attn_mask
```

## 4. 动态 batching（可选）

```python
class BucketSampler(BatchSampler):
    def __init__(self, lengths, max_tokens=20000):
        ...
    def __iter__(self):
        idx_by_len = sorted(range(len(self.lengths)), key=lambda i: self.lengths[i])
        batch, sz = [], 0
        for i in idx_by_len:
            if sz + self.lengths[i] > self.max_tokens:
                yield batch; batch, sz = [], 0
            batch.append(i); sz += self.lengths[i]
```

> [⚠️] **不用 bucket 的后果**：允许 batch 内序列长短混合 → 短序列 padding 占 70%+显存都是 0，开了 bucket 后同显存可上更大 effective batch。GPT-SoVITS 默认不开（实现简单优先），大规模复训推荐开。

## 5. 并发 IO 考量

|类型|文件|平均大小|优化|
|---|---|---|---|
|phoneme|文本|1KB|读入内存|
|BERT|`.pt`|200KB|**主要 IO**|
|semantic|tsv 一列|0.5KB|[pd.read](http://pd.read)_csv|

> [🔧] **BERT IO 优化**：① `num_workers=4\~8` 充分释放 CPU 并发；② 将 BERT 预合成单个 `.npz`（全部样本），mmap 读取；③ 在 SSD 上跑，HDD 会是主瓶颈。

## 6. 与 SoVITS 训练 dataset 的差异

|维度|AR (s1) dataset|SoVITS (s2) dataset|
|---|---|---|
|输入|phoneme + BERT + semantic|spec / wav + semantic|
|target|semantic ids (CE)|wav (L1+adv) / mel (CFM)|
|切片|随机 ref / tgt|全句|
|主 IO|BERT .pt|**wav 1.4MB/s**|
