> [📎] 前置：AR 推理 · prompt 机制 · 音素/BERT/semantic 三路拼接。

> **定义**：位于 AR (T2S) 推理输入的 6 段拼接顺序·决定 zero-shot 能否生成与 ref 同音色的 semantic token。

## 1. 拼接顺序

```jsx
[phone_ref] [phone_target] [bert_ref] [bert_target] [BOS] [semantic_ref]
                                                            ↑
                                                  AR 从此续派 semantic_target
```

## 2. 各段含义

|段|含义|来源|
|---|---|---|
|**phone_ref**|ref 文本音素|g2pW(ref_text)|
|**phone_target**|目标文本音素|g2pW(target_text)|
|**bert_ref**|ref BERT hidden|chinese-roberta(ref_text)[-3]|
|**bert_target**|目标 BERT hidden|chinese-roberta(target_text)[-3]|
|**BOS**|begin-of-semantic|vocab[0]|
|**semantic_ref**|ref 语义 token|VQ.encode(cnhubert(ref_wav))|

## 3. 拼接实现

```python
# AR/models/t2s_model.py 伪代码
phone_concat = torch.cat([phone_ref, phone_target], dim=-1)
bert_concat  = torch.cat([bert_ref, bert_target], dim=-2)
prompt = torch.cat([bos_token, semantic_ref], dim=-1)
gen = ar.generate(
    phone=phone_concat,
    bert=bert_concat,
    prompt=prompt,
    top_k=15, top_p=0.8, temperature=0.7,
)
semantic_target = gen[len(prompt):]  # 去除 prompt 前缀
```

## 4. 顺序不能错

> [⚠️] **ref 在前 · target 在后 · 不可反**：AR 是 单 向 自 回 归 · 仅 看 到 左 侧 · ref 在 左 才 能 充 当 音 色 prompt。 target 在 左 会 令 ref 不 传 音 色 · 输 出 为 默 认 音 色。

## 5. 与 CosyVoice 2 对比

|项|GPT-SoVITS|CosyVoice 2|
|---|---|---|
|phone|路 1 + 路 2|仅路 2|
|BERT|依|不依|
|semantic prompt|依 ref_wav|依 ref_text + ref_wav|
