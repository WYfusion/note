> [📎] 前置知识：Sinusoidal Positional Embedding（Vaswani 2017）、相对/绝对位置编码、外推性（length extrapolation）、RoPE / ALiBi。

> **定位**：拆解 GPT-SoVITS AR 侧使用的 `SinePositionalEmbedding`——公式、实现、`scale` 可学习参数、与 RoPE 的取舍。

## 1. 公式

经典 Transformer 正弦位置编码：

$$\text{PE}(pos, 2i) = \sin\!\left(\frac{pos}{10000^{2i/d}}\right), \quad \text{PE}(pos, 2i+1) = \cos\!\left(\frac{pos}{10000^{2i/d}}\right)$$

维度 $d$ 等于 `d_model`（v1/v2=512，v3/v4=768）。pos ∈ [0, max_len)，max_len=4096（实际 ≤ 2048）。

## 2. GPT-SoVITS 的可学习缩放

源码 `AR/modules/embedding.py`：

```python
class SinePositionalEmbedding(nn.Module):
    def __init__(self, embedding_dim, dropout=0.0,
                 scale=False, alpha=False):
        super().__init__()
        self.embedding_dim = embedding_dim
        self.x_scale = math.sqrt(embedding_dim) if scale else 1.0
        self.alpha = nn.Parameter(torch.ones(1), requires_grad=alpha)
        self.dropout = nn.Dropout(dropout)
        self.reverse = False
        self.pe = None
        self.extend_pe(torch.tensor(0.0).expand(1, 4096))

    def extend_pe(self, x):
        pe = torch.zeros(x.size(1), self.embedding_dim)
        position = torch.arange(0, x.size(1)).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, self.embedding_dim, 2)
                             * -(math.log(10000.0) / self.embedding_dim))
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        self.pe = pe.to(device=x.device, dtype=x.dtype).unsqueeze(0)

    def forward(self, x):
        if self.pe.size(1) < x.size(1):
            self.extend_pe(x)
        output = x.unsqueeze(-1) if x.ndim == 2 else x
        output = output * self.x_scale + self.alpha * self.pe[:, :x.size(1)]
        return self.dropout(output)
```

**关键设计**：

1. **PE 与 token embedding 是 add（同位）** —— 与原 Transformer 一致；

1. `**x_scale = sqrt(d)**`（若 scale=True）—— 让 token embedding 量级匹配 PE，避免 PE 被淹没；

1. `**alpha**` **可学习** —— 给 PE 一个标量门控，允许网络在训练中自适应调整 PE 强度；

1. `**extend_pe**` **懒扩展** —— 序列变长时再重算 PE，省内存。

## 3. 长度外推性

Sine PE 理论上可以「外推到任意长度」——只要 pos 没溢出 float 范围。但实际上：

|现象|解释|
|---|---|
|训练长度 ≤ 1024，推理 2048|PE 数值连续可解，但**模型权重没见过这种相对位置**，注意力质量下滑|
|推理超过 4096|`extend_pe` 兜底，但 v3 上下文设计上限 2048，超出无意义|

> [⚠️] **alpha 训完后通常 < 1**：经验上 alpha 收敛到 0.3–0.6，说明模型偏好「弱位置 + 强内容」。把 alpha 强制设为 1 反而掉点。

## 4. Sine PE vs RoPE vs ALiBi

|方案|注入位置|外推|计算成本|GPT-SoVITS 选用|
|---|---|---|---|---|
|Sine PE|embedding add|中|0（缓存）|✅|
|Learned PE|embedding add|差|0|❌|
|RoPE|Q/K 旋转|好|每 step 算 sin/cos|❌|
|ALiBi|attention bias|优|0|❌|

> [🤔] **为何不上 RoPE？** ①AR 序列 ≤ 2048，外推压力小；②已有 KV Cache，attention 不重算；③社区分支验证 RoPE 仅提升 0.1–0.2 CER，引入兼容性破坏不值得；④Sine PE 实现简单、所有 ckpt 兼容。

## 5. 与同期方案的实测对比

|系统|PE 方案|训练长度|推理外推|
|---|---|---|---|
|GPT-SoVITS|Sine + α|1024|至 1600（25Hz 64s）OK|
|VALL-E|Sine|2048|OK 至 3000|
|CosyVoice 2|RoPE|4096|至 8192 OK|
|LLaMA|RoPE|2048|RoPE scaling → 32k|

## 6. 工程判断

> [🔧] **何时考虑改 RoPE？** ①目标支持长 podcast（>2 min）连续生成；②上下文要 > 4096；③愿意接受 ckpt 不兼容、重训。对当前 GPT-SoVITS 用户而言，Sine PE 已是 sweet spot。
