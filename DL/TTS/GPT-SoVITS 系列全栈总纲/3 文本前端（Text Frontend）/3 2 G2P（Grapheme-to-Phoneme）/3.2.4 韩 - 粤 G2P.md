## 0. 定位

> **一句话**：韩 / 粤 G2P = 「**少资源语种的 G2P**」。两者都复用现有库、不额外训练。

---

## 1. 韩文 G2P

```mermaid
flowchart LR
	KO["안녕하세요"] --> G2PK["g2pk"]
	G2PK --> JAMO["・ 안녕・ · (Jamo)·"]
	JAMO --> ROM["罗马化 (Revised)"]
	ROM --> PH["音素: a n nj n h a s e jo"]

	style G2PK fill:\#1d2433,stroke:#bae67e,color:\#bae67e
```

- **g2pk** 是 Python G2P 库、包含韩文变音规则、准确率 >95%。

- 音素表以 IPA 为基、总计 总计 ~ 40 个。

### 韩文特有变音

|现象|例|变音|
|---|---|---|
|连音化|`쉯이`|`시시`|
|同化|`국민`|`궁민`|
|激音化|`좋고`|`조코`|

---

## 2. 粤语 G2P

```mermaid
flowchart LR
	YUE["你好嗎"] --> PYCAN["pycantonese.characters_to_jyutping"]
	PYCAN --> JYT["nei5 hou2 maa1"]
	JYT --> PH["声部 + 韵部 + 声调 (1-6)"]

	style PYCAN fill:\#1d2433,stroke:#bae67e,color:\#bae67e
```

- **Jyutping (粤拼)**：类似拼音、但声调 1-6 六个 (不包含「转调」 7-9)。

- **特有韵部**：`oe / yu / eo / aa` 与普通话不同。

- **多音字**：粤语同样存在、需依赖 pycantonese 的词典 + 上下文启发 (较中文 g2pW 弱)。

## 3. 资源估算

## 4. GPT-SoVITS 集成

```python
# text/korean.py
from g2pk import G2p
ko_g2p = G2p()
phones = ko_g2p("안녕하세요")

# text/cantonese.py
import pycantonese as pc
jyt = pc.characters_to_jyutping("你好嗎")
phones = jyutping_to_phoneme(jyt)
```

- **两个语种都不默认启用 BERT** 、 依赖 phoneme 与 cnhubert SSL。

---

## 5. 常见问题

> [!important]
> 
> - **韩 变音错误**：g2pk 依赖上下文、在口语场景误率升。
> 
> - **粤 上调 下调**：调值 1-6 不是普通话 1-5、AR vocab 需独立映射。
> 
> - **资源不足**：训练集中韩/粤 << 7000h 中文、十记公里「众子」定位。
