> [📎] 前置：G2P、多音字 (polyphone)、g2pW、BERT contextual embedding。

> **定义**：同一汉字在不同语境读不同音·需从上下文判断的现象。GPT-SoVITS V2+ 用 **g2pW** (BERT-based) 代 替 V1 的 pypinyin 规则表。

## 1. 三类高频多音字

|字|音 A / 例|音 B / 例|
|---|---|---|
|乐|lè / 快乐|yuè / 音乐|
|重|zhòng / 体重|chóng / 重复|
|行|xíng / 行走|háng / 银行|
|长|cháng / 长短|zhǎ ng / 长大|
|为|wéi / 成为|wèi / 因为|

## 2. 两代对比

|项|V1 pypinyin|V2+ g2pW|
|---|---|---|
|算法|词典 + 规则|**BERT contextual**|
|多音字准确率|≈85%|**≈97%**|
|依赖|无|chinese-roberta-wwm-ext-large|

## 3. g2pW 推理

```python
# 伪代码
from g2pw import G2PWConverter
conv = G2PWConverter(model_source='bert-base-chinese')
pinyin = conv('银行门口行人多')
# → ['yín', 'háng', 'mén', 'kǒu', 'xíng', 'rén', 'duō']
```
