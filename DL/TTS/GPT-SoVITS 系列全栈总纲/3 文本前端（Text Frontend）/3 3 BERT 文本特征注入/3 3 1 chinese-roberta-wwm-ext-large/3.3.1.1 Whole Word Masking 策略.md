> [📎] 前置：BERT MLM、子词 masking、中文分词。

> **定义**：**Whole Word Masking (WWM)** = 原 BERT 按 token mask·中文会拆字 (「香港」→「香」+「港」)·WWM 修为整词同时 mask·提高语义一致性。

## 1. 对比

```jsx
原句：今天 香港 天气 不错

BERT 原始 mask:
    今[MASK]香[MASK]天气不错        ← 随机 token · 拆词
BERT-wwm mask:
    今天 [MASK][MASK] 天气不错       ← 整词 · 语义一致
```

## 2. ckpt 选型

|模型|作者|参数|使用|
|---|---|---|---|
|chinese-roberta-wwm-ext|HFL|110 M|中型|
|**chinese-roberta-wwm-ext-large**|HFL|**325 M / 1.3 GB**|**GPT-SoVITS V2+ 默认**|

## 3. 仓库接口

```python
from transformers import AutoModel, AutoTokenizer
model = AutoModel.from_pretrained('hfl/chinese-roberta-wwm-ext-large')
tokenizer = AutoTokenizer.from_pretrained('hfl/chinese-roberta-wwm-ext-large')
out = model(**tokenizer(text, return_tensors='pt'), output_hidden_states=True)
feat = out.hidden_states[-3]  # 倍数第 3 层
```

## 4. 为何选 hidden_states[-3]

> [💡] **高层对 NLP 任务偏 · 中层对韵律偏**：最 后 层 偏 向 词 语 预 测。倍 数 第 3 层 保 存 语 义 + 韵 律 · 适 TTS。
