## 2. 为何需 s2G ckpt

```python
# 3-get-semantic.py 伪代码
sovits_model = torch.load('s2G488k.pth')
vq_model = sovits_model.quantizer    # 仅 VQ 部分
hubert_feat = torch.load(f'4-cnhubert/{wavname}.pt')    # 50Hz
hubert_25hz = F.avg_pool1d(hubert_feat.transpose(1,2), 2).transpose(1,2)
quantized, codes = vq_model(hubert_25hz)
# codes shape: [1, T_25hz], values in [0, 1024)
```

> [⚠️] **不能跳 s2G ckpt**：VQ codebook 是需 随 s2G 预训 一起训的 · 不能 随机初。 说明 1c 需 1ba s2 预训 ckpt 存在。社区 预训 ckpt s2G488k.pth 是仅为了这个目的发布。

## 3. 产物格式

```jsx
6-name2semantic.tsv:
wavname    \t    'codes string'
seg_001    \t    '123 456 78 90 ...'
```

社区 这个 tsv 会被 s1_[train.py](http://train.py) 读入 AR 训练。

## 4. 25 Hz 与 50 Hz 对齐

```mermaid
flowchart LR
    A[50 Hz hubert] --> B[avg_pool1d kernel=2]
    B --> C[25 Hz hubert]
    C --> D[VQ · 必 与 s2G ckpt 一致]
    style B fill:\#1d2433,stroke:#FFD580,color:\#FFD580
```

帧率重要性：AR 训练 需 25 Hz semantic、 SoVITS 训练 需 50 Hz hubert。

## 7. 常见错误

|现象|原因|修复|
|---|---|---|
|s2G 未找到|预训 ckpt 未下|下载|
|codes 越范围|vocab 错|检查 vocab=1024|
|长度不匹配|50Hz 不 下 采|检查 avg_pool|
