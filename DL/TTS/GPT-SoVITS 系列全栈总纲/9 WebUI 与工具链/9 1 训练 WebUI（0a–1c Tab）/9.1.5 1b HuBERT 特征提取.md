## 2. 为何取 Layer 9

|Layer|信息偏|作用|
|---|---|---|
|1–3|语音面 · 声学|低级|
|4–7|音素 · 过渡|中|
|**8–10**|**语义 · 词**|**佳**|
|11–12|过拟合任务|偏任务|

> [💡] **Layer 9 是社区幽限点**：中层表示能保留 语 义 · 去除音色 是「语义 token」的甜蜜点。VALL-E、SoundStream 都选中层。

## 3. 代码

```python
from feature_extractor.cnhubert import get_model
cnhubert = get_model().cuda().eval()
# 加载
wav, _ = librosa.load(path, sr=16000)
wav = torch.from_numpy(wav).float().cuda().unsqueeze(0)
with torch.no_grad():
    feat = cnhubert.model(wav)['last_hidden_state']    # 默认 layer 9
# feat shape: [1, T_frames, 768], T_frames @ 50 Hz
torch.save(feat.cpu(), f'4-cnhubert/{wavname}.pt')
```

```bash
# 4 卡并行
for i in 0 1 2 3; do
  CUDA_VISIBLE_DEVICES=$i python 2-get-hubert-wav32k.py --i_part $i --all_parts 4 &

wait
```

## 7. 常见错误

|现象|原因|修复|
|---|---|---|
|OOM|batch 太大 · 长句|batch=1|
|feat 为 NaN|16k resample 错|检查 sample rate|
|50 Hz 不不贴 25 Hz|cnhubert 本身 50Hz|3-get-semantic 会下采样|
