> [📎] 前置知识：Flask、FastAPI、REST · SSE · WebSocket、 `api.py` v1 与 `api_v2.py`。

> **定位**：API 是部署门面。本节拆 两代 API · 端点表 · 请求/返回 · 部署考虑。

## 1. 两代 API

|项|[api.py](http://api.py) v1|**api_[v2.py](http://v2.py) v2**|
|---|---|---|
|框架|Flask|**FastAPI + uvicorn**|
|同步|同步|**异步**|
|流式|不支持|**支持 SSE**|
|OpenAPI|无|**/docs 自动**|
|推荐|老 · 兼容|**生产首选**|

## 2. 端点表 (api_v2)

|路径|方法|作用|
|---|---|---|
|**/tts**|POST/GET|主端 · 生成音频|
|/control|POST|启动/重动/退出|
|/set_refer_audio|POST|设默认 ref|
|/set_gpt_weights|POST|热换 s1 ckpt|
|/set_sovits_weights|POST|热换 s2 ckpt|

## 3. /tts 请求 schema

```json
{
  "text":              "要合成的文本",
  "text_lang":         "zh",
  "ref_audio_path":    "/path/to/ref.wav",
  "prompt_text":       "ref 转录文本",
  "prompt_lang":       "zh",
  "top_k":             15,
  "top_p":             0.8,
  "temperature":       0.7,
  "text_split_method": "cut3",
  "batch_size":        1,
  "media_type":        "wav",
  "streaming_mode":    true
}
```

## 4. 返回

|media_type|响应体|Content-Type|
|---|---|---|
|wav|二进制 wav|audio/wav|
|ogg|OggOpus · 画质高压缩高|audio/ogg|
|aac|AAC|audio/aac|
|raw|PCM 32k|audio/raw|

## 5. 调用例

```python
import requests
r = requests.post('http://127.0.0.1:9880/tts', json={
    'text': '你好，今天天气不错。',
    'text_lang': 'zh',
    'ref_audio_path': '/ref/cute.wav',
    'prompt_text': '你好啊。',
    'prompt_lang': 'zh',
})
with open('out.wav', 'wb') as f:
    f.write(r.content)
```

## 6. 启动

```bash
# v1 (Flask)
python api.py --port 9880 --device cuda

# v2 (FastAPI)
python api_v2.py --port 9880 --bind 0.0.0.0
# · OpenAPI: http://127.0.0.1:9880/docs
```

## 7. 部署考虑

|场景|推荐|
|---|---|
|本地开发|api_v2 · SSE 流式|
|生产|**api_v2 + Nginx + GPU 负载平衡**|
|安全|加鉴权 (需手改 api_v2)|
|多路|多进程 + GPU sharding|

## 8. 常见错误

|现象|原因|修复|
|---|---|---|
|404|v1 不支持 v2 端点|换 api_[v2.py](http://v2.py)|
|500|ref/ckpt 不在|set_refer + set_gpt|
|响应慢|同步 + 长文|开 streaming_mode|
|多用户冲突|单进程|多进程 + LB|

## 9. 工程判断

> [🔧] **v2 是唯一选择**：FastAPI + 异步 + SSE + OpenAPI 是现代 API 标准。 v1 已 过 时 · 仅 保 留 为 兼 容 。 生产 需 补 鉴 权 + 多 GPU + 负 载 平 衡。
