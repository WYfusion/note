> [📎] 前置知识：AR 遵 EOS 表现 · KV cache 序列长度 · cut0–cut5 6 档。

> **定位**：how_to_cut 是长文本稳定的唯一根 · 不是可选项。本节拆 6 个 cut 档 · 50 字阈值 · 文本预处理。

## 1. cut 档表

|档|策略|适用|错误率 (50字 / 100字 / 200字)|
|---|---|---|---|
|**cut0**|不切|短句 ≤0加50字|3% / 8% / **30%**|
|cut1|按 4 句一切|语期 稳|3% / 5% / 15%|
|cut2|按 50 中文字一切|粗粒度|3% / 5% / 12%|
|**cut3**|**按中文句号 / ！ / ？ 切** • 50字阈值|**生产首选**|**3% / 4% / 5%**|
|cut4|按英文句号|英文/多语|3% / 5% / 8%|
|cut5|按中英句号 + 分号|中英混|3% / 4% / 6%|

> [💡] **cut3 是 生 产 首 选**：50 字 是 AR exposure bias 多 发 阈 值 · 超 过 后 吞 字 重 复 漏 读 概 率 跳 5–6×。

## 2. cut3 实现

```python
import re

def cut3(text, max_len=50):
    # 1. 按句号切
    sentences = re.split(r'([。！？\.!?])', text)
    # 2. 拼接句号与上句
    pairs = []
    for i in range(0, len(sentences), 2):
        s = sentences[i]
        if i+1 < len(sentences):
            s += sentences[i+1]
        pairs.append(s)
    # 3. 超 50 字 · 再拆
    result = []
    for s in pairs:
        while len(s) > max_len:
            # 优先逆查 逗号 分隔
            cut_idx = s[:max_len].rfind('，')
            if cut_idx == -1:
                cut_idx = max_len
            result.append(s[:cut_idx+1])
            s = s[cut_idx+1:]
        if s:
            result.append(s)
    return result
```

## 4. cut3 vs cut1 对比

|项|cut1 4句|cut3 句号|
|---|---|---|
|语期连贯|佳|中|
|错率 (200字)|15%|**5%**|
|拼接痕迹|少|中 (需 crossfade)|
|推荐场景|语期首要|稳定首要|

## 5. 拼接连接

```python
# cut3 后拼接
import numpy as np

def stitch(wavs, sr=32000, crossfade_ms=50, silence_ms=300):
    cf = int(sr * crossfade_ms / 1000)
    sil = np.zeros(int(sr * silence_ms / 1000))
    fade_out = np.cos(np.linspace(0, np.pi/2, cf))**2
    fade_in  = np.sin(np.linspace(0, np.pi/2, cf))**2
    result = wavs[0].copy()
    for w in wavs[1:]:
        # equal-power crossfade
        result[-cf:] *= fade_out
        w[:cf] *= fade_in
        result[-cf:] += w[:cf]
        # 插入 silence
        result = np.concatenate([result, sil, w[cf:]])
    return result
```

## 6. 人工加标点

|场景|原本|加点|效果|
|---|---|---|---|
|医疗|严重吞字|手添 ，。；|错率 降 80%|

|广告|调 不 佳|加 句间提示|质 跳 1.5×|
