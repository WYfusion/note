## 0. 定位

> 「长文本不稳是第一大痛点。」吞字 / 重复 / 漏读 / 金属音尾巴 四大现象的根因与缓解。本质是 exposure bias 与 ctx 限制的携手问题，不能只靠采样调参根治。

## 1. 四种崩坏模式

```mermaid

  Q -->|采样陷入循环| F2[**重复**<br/>「啊啊啊」]
  Q -->|early_stop 扄断| F3[**漏读**<br/>中间某段没读]
  Q -->|EOS 未动| F4[**金属音尾巴**<br/>超 1600 后噪声]

  style F1 fill:\#1d2433,stroke:\#FFA3A3,color:#FFA3A3
  style F2 fill:\#1d2433,stroke:\#FFA3A3,color:#FFA3A3
  style F3 fill:\#1d2433,stroke:\#FFA3A3,color:#FFA3A3
  style F4 fill:\#1d2433,stroke:\#FFA3A3,color:#FFA3A3
```

|现象|根本原因|听感表现|领发场景|
|---|---|---|---|
|**吞字**|AR 预测 EOS 过早 / 采样偊跑|后半句丢失|长句·复杂结构|
|**重复**|rep_penalty 不够 / 采样陷循环|「啊啊啊」「合作合作合作」|句尾多发|
|**漏读**|early_stop 提前截断 / cut 错|中间丢字|长句中间|
|**金属尾巴**|EOS 未动·超上限后乱出|句后噪声·机械响|EOS 训不够|

## 2. exposure bias 是根本原因

```mermaid
flowchart LR
  TRAIN[训练·teacher forcing] --> SAFE[只看真实历史]
  SAFE --> DIST[**学到「干净分布」**]
  INFER[推理·逐 token] --> RISK[靠自生成历史]
  RISK -.一 token 偏.-> SNOW[雪崩]
  SNOW --> BAD[出问题]

  DIST -.训推不对称.-> RISK

  style DIST fill:\#1d2433,stroke:\#BAE67E,color:#BAE67E
  style SNOW fill:\#1d2433,stroke:\#FFA3A3,color:#FFA3A3
  style BAD fill:\#1d2433,stroke:\#FFA3A3,color:#FFA3A3
```

$$P_\text{train}(s_t \mid s_{<t}^\text{real}, c) \neq P_\text{infer}(s_t \mid \hat{s}_{<t}, c)$$

**错误累积概率**：设单步独立错率 $p$，连续 T 步出错概率：

$$P_\text{err}(T) = 1 - (1-p)^T$$

|p|T=100|T=500|T=1000|T=1600|
|---|---|---|---|---|
|0.001|9.5%|39%|63%|**80%**|
|0.005|39%|**92%**|99%|~100%|
|0.01|63%|99%|~100%|~100%|

> [⚠️] **单步错率 0.5% · 500 token · 出错概率 ≈92%**。这是为什么 cut 是唯一根治手段：把 T 缩到 100，出错概率降到 39%。

## 3. cut 策略是第一优先

```mermaid
flowchart TD
  TEXT[输入文本·~500字] --> Q{cut 选择}
  Q -->|cut0 不切| AS_IS[**难以生成·必坌**]
  Q -->|cut1 多句隔点| MULTI[中·5 句/段]
  Q -->|cut2 50字 · 词粒度| FIFTY[平衡]
  Q -->|cut3 中文句号| BY_PERIOD[**推荐**·不装问题]
  Q -->|cut4 英文句号| EN[英文使用]
  Q -->|cut5 按标点| PUNCT[项目需调]

  style AS_IS fill:\#1d2433,stroke:\#FFA3A3,color:#FFA3A3
  style BY_PERIOD fill:\#1d2433,stroke:\#BAE67E,color:#BAE67E
```

|cut|含义|适用|错率限|
|---|---|---|---|
|cut0|不切|短句 <20 字|高|
|cut1|按 5 句/段|中|中|
|cut2|按 50 字|多|低|
|**cut3**|**按中文句号**|**默认推**|**最低**|
|cut4|按英文句号|英项目|低|
|cut5|按标点|多语种|低|

> [💡] **cut3 是默认·项目里 95% 场景都应该开」**。不切别试 1000 token 上限，那是在给 exposure bias 送军充火药。

## 4. 调参经验表

```mermaid
flowchart LR
  PROB[长文本不稳] --> CUT[**cut3** · 首选]
  CUT --> REP[repetition_penalty 1.35 → **1.5**]
  REP --> TEMP[temperature 0.7 → **0.6**]
  TEMP --> EARLY[early_stop_num 1600 → **2000**]
  EARLY --> TOPK[top_k 15 → **10**]
  TOPK --> STABLE[稳定]

  style PROB fill:\#1d2433,stroke:\#FFA3A3,color:#FFA3A3
  style STABLE fill:\#1d2433,stroke:\#BAE67E,color:#BAE67E
```

|参数|默认|长文本|原理|
|---|---|---|---|
|how_to_cut|cut0|**cut3**|减少 T|
|top_k|15|**10**|减少采样随机性|
|top_p|0.8|0.85|保留足够选项|
|temperature|0.7|**0.6**|锐化分布|
|repetition_penalty|1.35|**1.5**|压重复|
|early_stop_num|1600|**2000**|防被提前截|

## 8. 工程判断

> 🔧 **设定 cut3 是第一优先，其他都是补助**。看到长文本不稳不要先调 temperature，先调 cut。

> ⚠️ **temperature 调太低（<0.5）会出现机械感 · 语调一致**。不要为了稳犹犹调。

> 💡 **在医疗 / 法律 / 广告场景，人工加标点是性价比最高的稳定性优化**；能包走 80% 问题。SSML 语魔补上可走 95%。

> 🤔 **根治需 Scheduled Sampling 或 RL 微调**。仅靠采样重错修复是「创可贴」不是「手术」。VALL-E 2 的 Grouped GPT 是另一条可期路径。
