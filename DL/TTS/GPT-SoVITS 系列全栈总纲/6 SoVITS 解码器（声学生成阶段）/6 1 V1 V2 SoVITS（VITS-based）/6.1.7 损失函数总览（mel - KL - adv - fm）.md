> [📎] 前置知识：VAE、GAN、Mel Spectrogram L1、KL Divergence、Feature Matching。

> **定位**：总览 V1/V2 SoVITS 训练时的所有 loss 项、权重、计算位置。一张表看清 5 项 loss，避免调参时迷路。

## 1. 总 loss公式

$$\mathcal L_G = \lambda_{\text{mel}} \mathcal L_{\text{mel}} + \lambda_{\text{KL}} \mathcal L_{\text{KL}} + \lambda_{\text{GAN}} \mathcal L_G^{\text{GAN}} + \lambda_{\text{FM}} \mathcal L_{\text{FM}} + \lambda_{\text{dur}} \mathcal L_{\text{dur}}$$

$$\mathcal L_D = \mathcal L_D^{\text{MPD}} + \mathcal L_D^{\text{MSD}}$$

## 2. 详拆

|Loss|公式 / 含义|权重|作用|
|---|---|---|---|
|$\mathcal L_{\text{mel}}$|$\\|\text{mel}(x) - \text{mel}(\hat x)\\|_1$|**45.0**|重构保真|
|$\mathcal L_{\text{KL}}$|$D_{\text{KL}}(q(z\|x) \\| p(z\|c))$|1.0|Posterior ⊣ Prior|
|$\mathcal L_G^{\text{GAN}}$|$\sum_k (D_k(\hat x) - 1)^2$|1.0|接近真实分布|
|$\mathcal L_{\text{FM}}$|$\sum_l \\|\phi_l(x) - \phi_l(\hat x)\\|_1$|**2.0**|多层特征对齐|
|$\mathcal L_{\text{dur}}$|Duration L2（该项在 GPT-SoVITS 中被去除）|**0**|原 VITS 需，SoVITS 不需|

## 3. 为何 mel 权重 = 45

VITS 原论文经验值。mel L1 量级不高（0.1–0.5），但是总 loss 中最重要的重构信号，需放大。KL 中项量级为 1–5，需「助助」后才能与 mel 赛衡。

> [💡] **45 是 sweet spot**：社区实验趋后 30/45/60 听感不可辨，40 以下 mel 重构质量下降。 保持 45 是「被许多口碑验证」的选项。

## 4. KL warmup

训练初期 $\mathcal L_{\text{KL}}$ 不启动或貃低权重。

```python
kl_weight = min(1.0, current_step / kl_warmup_steps)  # warmup 5000 step
loss = mel_l1 * 45 + kl_div * kl_weight + ...
```

> [⚠️] **不 warmup KL 的后果**：KL 初期表现为 $\mu, \sigma$ 趋于 Prior（被「压」住），Posterior 未能学到有意义信息，mel L1 反者不下降。KL warmup 是 VAE 训练的标准套緯。

## 5. loss 监控门阈

|Loss|初期|收敛后|异常|
|---|---|---|---|
|mel L1|1.5|**0.3–0.5**|>1.0 表示谱提取问题|
|KL|5–10|**1–3**|>10 收敛后表示 Posterior 过 sharp|
|G GAN|0.5|**0.3–0.7**|>1 D 过强|
|D total|1.0|**0.3–0.8**|<0.05 D 过强|
|FM|2–5|**1–2**|>5 表示 G 未接近真实|

## 6. 与 V3/V4 的区别

V3/V4 采用 CFM 后不再需 GAN / Feature Matching：

|Loss|V1/V2|V3/V4|
|---|---|---|
|mel L1 ×45|✅|❌|
|KL|✅|❌|
|GAN|✅|❌|
|FM|✅|❌|
|**CFM Flow Matching L2**|❌|**✅**|

> [💡] **V3 的损失面随架构变了**：CFM 是「预测速度场」的回归问题 (L2 损失)，不再需 GAN。详见 [[6.2.1 CFM Backbone（Conditional Flow Matching）]]。

## 7. 工程判断

> [🔧] **loss 不同步下降是常态**：GAN 训练中 D loss 不会「単调下降」，震荡是正常。只要 mel L1 稳定下降、听感质量提升，其他 loss 在 [0.3, 5] 内环动都可接。不要「看它以 loss 曲线」。
