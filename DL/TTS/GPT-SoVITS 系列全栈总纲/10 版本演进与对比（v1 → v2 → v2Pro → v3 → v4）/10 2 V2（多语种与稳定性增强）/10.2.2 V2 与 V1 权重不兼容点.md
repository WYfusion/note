> [📎] 前置知识：PyTorch state_dict 加载、Embedding 形状、AR 输入 token 空间。

> **定位**：v1 / v2 权重不能互加载。本节说明 为何 · 哪些 · 如何迁移。

## 1. 为何不兼容

## 2. 具体不兼容点

|模块|v1 形状|v2 形状|原因|
|---|---|---|---|
|AR phone Embedding|[300, 512]|[600, 512]|symbols 扩|
|SoVITS TextEncoder Embedding|[300, 192]|[600, 192]|symbols 扩|
|SoVITS bert proj in_dim|❌ 未有|1024→192|v2 + BERT|
|AR bert proj in_dim|❌|1024→512|v2 + BERT|

## 3. 跳载出错例

```jsx
RuntimeError: Error(s) in loading state_dict for SynthesizerTrn:
  size mismatch for enc_p.text_embedding.weight:
    copying a param with shape torch.Size([300, 192]) from checkpoint,
    the shape in current model is torch.Size([600, 192]).
  Missing key(s) in state_dict: "enc_p.bert_proj.weight", ...
```

## 4. 三种迁移选择

|选|做法|质量|
|---|---|---|
|**重训 v2 (推荐)**|下 v2 预训 ckpt + SFT|⭐⭐⭐⭐⭐|
|手动 expand Embedding|新 emb[:300] = old; 后 300 zero-init|⭐⭐|
|仅用 v1|不上 v2 前端|⭐|

## 5. 手动 expand 伪代码

```python
import torch
v1_ckpt = torch.load('v1_s2G.pth', map_location='cpu')
v2_init = torch.load('v2_pretrain_s2G.pth', map_location='cpu')

# 拷入 v1 emb 到 v2 前 300 位
v1_emb = v1_ckpt['weight']['enc_p.text_embedding.weight']
v2_init['weight']['enc_p.text_embedding.weight'][:v1_emb.shape[0]] = v1_emb
# 后面多语种 300 个 token 保持 v2 预训初始化

# AR bert_proj 需随 v2 预训 · 不需拷贝
torch.save(v2_init, 'migrated_v2.pth')
```

> [⚠️] **手动迁移质量低**：BERT proj 未训 · 多语种 token 未训 · 需 SFT。 社区 不 推荐 手 动 迁 移 · 推荐 重 新 SFT 于 v2 预训。

## 6. 迁移后训练参数

|项|推荐|
|---|---|
|起始 lr|5e-5 (低于默认)|
|warmup_steps|2000|
|max_steps|10000–20000|
|冻结|仅训 bert_proj + emb · 冻 AR body|

## 7. 工程判断

> [🔧] **跳 v2 应重训 SFT**：v1 · v2 架构变化 · 手 动 迁 移 质 量 低。社区 推荐 下 v2 预训 ckpt + 用 你的数据 SFT · 是唯一可靠上 v2 的路径。
