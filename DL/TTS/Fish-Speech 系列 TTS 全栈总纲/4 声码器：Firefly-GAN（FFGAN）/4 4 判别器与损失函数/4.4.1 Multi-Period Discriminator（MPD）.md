## 4.4.1.0 定位

> 一句话：**Multi-Period Discriminator（MPD）** 是 HiFi-GAN 提出的「周期采样」判别器，以多个互质素周期拽取波形中的不同细节，促进谐波升生。

---

## 4.4.1.1 为什么需要「周期」判别器

> [!important]
> 
> 语音信号本质是复杂的准周期信号：
> 
> - 基频（0 50-400 Hz）产生「存在」。
> 
> - 谐波（1-10 kHz）是基频的整数倍。
> 
> - 传统 1D Conv 难以抓住顶期性：感野为连续、没有明确周期轴。
> 
> MPD 柠于「将 1D 波形 reshape 为 2D 带周期轴」，后采用 2D Conv。

## 4.4.1.3 多周期设置

HiFi-GAN/Firefly-GAN 采用 5 个互质周期：$p \in \{2, 3, 5, 7, 11\}$。

> [!important]
> 
> **为什么互质**？避免不同周期之间出现同期重叠。$\{2, 3, 5, 7, 11\}$ 是前 5 个质数，逆索索皆 1。

---

## 4.4.1.4 单周期判别器结构

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DiscriminatorP(nn.Module):
    def __init__(self, period):
        super().__init__()
        self.period = period
        ks, ss = 5, 3
        self.convs = nn.ModuleList([
            nn.Conv2d(1, 32, (ks, 1), (ss, 1), padding=(2, 0)),
            nn.Conv2d(32, 128, (ks, 1), (ss, 1), padding=(2, 0)),
            nn.Conv2d(128, 512, (ks, 1), (ss, 1), padding=(2, 0)),
            nn.Conv2d(512, 1024, (ks, 1), (ss, 1), padding=(2, 0)),
            nn.Conv2d(1024, 1024, (ks, 1), 1, padding=(2, 0)),
        ])
        self.conv_post = nn.Conv2d(1024, 1, (3, 1), 1, padding=(1, 0))

    def forward(self, x):
        # x: (B, 1, T)
        B, C, T = x.shape
        # pad to multiple of period
        if T % self.period != 0:
            pad = self.period - (T % self.period)
            x = F.pad(x, (0, pad), 'reflect')
            T = T + pad
        x = x.view(B, C, T // self.period, self.period)  # (B, 1, T/p, p)
        fmap = []
        for conv in self.convs:
            x = F.leaky_relu(conv(x), 0.1)
            fmap.append(x)
        x = self.conv_post(x)
        fmap.append(x)
        return x.flatten(1, -1), fmap
```

## 4.4.1.5 与 MSD 对比

|项目|**MPD**|MSD|
|---|---|---|
|输入维度|2D (重塑 1D)|1D|
|重点获得|**周期性、谐波**|**多尺度、齐创**|
|数量|5 (互质周期)|3 (原、avg-pool 2×、4×)|

## 4.4.1.6 为什么 MPD 提升 perceptual quality

> [!important]
> 
> HiFi-GAN 原论文报告 MPD 贡献主要在：
> 
> 1. **上高频发音清晰度**：s, sh, t, k 等高频 fricative 需周期信号表达。
> 
> 1. **上 buzz/hiss 减少**：不自然的 sub-harmonic noise 被 MPD 抓住。
> 
> 1. **训练拉入 MOS 提升 ~0.3**。

## 4.4.1.7 踩坑记录

> [!important]
> 
> **坑 1：reshape 前未 pad** → 输入 T 不为 p 倍数会报错。
> 
> **坑 2：reflect pad 不适 small T** → 训练初期短 segment 需采用 zero pad。
> 
> **坑 3：spectral norm 未应用** → GAN 训练不稳，需 weight_norm 或 spectral_norm。
