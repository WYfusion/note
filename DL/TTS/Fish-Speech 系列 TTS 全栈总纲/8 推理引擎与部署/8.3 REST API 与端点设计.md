## 8.3.0 定位

> 一句话：Fish-Speech 提供与 **OpenAI TTS API 兼容** 的 REST 接口，可直接替换 OpenAI 客户端使用。

---

## 8.3.1 接口列表

|路径|方法|作用|
|---|---|---|
|/v1/audio/speech|POST|文转语音（OpenAI 兼容）|
|/v1/audio/speech/stream|POST|流式 TTS（SSE）|
|/v1/voices|GET|列出可用说话人|
|/v1/voices/upload|POST|上传参考音频|
|/v1/health|GET|健康检查|

---

## 8.3.2 请求示例与 OpenAI 对齐

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="sk-xxx",  # Fish-Speech 不验证，占位
)

resp = client.audio.speech.create(
    model="fish-speech-1.5",
    voice="alice",          # speaker ID
    input="你好，世界。",
    response_format="mp3",  # mp3 / wav / opus
    speed=1.0,
)
with open("out.mp3", "wb") as f:
    f.write(resp.content)
```

## 8.3.3 流式调用

```python
import requests

with requests.post(
    "http://localhost:8080/v1/audio/speech/stream",
    json={"input": "这是一段长文本。", "voice": "alice"},
    stream=True,
) as r:
    for chunk in r.iter_content(chunk_size=4096):
        play_audio(chunk)  # 逐块播放
```

> [!important]
> 
> 流式接口 TTFB ~200 ms，后续音频连续推送，适合实时交互。

## 8.3.4 扩展参数（超出 OpenAI 规格）

|参数|说明|
|---|---|
|reference_audio|Base64 编码的参考音频|
|reference_text|参考音频对应文本|
|lora_id|指定 LoRA 适配器|
|emotion|(happy) / (sad) / (angry) ...|
|top_p / top_k / temperature|采样参数|
|seed|随机种子，保证可复现|

---

## 8.3.5 错误码

|HTTP|code|含义|
|---|---|---|
|400|invalid_input|文本超长 / 不可识别字符|
|404|voice_not_found|说话人 ID 不存在|
|429|rate_limit|请求超限|
|503|model_loading|服务启动中|

---

## 8.3.6 踩坑记录

> [!important]
> 
> **坑 1：OpenAI SDK 默认超时 60s** → 长文本需手动调高 timeout。
> 
> **坑 2：/v1/audio/speech 返回二进制 vs Base64** → 需与客户端约定 Content-Type。
> 
> **坑 3：参考音频体积大** → 推荐预上传获取 voice_id，避免每次上传。
