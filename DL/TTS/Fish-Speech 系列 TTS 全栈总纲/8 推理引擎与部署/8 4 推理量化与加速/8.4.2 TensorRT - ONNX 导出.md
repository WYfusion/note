## 8.4.2.1 ONNX vs TensorRT

|属性|ONNX|TensorRT|
|---|---|---|
|性质|跳档格式|NVIDIA 推理引擎|
|设备|跨平台|NVIDIA GPU|
|友好模型|CNN, Transformer|同|
|静态图|需要|需要|
|加速倍数|1.2-1.5x|2-3x|
|INT8 量化|支持|**原生**|

## 8.4.2.3 ONNX 导出

```python
import torch
from fish_speech import FishSpeechModel

model = FishSpeechModel.from_pretrained("checkpoints/openaudio-s2-pro")
model.eval()

# Dummy input 不能为动态 shape 未设
batch = 1
seq_len = 256
dummy_input = {
    "input_ids": torch.zeros(batch, seq_len, dtype=torch.long).cuda(),
    "attention_mask": torch.ones(batch, seq_len).cuda(),
}

torch.onnx.export(
    model,
    (dummy_input,),
    "fish_speech.onnx",
    input_names=["input_ids", "attention_mask"],
    output_names=["logits"],
    dynamic_axes={
        "input_ids": {0: "batch", 1: "seq"},
        "attention_mask": {0: "batch", 1: "seq"},
        "logits": {0: "batch", 1: "seq"},
    },
    opset_version=17,
)
```

## 8.4.2.4 ONNX Simplifier

```bash
pip install onnxsim

python -m onnxsim fish_speech.onnx fish_speech.simplified.onnx \
    --overwrite-input-shape "input_ids:1,256"
```

> [!important]
> 
> onnxsim 能合并连续的 Cast / Reshape / Constant 节点，减少 30-50% 节点数，提高后续 TRT 构建速度。

## 8.4.2.5 TensorRT 构建

```bash
trtexec \
    --onnx=fish_speech.simplified.onnx \
    --saveEngine=fish_speech.engine \
    --fp16 \
    --memPoolSize=workspace:8192 \
    --minShapes=input_ids:1x1 \
    --optShapes=input_ids:1x256 \
    --maxShapes=input_ids:1x2048
```

> [!important]
> 
> **重点参数**：
> 
> - `--fp16`：启用 FP16 inference，+1.8x 加速。
> 
> - `--int8`：需 calibration 集，+2.5x 加速。
> 
> - `--minShapes/optShapes/maxShapes`：动态 shape 上下限。
> 
> - `--memPoolSize`：workspace 大小，默认 1GB，大模型需提升。

## 8.4.2.6 推理代码

```python
import tensorrt as trt
import pycuda.driver as cuda
import pycuda.autoinit
import numpy as np

TRT_LOGGER = trt.Logger(trt.Logger.WARNING)
runtime = trt.Runtime(TRT_LOGGER)

with open("fish_speech.engine", "rb") as f:
    engine = runtime.deserialize_cuda_engine(f.read())
context = engine.create_execution_context()

# bindings = host 与 device 的指针集合
bindings = [int(cuda.mem_alloc(...)) for _ in range(engine.num_bindings)]
context.execute_v2(bindings)
```

## 8.4.2.7 踩坑

> [!important]
> 
> - **opset_version 过低**：RMSNorm / RoPE 需 opset >= 17。
> 
> - **Dynamic shape 损失 加速**：TensorRT 在 dynamic shape 下会生成多 profile，加速不如 static。推荐固定 seq_len bucket。
> 
> - **KV cache 不能导出 ONNX**：AR 推理需 KV cache。需使用 SGLang/TRT-LLM 专用路径。
> 
> - **加载 engine 跨 GPU 失败**：.engine 与 GPU 架构纯对应。A100 构建的 engine 不能在 H100 运行，需重建。
