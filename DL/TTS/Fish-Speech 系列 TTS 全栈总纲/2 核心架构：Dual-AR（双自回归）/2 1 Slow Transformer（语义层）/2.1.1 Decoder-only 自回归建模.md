## 2.1.1.0 定位

> 一句话：本页推导 Slow Transformer 为 **一个带 prompt audio 的条件自回归建模器**，明确给出训练与推理阶段的数学形式。

---

## 2.1.1.1 自回归分解

设文本序列 $T = (t_1, \dots, t_m)$，prompt audio token 序列 $P = (p_1, \dots, p_n)$，目标 audio token 序列 $A = (a_1, \dots, a_L)$。在 Slow 层面，只考虑 codebook 0（主 token）：

$$p(A \mid T, P) = \prod_{i=1}^{L} p\!\left(a_i \,\big|\, T, P, a_{<i}\right)$$

这是严格的**链式法则**分解，与 GPT 生成同形。

---

## 2.1.1.2 输入拼接与位置

$$X = [\,\text{embed}(t_1), \dots, \text{embed}(t_m), \text{embed}(p_1), \dots, \text{embed}(p_n), \text{embed}(a_1), \dots, \text{embed}(a_{i-1})\,]$$

RoPE 定位起点需区别「文本轴」与「音频轴」，但 Fish-Speech 采用统一位置索引，依靠 modality token 划分。

---

## 2.1.1.3 训练 loss

$$\mathcal{L}_{\text{slow}} = -\frac{1}{L} \sum_{i=1}^{L} \log p\!\left(a_i \mid T, P, a_{<i}\right)$$

在 GFSQ 多码本设计下，Fish-Speech 实际 loss 是 8 个 head 联合：

$$\mathcal{L} = \sum_{k=0}^{7} \lambda_k \mathcal{L}_{\text{head-}k}$$

其中 $k=0$ 由 Slow head 负责，$k=1, \dots, 7$ 由 Fast head 负责。

---

## 2.1.1.4 推理伪代码

```python
def slow_inference(text_ids, prompt_audio_ids, max_len=4096):
    """Slow Transformer 推理 codebook 0。"""
    ctx = embed_text(text_ids) + embed_audio(prompt_audio_ids)
    kv_cache = init_kv_cache(slow_model)
    generated = []
    for i in range(max_len):
        x = ctx if i == 0 else embed_audio([generated[-1]])
        h_i, kv_cache = slow_model(x, kv_cache)        # (1, d)
        logits = slow_head(h_i)                        # (1, V)
        a_i = sample(logits, top_p=0.9, temp=0.8)
        if a_i == EOS:
            break
        generated.append(a_i)
        # h_i 同时作为 Fast 的条件输入
        yield h_i, a_i
    return generated
```

## 2.1.1.5 踩坑记录

> [!important]
> 
> **坑 1：prompt audio 后忘加 separator token**。会导致生成一口气跟 prompt 尾部音色对不上。
> 
> **坑 2：推理不用 KV cache**，$O(L^2)$ 复杂度冲顶。必须 cache。
> 
> **坑 3：h_i 传递给 Fast 时未 detach**，训练时梯度会反传双路引起不稳。需判断训练/推理 mode。

## 2.1.1.6 与 VALL-E 的区别

|项目|VALL-E AR|**Fish-Speech Slow**|
|---|---|---|
|Codebook|1 个（Encodec layer 0）|1 个（GFSQ codebook 0）|
|下游|VALL-E NAR 生成剩 layer|**Fast Transformer AR 生成剩 codebook**|
|token rate|75 Hz|**25 Hz**|
