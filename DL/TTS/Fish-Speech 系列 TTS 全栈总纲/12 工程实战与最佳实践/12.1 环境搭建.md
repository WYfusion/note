## 12.1.2 软件依赖

> [!important]
> 
> - **OS**：Ubuntu 22.04 / Windows 10+ / macOS 13+ 。推荐 Linux。
> 
> - **Python**：3.10 (不推荐 3.11+，部分依赖未适配)。
> 
> - **CUDA**：12.1+ (Linux/Windows GPU)。
> 
> - **PyTorch**：2.4.1 + cu121。
> 
> - **FFmpeg**：需在 PATH 中（处理音频 IO）。
> 
> - **Git LFS**：拉取模型权重。

---

## 12.1.3 环境安装 - Linux

```bash
# 1. 安装 conda
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh

# 2. 创建环境
conda create -n fish-speech python=3.10 -y
conda activate fish-speech

# 3. 安装 PyTorch (CUDA 12.1)
pip install torch==2.4.1 torchaudio==2.4.1 --index-url https://download.pytorch.org/whl/cu121

# 4. 安装 FFmpeg
sudo apt install ffmpeg git-lfs
git lfs install

# 5. 克隆仓库
git clone https://github.com/fishaudio/fish-speech
cd fish-speech
pip install -e .[stable]
```

---

## 12.1.4 环境安装 - Windows

```powershell
# 推荐使用 WSL2 + Ubuntu
wsl --install -d Ubuntu-22.04

# 进入 WSL 后同 Linux 流程

# 或者使用官方 portable 包（免安装）
# https://github.com/fishaudio/fish-speech/releases
```

> [!important]
> 
> Windows 下原生运行可能遇到 OpenSSL / FFmpeg 路径问题，推荐优先使用 WSL2。

## 12.1.5 验证环境

```bash
# 1. 验证 CUDA
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"

# 2. 验证 fish-speech 包
python -c "import fish_speech; print(fish_speech.__version__)"

# 3. 验证 FFmpeg
ffmpeg -version
```

## 12.1.6 常见问题

> [!important]
> 
> - **CUDA OOM**：试 INT4 量化、减 batch size、启用 KV cache。
> 
> - **依赖冲突**：创建独立 conda 环境，不要与其它项目共享。
> 
> - **FFmpeg 找不到**：检查 PATH，Windows 加入 ffmpeg.exe 所在目录。
> 
> - **Git LFS 超时**：使用镜像位址（[hf-mirror.com](http://hf-mirror.com) / modelscope）。
