## 12.3.0 定位

> 一句话：单条合成是 Fish-Speech 最基本的入门 demo，实现后可以验证环境、检查质量、作为上层集成点。

---

## 12.3.1 Python API 一行调用

```python
from fish_speech import FishSpeechModel

model = FishSpeechModel.from_pretrained("checkpoints/openaudio-s2-pro")

wav = model.tts(
    text="你好，欢迎使用 Fish-Speech。",
    reference_audio="reference.wav",
    reference_text="你好，我是一个物试者。",
)

import soundfile as sf
sf.write("out.wav", wav, 44100)
```

---

## 12.3.2 参数说明

|参数|含义|默认|推荐范围|
|---|---|---|---|
|text|要记说的文本|必填|< 500 chars|
|reference_audio|参考音频 wav|None|3-10s|
|reference_text|参考音频转录|None|与音频一致|
|temperature|采样温度|0.7|0.6 - 1.0|
|top_p|top-p 采样|0.7|0.5 - 0.9|
|repetition_penalty|重复惩罚|1.5|1.0 - 2.0|
|max_new_tokens|生成上限|2048|按需调|

## 12.3.3 CLI 调用

```bash
python -m fish_speech.tts \
    --text "你好，欢迎使用 Fish-Speech。" \
    --reference-audio reference.wav \
    --reference-text "你好，我是一个物试者。" \
    --checkpoint checkpoints/openaudio-s2-pro \
    --output out.wav
```

## 12.3.4 调参技巧

> [!important]
> 
> - **听起来老人**：temperature 高。试 1.0。
> 
> - **走音偏离**：代表 reference_audio 与 reference_text 不匹配。检查转录。
> 
> - **重复、吃字**：增加 repetition_penalty 到 1.8。
> 
> - **语速太快/太慢**：在文本内插入 (slow) (fast) NL Tag。
> 
> - **能调不出情感**：提醒 reference_audio 需含同类情感。

## 12.3.6 常见错误

> [!important]
> 
> - `**RuntimeError: CUDA out of memory**`：添加 `--int4` 或减少 max_new_tokens。
> 
> - **生成一直打静**：reference_audio 太静或不包含质量。检查是否 < 1 秒。
> 
> - **音频崩坏**：检查模型哈希，重下。
> 
> - **中英混合说不出**：Fish-Speech 支持，但需 reference_audio 同样为中英混合。
