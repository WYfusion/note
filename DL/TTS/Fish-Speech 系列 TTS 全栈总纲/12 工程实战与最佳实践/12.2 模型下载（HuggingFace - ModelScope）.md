## 12.2.1 模型仓库与里程碑

|模型|大小|推荐场景|
|---|---|---|
|fish-speech-1.5|2.1 GB|入门/老代码|
|openaudio-s1-mini|0.9 GB|低资源部署|
|**openaudio-s1**|2.4 GB|生产 baseline|
|**openaudio-s2**|3.1 GB|高质、全面能力|
|**openaudio-s2-pro**|3.5 GB|最佳 (UTMOS 4.32)|
|firefly-gan-vocoder|0.3 GB|声码器（必备）|

## 12.2.3 下载脚本

```bash
# 方法 1: HF CLI
huggingface-cli download fishaudio/openaudio-s2-pro \
    --local-dir checkpoints/openaudio-s2-pro

# 方法 2: 镜像加速下载
export HF_ENDPOINT=https://hf-mirror.com
huggingface-cli download fishaudio/openaudio-s2-pro \
    --local-dir checkpoints/openaudio-s2-pro

# 方法 3: ModelScope
from modelscope import snapshot_download
model_dir = snapshot_download("fishaudio/openaudio-s2-pro")
```

---

## 12.2.4 验证哈希

```bash
# 计算 SHA256
sha256sum checkpoints/openaudio-s2-pro/model.safetensors

# 与官方发布的哈希对比
cat checkpoints/openaudio-s2-pro/SHA256SUMS
```

> [!important]
> 
> 如哈希不匹配，重下一次。体现为在推理时输出崩坏音频。

## 12.2.5 加载与初始化

```python
from fish_speech import FishSpeechModel

model = FishSpeechModel.from_pretrained(
    "checkpoints/openaudio-s2-pro",
    device="cuda",
    dtype="bfloat16",  # 或 "int4"
    use_kv_cache=True,
)
print(model.config)
```

## 12.2.7 常见坐坏

> [!important]
> 
> - **下载中断**：[hf-mirror.com](http://hf-mirror.com) 可以 resume。需安装 `aria2` 加速。
> 
> - **资源仓库不发布 v2-Pro**：Fish Audio 需邀请辩产生 openaudio-s2-pro，社区版本有些差别。
> 
> - **加载后 OOM**：换为 int4 量化。
