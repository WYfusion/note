## 12.7.0 定位

> 一句话：ms-swift（阿里 ModelScope 出品）是中文社区最受欢迎的调参框架，为 Fish-Speech LoRA 训练提供了如下优点：“加速、多卡、可锁」。

---

## 12.7.1 ms-swift 是什么

> [!important]
> 
> ms-swift = ModelScope Swift，是面向多模态大模型的 PEFT 训练框架。支持：
> 
> - Llama / Qwen / Baichuan 等文本模型。
> 
> - Fish-Speech / CosyVoice 等 TTS 模型。
> 
> - DeepSeek-VL / Qwen-VL 等 VLM。
> 
> - LoRA / QLoRA / DoRA / GaLore 等 PEFT 方法。
> 
> - DeepSpeed Zero-2/3 改序。

---

## 12.7.2 安装

```bash
pip install ms-swift

# 验证
swift --help
```

---

## 12.7.3 快速上手

```bash
# 1. 下载 Fish-Speech 模型
swift download \
    --model fishaudio/openaudio-s2-pro \
    --local_dir checkpoints/

# 2. 启动 LoRA 训练
swift sft \
    --model checkpoints/openaudio-s2-pro \
    --dataset my_voice_dataset \
    --train_type lora \
    --lora_rank 16 \
    --lora_alpha 32 \
    --lr 1e-4 \
    --num_train_epochs 50 \
    --batch_size 8 \
    --gradient_accumulation_steps 2 \
    --output_dir checkpoints/lora_my_voice \
    --deepspeed default-zero2
```

## 12.7.4 与原生训练脚本对比

|维度|原生脚本|ms-swift|
|---|---|---|
|安装|需手动配|**一行**|
|多卡|需手动 torchrun|**自动** DeepSpeed|
|QLoRA|不支持|**原生**|
|日志|仅 stdout|**SwanLab/W&B**|
|恢复训练|需手动|**自动 resume**|
|文档|社区依赖|**官方文档**|

## 12.7.5 QLoRA（4-bit 量化 LoRA）

```bash
swift sft \
    --model checkpoints/openaudio-s2-pro \
    --dataset my_voice_dataset \
    --train_type lora \
    --quantization_bit 4 \
    --bnb_4bit_compute_dtype bfloat16 \
    --lora_rank 16 \
    --lr 2e-4 \
    --output_dir checkpoints/qlora_my_voice
```

> [!important]
> 
> QLoRA 能让 24GB GPU 训练 0.6B 模型只需 8GB 显存，门槛准入大限降低。

## 12.7.6 多卡 + DeepSpeed Zero-3

```bash
NPROC_PER_NODE=4 swift sft \
    --model checkpoints/openaudio-s2-pro \
    --dataset my_voice_dataset \
    --train_type lora \
    --lora_rank 64 \
    --deepspeed default-zero3 \
    --batch_size 4 \
    --gradient_accumulation_steps 4 \
    --output_dir checkpoints/lora_zero3
```

## 12.7.7 训练后推理

```python
from swift.llm import infer_main, InferArguments

args = InferArguments(
    model="checkpoints/openaudio-s2-pro",
    adapters=["checkpoints/lora_my_voice"],
    merge_lora=True,  # 可选 merge
)
infer_main(args)
```

## 12.7.8 常见问题

> [!important]
> 
> - `**ImportError: deepspeed**`：补 `pip install deepspeed`，需 GCC 9+。
> 
> - **多卡 hang**：NCCL 超时。设 `NCCL_TIMEOUT_MS=1800000`。
> 
> - **OOM in zero-3**：offload optimizer to CPU。
> 
> - **不能加载 Fish-Speech**：swift 版本 < 2.4 不支持。升级到 latest。
