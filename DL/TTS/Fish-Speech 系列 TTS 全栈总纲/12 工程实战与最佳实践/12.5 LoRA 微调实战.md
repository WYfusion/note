## 12.5.0 定位

> 一句话：LoRA 训练是从「克隆」走到「个人专属 TTS」的必经之路，训练代价低、SECS 可升至 0.85+。

---

## 12.5.1 数据准备

|要素|要求|
|---|---|
|总时长|5-20 分钟（越多越好）|
|采样率|22kHz / 44.1kHz|
|背景|无噪、无 BGM|
|语言|与目标一致|
|情感覆盖|平静 + 高兴 + 追伤 + 高亢 (多样)|
|转录|ASR 后人检 (CER 接近 0)|

---

## 12.5.2 数据预处理

```bash
# 1. 切分为 5-15s 片段
python -m fish_speech.tools.slice \
    --input my_audio.wav \
    --output_dir my_dataset/ \
    --max_duration 15

# 2. ASR 转录
python -m fish_speech.tools.asr \
    --input_dir my_dataset/ \
    --output_file my_dataset/labels.json \
    --language zh

# 3. 人工检查
vim my_dataset/labels.json
```

---

## 12.5.3 LoRA 配置

```yaml
# configs/lora_my_voice.yaml
base_model: checkpoints/openaudio-s2-pro
lora:
  r: 16
  alpha: 32
  dropout: 0.05
  target_modules: ["q_proj", "k_proj", "v_proj", "o_proj"]
training:
  epochs: 50
  batch_size: 8
  lr: 1e-4
  warmup_steps: 100
  grad_accum: 2
data:
  train_dir: my_dataset/
  labels: my_dataset/labels.json
```

---

## 12.5.4 训练

```bash
python -m fish_speech.train_lora \
    --config configs/lora_my_voice.yaml \
    --output_dir checkpoints/lora_my_voice
```

|GPU|10分钟数据|训练时间|
|---|---|---|
|RTX 4090|50 epochs|~2 小时|
|A100 40GB|50 epochs|~1 小时|

## 12.5.5 推理与出品

```python
from fish_speech import FishSpeechModel, load_lora

model = FishSpeechModel.from_pretrained("checkpoints/openaudio-s2-pro")
model = load_lora(model, "checkpoints/lora_my_voice")

wav = model.tts(
    text="今天是个好天气。",
    reference_audio="sample.wav",
    reference_text="示例转录。",
)
```

## 12.5.6 评价 LoRA 质量

> [!important]
> 
> 1. **SECS**：训练后应达 0.85+。低于 0.80 需增加数据。
> 
> 1. **UTMOS**：不低于 baseline。下降多说明过拟合。
> 
> 1. **CER**：与 baseline 保持一致。LoRA 几乎不应击语义。
> 
> 1. **主观听**：听一下是否是本人。

---

## 12.5.7 踩坑记录

> [!important]
> 
> - **过拟合**：数据太少 + epochs 太多。如 5 分钟数据需 ≤ 30 epochs。
> 
> - **过化**：LoRA r 太高（如 64+） + alpha 太高 → 变成全量微调 → 伤部分 baseline。推荐 r=8/16/32。
> 
> - **说话人崩坏**：所有句子都是本人 → LoRA 变为「说话人 叠加」。需加入多样性额外数据。
