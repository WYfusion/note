## 0. 定位

> 一句话：本页用一张对比矩阵、一棵决策树、一份误区清单，回答**「同一个模型/数据集，到底该从哪儿下、用什么入口下」**。

## 1. 两大生态的「物理事实」

| 维度     | **HuggingFace Hub**               | **ModelScope Hub**                 |
| ------ | --------------------------------- | ---------------------------------- |
| 主体     | Hugging Face Inc.（法 / 美）          | 阿里达摩院 / 通义实验室                      |
| 主域名    | `huggingface.co`                  | `www.modelscope.cn`                |
| 国内可达性  | ❌ 直连大概率被墙                         | ✅ 国内 CDN，稳定                        |
| 核心 SDK | `huggingface_hub`                 | `modelscope`                       |
| 底层存储   | **Git LFS** → 新 **Xet**（块级去重）     | Git LFS + 自研对象存储                   |
| 主流模型覆盖 | 📈 国际开源最完整（Llama / Mistral / SD…） | 📈 国内开源最完整（Qwen / DeepSeek / GLM…） |
| 镜像     | `hf-mirror.com`（社区维护）             | 无需镜像                               |

## 2. 决策树：到底从哪里下？

```mermaid
flowchart TD
	START["开始：我要一个 repo"] --> Q1{"模型方/数据方<br>主推哪个 Hub？"}
	Q1 -->|HF 独占| HF_ONLY["HF 路线"]
	Q1 -->|MS 独占| MS_ONLY["MS 路线"]
	Q1 -->|两边都有| Q2{"我在哪？"}
	Q2 -->|海外 / 出网良好| HF_PREF["HF 优先"]
	Q2 -->|国内大陆| Q3{"是否在<br>训练流水线？"}
	Q3 -->|是| FALLBACK["抽象层：MS 主，HF 备"]
	Q3 -->|否| MS_PREF["MS 优先"]
	HF_ONLY --> Q4{"国内？"}
	Q4 -->|是| HF_MIRROR["HF + hf-mirror.com 镜像"]
	Q4 -->|否| HF_DIRECT["HF 直连"]

	style START fill:\#1d2433,stroke:#bae67e,color:\#bae67e
	style HF_DIRECT fill:\#1d2433,stroke:#ffd580,color:\#ffd580
	style MS_PREF fill:\#1d2433,stroke:#ffd580,color:\#ffd580
```

> [!important]
> 
> **工程优先级**：海外 → 直连 HF；国内通用 → MS 直连；国内 HF 独占 → 镜像；CI/训练 → 抽象层 fallback。三层兜底保证「下载一定能成功」。
