> Apple Silicon（M1 / M2 / M3 / M4）改变了 Python 生态：**部分 wheel 仅 x86_64**，需 Rosetta 翻译；**MPS 后端**替代 CUDA；**bitsandbytes 至今不可用**。

## 一键自检

```bash
uname -m                                            # arm64 = Apple Silicon
sysctl -n machdep.cpu.brand_string                 # 看具体型号
python -c "import platform; print(platform.machine(), platform.processor())"
python -c "import torch; print(torch.backends.mps.is_available())"
```

## Rosetta 2：x86_64 兼容层

首次跑 Intel 二进制会触发安装，也可以手动：

```bash
softwareupdate --install-rosetta --agree-to-license
```

用 Rosetta 跑 Python：

```bash
arch -x86_64 /usr/bin/python3 -c "import platform; print(platform.machine())"   # 输出 x86_64
```

## conda：装哪个 Miniforge

- **arm64 原生**（首选）：`Miniforge3-MacOSX-arm64.sh`

- **x86_64 兼容**（仅当依赖只有 Intel wheel）：`Miniforge3-MacOSX-x86_64.sh`

两个 conda 不冲突，可装在不同前缀：`~/miniforge3-arm64` / `~/miniforge3-x86_64`。

## PyTorch / Transformers 兼容性

|组件|Apple Silicon 状态|备注|
|---|---|---|
|torch|✅ 2.0+ 原生 arm64|MPS 后端：device="mps"|
|transformers|✅ 原生|需 device_map="mps"，部分算子回退 CPU|
|safetensors|✅ 原生||
|hf_transfer|✅ 原生||
|bitsandbytes|❌ 不支持|4/8bit 量化用不了，改用 mlx-lm / Q4_K_M GGUF|
|flash-attn|❌|CUDA-only，MPS 无对等品|
|xformers|⚠️ 部分|memory-efficient attention 已落 MPS|
|vllm|❌|CUDA-only|
|llama.cpp / mlx-lm|✅✅ 原生最优|Metal 加速，无需 torch|

## MPS 后端用法

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "Qwen/Qwen2.5-1.5B-Instruct"
tok = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id, torch_dtype=torch.float16).to("mps")
inputs = tok("你好", return_tensors="pt").to("mps")
out = model.generate(**inputs, max_new_tokens=32)
print(tok.decode(out[0]))
```

常见报错：`NotImplementedError: The operator 'aten::xxx' is not currently implemented for the MPS device`。处方：

```bash
export PYTORCH_ENABLE_MPS_FALLBACK=1   # 不支持的算子自动落 CPU
```

## MLX：原生最佳方案

如果只是推理本地 LLM，建议用 Apple 自家的 mlx-lm：

```bash
pip install mlx-lm
python -m mlx_lm.generate --model mlx-community/Qwen2.5-7B-Instruct-4bit --prompt "你好"
```

mlx 直接调用 Metal，**功耗、速度都优于 torch+MPS**，并且不需要任何 CUDA-tooling。

## 关于量化

- Apple Silicon 上不要硬上 bitsandbytes / AWQ / GPTQ（很多扩展名为 cu 的 op 不存在）。

- 想跑量化：选 **GGUF（llama.cpp / lm-studio）** 或 **mlx-community 的 4bit/8bit 变体**。
