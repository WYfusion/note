> macOS 默认 shell 是 zsh（10.15 Catalina 起）。`~/.zshrc` 是终端的家，但 **GUI 程序**（VSCode、PyCharm、Cursor、Finder 双击 .app）**不读 zshrc**，只读 launchd 注入的环境变量。

## 终端：~/.zshrc

```bash
# ~/.zshrc 末尾
export HF_ENDPOINT="https://hf-mirror.com"
export HF_HOME="$HOME/Library/Caches/huggingface"   # macOS 推荐放 Caches
export HF_HUB_ENABLE_HF_TRANSFER=1
export HF_HUB_DOWNLOAD_TIMEOUT=60
export MODELSCOPE_CACHE="$HOME/Library/Caches/modelscope"
export MODELSCOPE_DOMAIN="www.modelscope.cn"
export TOKENIZERS_PARALLELISM=false
```

生效：

```bash
source ~/.zshrc
env | grep -E '^(HF_|MODELSCOPE_)'
```

> 💡 **关于缓存位置**：macOS 系统约定缓存放 `~/Library/Caches/`，Time Machine 备份默认会跳过这个目录，省备份空间。

## GUI 应用：launchctl setenv

```bash
launchctl setenv HF_ENDPOINT https://hf-mirror.com
launchctl setenv HF_HUB_ENABLE_HF_TRANSFER 1
launchctl setenv HF_HOME "$HOME/Library/Caches/huggingface"
```

**注意**：launchctl setenv **重启就丢**。要持久化，写一个 LaunchAgent：

```xml
<!-- ~/Library/LaunchAgents/com.user.hfenv.plist -->
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.user.hfenv</string>
  <key>ProgramArguments</key>
  <array>
    <string>sh</string>
    <string>-c</string>
    <string>launchctl setenv HF_ENDPOINT https://hf-mirror.com; launchctl setenv HF_HUB_ENABLE_HF_TRANSFER 1; launchctl setenv HF_HOME "$HOME/Library/Caches/huggingface"</string>
  </array>
  <key>RunAtLoad</key>
  <true/>
</dict>
</plist>
```

加载：

```bash
launchctl load ~/Library/LaunchAgents/com.user.hfenv.plist
```

之后每次开机，所有 GUI 程序都能读到 HF_ENDPOINT 等变量。

## VSCode / Cursor 的小坑

- VSCode 终端默认继承启动 VSCode 时的环境。若 launchctl 注入的变量没生效，**VSCode 重启**即可。

- 「Python: Select Interpreter」 之后，Run/Debug 跑的是 IDE 子进程，吃 launchctl 的环境而非 zshrc 的。

## 验证

```bash
# 终端环境
zsh -lic 'env | grep HF_'
# launchctl 注入的（影响 GUI）
launchctl getenv HF_ENDPOINT
```

## 常见错误

|现象|原因|处方|
|---|---|---|
|终端能下，VSCode 不能|没 launchctl setenv|写 LaunchAgent 持久化|
|重启后又失效|没建 plist|同上|
|Cursor / PyCharm 仍读老值|IDE 启动时缓存了 env|退出整个 IDE 后再开|
|iTerm2 与 [Terminal.app](http://Terminal.app) 表现不同|iTerm 可能用 login shell|检查 iTerm「Profiles → General → Command」|
