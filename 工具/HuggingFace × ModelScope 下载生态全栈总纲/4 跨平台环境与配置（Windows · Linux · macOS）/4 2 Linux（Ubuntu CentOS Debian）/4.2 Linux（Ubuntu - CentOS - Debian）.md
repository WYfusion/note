> Linux 是这条工具链的「主场」：环境变量持久化只需写 rc 文件；多用户共享缓存靠 group + setgid；容器化场景则需要把 cache 目录挂出宿主机。本节按 **rc 文件 → 共享权限 → Docker/K8s** 三步走。

## 三发行版兼容性速判

- **Ubuntu / Debian**：默认 `bash`，新 24.04 起部分镜像默认 `dash`；`apt install git-lfs` 已在 22.04+ 直接可用。

- **CentOS / RHEL / Rocky**：默认 `bash`，需 `dnf install git-lfs` 或 `git-lfs/install.sh`；老 CentOS 7 的 glibc 偏低，hf_transfer 的预编译 wheel 可能拒装，需要 `--no-binary` 或升级 glibc。

- **Alpine（常见于容器）**：musl libc，hf_transfer / huggingface-hub 的 C 扩展常需要 `apk add --no-cache build-base linux-headers`。
