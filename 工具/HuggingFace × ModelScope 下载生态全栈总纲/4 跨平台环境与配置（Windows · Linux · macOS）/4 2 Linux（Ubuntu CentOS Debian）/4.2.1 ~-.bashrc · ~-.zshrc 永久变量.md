> Linux 上配置 HF / MS 永久环境变量，**核心就是写对 shell rc 文件**。但坑在哪个 shell 读哪个文件、登录 shell vs 交互 shell、systemd 服务的特殊性。

## 谁读谁的 rc

|shell|登录 shell（SSH）|交互式 shell（terminal）|非交互（脚本）|
|---|---|---|---|
|bash|~/.bash_profile → ~/.bashrc|~/.bashrc|$BASH_ENV|
|zsh|~/.zprofile → ~/.zshrc|~/.zshrc|~/.zshenv|
|fish|~/.config/fish/[config.fish](http://config.fish)|同左|同左|

**普适做法**：变量都写到 `~/.bashrc` 或 `~/.zshrc`，并在 `~/.bash_profile` / `~/.zprofile` 里 `source ~/.bashrc`。

## 标准 HF + MS 配置块

把下面这段贴到 `~/.bashrc`（或 `~/.zshrc`）的末尾：

```bash
# ---- HuggingFace ----
export HF_ENDPOINT="https://hf-mirror.com"           # 国内默认走镜像
export HF_HOME="$HOME/.cache/huggingface"
export HF_HUB_ENABLE_HF_TRANSFER=1                   # 启用 hf_transfer 多线程
export HF_HUB_DOWNLOAD_TIMEOUT=60                    # 默认 10s 太短
# export HF_TOKEN="hf_xxxxxxxxxxxx"                  # 私有/受控模型才需要

# ---- ModelScope ----
export MODELSCOPE_CACHE="$HOME/.cache/modelscope"
export MODELSCOPE_DOMAIN="www.modelscope.cn"
# export MODELSCOPE_API_TOKEN="ms_xxxxxxxxxx"        # 仅私有模型

# ---- 通用 ----
export TRANSFORMERS_OFFLINE=0                        # 1 = 完全离线（CI/无网环境）
export TOKENIZERS_PARALLELISM=false                  # 抑制 fork 后的并行警告
```

生效：

```bash
source ~/.bashrc
# 验证
env | grep -E '^(HF_|MODELSCOPE_|TRANSFORMERS_)'
```

## systemd 服务的特殊性

如果 HF 的下载脚本要跑成 service，**systemd 不读 ~/.bashrc**。要么：

```
# /etc/systemd/system/hf-sync.service
[Service]
Environment="HF_ENDPOINT=https://hf-mirror.com"
Environment="HF_HUB_ENABLE_HF_TRANSFER=1"
EnvironmentFile=/etc/hf.env
ExecStart=/usr/local/bin/hf-sync.sh
```

或者把变量集中写到 `/etc/hf.env`：

```jsx
HF_ENDPOINT=https://hf-mirror.com
HF_HUB_ENABLE_HF_TRANSFER=1
```

## 调试技巧

- 不确定变量是否生效：`bash -lic 'env | grep HF_'`（`-l` = login，`-i` = interactive）。

- 不确定是 rc 的哪一行覆盖：`bash -x ~/.bashrc 2>&1 | grep HF_`。

- 跨 shell 共用：把变量写到 `~/.profile`（POSIX shell 兼容）并在 bash/zsh 的 rc 里 `[ -f ~/.profile ] && . ~/.profile`。

## 常见错误

- 写完不 `source` 也不开新窗口 → 看着没生效。

- 用了 `set HF_HOME=...`（CMD 语法）而非 `export HF_HOME=...` → bash 把它当成本地变量。

- 双引号里嵌入 `$HOME` 会被展开；用单引号则不展开。下载脚本里要明确。
