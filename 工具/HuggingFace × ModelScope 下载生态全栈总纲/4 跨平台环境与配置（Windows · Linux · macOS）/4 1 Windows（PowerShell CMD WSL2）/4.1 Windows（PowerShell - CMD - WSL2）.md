> Windows 是这条工具链上最容易踩坑的平台：环境变量分**用户级 / 系统级 / 进程级**三层；路径有 **MAX_PATH=260** 限制；Git LFS 的软链接在非管理员账户下会失败；WSL2 又是个并行宇宙。本节按 **PowerShell → CMD → 长路径 / 软链接 → WSL2** 四个角度梳理。

## 通用三件套（先做完再谈别的）

- 启用「开发者模式」：`Settings → Update & Security → For developers`，开启后 mklink 不再需要管理员权限。

- 启用长路径：`HKLM\SYSTEM\CurrentControlSet\Control\FileSystem\LongPathsEnabled = 1`（PowerShell：`New-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem' -Name 'LongPathsEnabled' -Value 1 -PropertyType DWORD -Force`），重启生效。

- 关闭 OneDrive 对缓存目录的接管：把 `C:\Users\<you>\.cache\huggingface` 排除出 OneDrive 同步，否则同步进程会和 LFS 锁文件互锁。
