> CMD（cmd.exe）虽然老旧但仍是脚本兼容性的最低底线。对图形党，**系统属性面板**（System Properties）是不写命令也能改环境变量的最直观入口。

## CMD 三种设置

### 临时（进程级）

```bash
set HF_ENDPOINT=https://hf-mirror.com
set HF_HOME=D:\hf-cache
set HF_HUB_ENABLE_HF_TRANSFER=1
huggingface-cli download meta-llama/Llama-3.1-8B
```

关窗口即失效。**注意** `**=**` **两边不要有空格**，CMD 会把空格当变量名一部分。

### 持久（用户级）

```bash
setx HF_ENDPOINT https://hf-mirror.com
setx HF_HOME D:\hf-cache
setx HF_HUB_ENABLE_HF_TRANSFER 1
```

`setx` 写进注册表，**当前窗口看不到改动**，需要新开 cmd。值有空格要加双引号：`setx HF_HOME "D:\my cache"`。

### 持久（系统级，需管理员）

```bash
setx /M HF_HOME D:\hf-cache
```

## 系统属性面板（GUI 路径）

1. `Win + R` → 输入 `sysdm.cpl` → 回车

1. **「高级」标签页** → 「环境变量」按钮

1. 上半部分 = **用户变量**，下半部分 = **系统变量**

1. 「新建」 → Name = `HF_ENDPOINT` / Value = `https://hf-mirror.com`

1. 找到 `Path`，**双击编辑**，可以新增一行 `%USERPROFILE%\.local\bin`（pip --user 安装的 CLI 落点）

> 🔧 修改后**所有新启动的进程**才生效。已经在跑的 VSCode / 终端不会刷新，必须退出重开。

## CMD 与 PowerShell 的差异速对

|动作|CMD|PowerShell|
|---|---|---|
|读变量|`echo %HF_HOME%`|`$env:HF_HOME`|
|设临时|`set HF_HOME=...`|`$env:HF_HOME="..."`|
|设永久|`setx HF_HOME ...`|`[Environment]::SetEnvironmentVariable(...)`|
|列全部|`set`|`Get-ChildItem env:`|

## 常见陷阱

- `setx` **最大 1024 字符**。Path 太长就拆，或者直接用面板。

- 用面板编辑 `Path` 之后，旧版 Windows 10 偶有 Path 被截断变成单行，**改完一定要展开看一遍**。

- 中文用户名（如 `C:\Users\张三`）会让某些 CLI 把 cache 写到带中文的路径，引发 Git LFS 异常。强烈建议把 `HF_HOME` 显式指到非中文盘符。
