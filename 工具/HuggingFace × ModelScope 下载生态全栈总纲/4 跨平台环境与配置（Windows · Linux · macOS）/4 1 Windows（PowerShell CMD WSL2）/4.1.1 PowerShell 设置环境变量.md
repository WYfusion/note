> PowerShell 是 Windows 10/11 上最推荐的 shell。环境变量分三层：**进程级**（仅当前会话）、**用户级**（持久，仅当前账户）、**系统级**（持久，所有账户，需管理员）。

## 三层环境变量

### 进程级（仅当前 PowerShell 会话）

```powershell
$env:HF_ENDPOINT = "https://hf-mirror.com"
$env:HF_HOME = "D:\hf-cache"
$env:HF_HUB_ENABLE_HF_TRANSFER = "1"
$env:HF_TOKEN = "hf_xxxxxxxxxxxxx"
```

关掉窗口就丢失。**适合临时调试**。

### 用户级（持久）

```powershell
[Environment]::SetEnvironmentVariable("HF_ENDPOINT", "https://hf-mirror.com", "User")
[Environment]::SetEnvironmentVariable("HF_HOME", "D:\hf-cache", "User")
[Environment]::SetEnvironmentVariable("HF_HUB_ENABLE_HF_TRANSFER", "1", "User")
[Environment]::SetEnvironmentVariable("MODELSCOPE_CACHE", "D:\ms-cache", "User")
```

新开窗口才能读到。**已开的窗口不会刷新**，必须新开。

### 系统级（需管理员）

```powershell
# 以管理员身份打开 PowerShell
[Environment]::SetEnvironmentVariable("HF_HOME", "D:\hf-cache", "Machine")
```

影响所有用户。**多人共用机器时才用**。

## 验证当前会话取到的值

```powershell
Get-ChildItem env: | Where-Object Name -match "HF_|MODELSCOPE_"
```

或单查一个：

```powershell
[Environment]::GetEnvironmentVariable("HF_ENDPOINT", "User")
```

## $PROFILE：每次启动自动加载

```powershell
# 看 profile 文件位置
$PROFILE
# 没有就建
if (!(Test-Path $PROFILE)) { New-Item -ItemType File -Path $PROFILE -Force }
# 编辑
notepad $PROFILE
```

在 `$PROFILE` 里写：

```powershell
$env:HF_ENDPOINT = "https://hf-mirror.com"
$env:HF_HUB_ENABLE_HF_TRANSFER = "1"
function hfdl { huggingface-cli download $args }
```

## 执行策略坑

首次跑脚本可能报 `running scripts is disabled`：

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

## 常见错误对照

|现象|原因|处方|
|---|---|---|
|新开窗口取不到|只设了 Process 层|用 User 层 SetEnvironmentVariable|
|VSCode 终端读不到|VSCode 在变量设置前已启动|重启 VSCode 而非仅重启终端|
|WSL 里读不到|WSL 不继承 Windows 用户变量|在 WSL 内 ~/.bashrc 单独写|
