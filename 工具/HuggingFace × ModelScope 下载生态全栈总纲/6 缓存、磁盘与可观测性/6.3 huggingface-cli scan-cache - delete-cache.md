> `huggingface-cli` 提供了 `scan-cache` / `delete-cache` 两个「缓存资产管理」主命令，是 HF 环境下唯一推荐的「顶部管理器」。手动 `rm -rf` 能删干净但会留下 refs/snapshots 对不上。

## scan-cache

```bash
huggingface-cli scan-cache
```

输出示例：

```jsx
REPO ID                              REPO TYPE   SIZE ON DISK   NB FILES   LAST_ACCESSED  LAST_MODIFIED   REFS    LOCAL PATH
-----------------------------------  ----------  ------------   --------   -------------  --------------  ------  ----------------------------------------------------------------
Qwen/Qwen2.5-7B-Instruct             model              14.8G          9    2 minutes ago   2 weeks ago    main    ~/.cache/huggingface/hub/models--Qwen--Qwen2.5-7B-Instruct
meta-llama/Llama-3.1-8B              model              16.1G          7   12 hours ago    1 month ago     main    ~/.cache/huggingface/hub/models--meta-llama--Llama-3.1-8B
bert-base-uncased                    model              440.0M         8    5 days ago     6 months ago    main    ~/.cache/huggingface/hub/models--bert-base-uncased
```

### 额外参数

- `--dir <path>`：扫描非默认 HF_HOME。

- `-v` / `--verbose`：展示每个 snapshot 与 blob。

- 到 huggingface_hub 0.20+ 还可调用 Python API：

```python
from huggingface_hub import scan_cache_dir
hf_cache_info = scan_cache_dir()
for repo in hf_cache_info.repos:
    print(repo.repo_id, repo.size_on_disk_str, len(repo.revisions))
print("Total", hf_cache_info.size_on_disk_str)
```

## delete-cache·交互式

```bash
huggingface-cli delete-cache
```

弹出一个多选列表，空格选中你要删的 commit，回车确认。它会：

- 删除选中 snapshots/<commit>

- 释放其独有的 blobs（如果被其他 snapshot 引用则保留）

- 修复 refs/、跳过锁住的文件

## delete-cache·脚本化

```python
from huggingface_hub import scan_cache_dir
info = scan_cache_dir()
strategy = info.delete_revisions(
    "abcd1234abcd1234abcd1234abcd1234abcd1234",   # commit sha
    "deadbeef..."
)
print("Will free", strategy.expected_freed_size_str)
strategy.execute()
```

## 按规则退隶例子

```python
# 删除「超过 30 天未访问且不是 main ”的所有快照
import time
from huggingface_hub import scan_cache_dir

now = time.time()
to_delete = []
for repo in scan_cache_dir().repos:
    for rev in repo.revisions:
        if rev.last_accessed and (now - rev.last_accessed.timestamp() > 30*86400) and "main" not in rev.refs:
            to_delete.append(rev.commit_hash)

if to_delete:
    strategy = scan_cache_dir().delete_revisions(*to_delete)
    print("Will free", strategy.expected_freed_size_str)
    strategy.execute()
```

## 锁文件 / 并发

- `scan-cache` 会跳过带 `.lock` 的下载中文件。

- 不要在下载进行中 `delete-cache` 同一仓库——会报 `FileLockTimeout`。

## scan-cache 看到了但加载不到？

可能原因：

- snapshots 里的 symlink 所指 blob 被别的进程删了 → `huggingface-cli scan-cache -v` 看是否 `corrupted`。

- HF_HOME 路径不同：scan-cache 默认走 `HUGGINGFACE_HUB_CACHE`，你代码里传的可能是另一个路径。

- Windows symlink 回退为拷贝，snapshot 里是普通文件，scan-cache 会警告。

## 与 ModelScope

```bash
du -sh ~/.cache/modelscope/hub/*/* | sort -h
```
