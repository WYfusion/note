> ModelScope 的缓存与 HF 类似但边界更清晰：**按 repo 目录直接在本地锻像**，不走 hash blobs + symlink。优点：贴近「纯文件」直觉；缺点：多版本不能去重。

## 默认路径

|平台|默认 MODELSCOPE_CACHE|
|---|---|
|Linux / macOS|~/.cache/modelscope|
|Windows|%USERPROFILE%.cachemodelscope|

手动指定：

```bash
export MODELSCOPE_CACHE=/data/ms-cache
```

## 完整布局

```jsx
$MODELSCOPE_CACHE/
├── hub/
│   ├── <namespace>/<repo>/             # 例如 qwen/Qwen2.5-7B-Instruct
│   │   ├── .mdl                        # 元信息
│   │   ├── .msc                        # 下载记录 / etag
│   │   ├── config.json
│   │   ├── tokenizer.json
│   │   ├── model-00001-of-00004.safetensors
│   │   └── ... (其他文件)
│   └── <namespace>/<dataset>/
├── datasets/                            # MS Datasets SDK 拉取的原文件
├── cache/                               # 临时下载区
└── modelscope/log/                      # SDK 日志
```

例子：

```jsx
~/.cache/modelscope/hub/qwen/Qwen2.5-7B-Instruct/
  ├── config.json
  ├── generation_config.json
  ├── model-00001-of-00004.safetensors
  ├── model-00002-of-00004.safetensors
  ├── model-00003-of-00004.safetensors
  ├── model-00004-of-00004.safetensors
  ├── model.safetensors.index.json
  ├── tokenizer.json
  ├── tokenizer_config.json
  └── .mdl  / .msc
```

## 与 HF 的差异速对

|维度|HuggingFace|ModelScope|
|---|---|---|
|底层布局|blobs + snapshots（CAS）|repo 目录直存|
|多版本去重|✅ 自动|❌ 多 commit 并存则文件重复|
|symlink 依赖|高（Windows 需特别配）|低，对平台心很广|
|本地路径可读性|blobs 是 hash，肃厄|目录亲切，可直接 cd|
|下载断点续|✅|✅|
|scan-cache|✅ 表格输出|❌ 需手动 du|

## 接轨 from_pretrained

代码粘到 `~/.cache/modelscope/hub/<ns>/<repo>` 路径也能 `from_pretrained`：

```python
from modelscope import AutoModelForCausalLM, AutoTokenizer
# 三种等价写法
model = AutoModelForCausalLM.from_pretrained("qwen/Qwen2.5-7B-Instruct")
# 或者
from modelscope import snapshot_download
local_dir = snapshot_download("qwen/Qwen2.5-7B-Instruct")
model = AutoModelForCausalLM.from_pretrained(local_dir)
```

混用 transformers 也可：拉下本地后，路径直接传给 `transformers.AutoModelForCausalLM.from_pretrained(local_dir)`。

## 仓库名字约定

注意 MS 的 `namespace/repo` 大小写**二者都要写准**。例：

- ✅ `qwen/Qwen2.5-7B-Instruct`

- ❌ `Qwen/qwen2.5-7b-instruct`

在大小写敏感 FS 上会报 404。
