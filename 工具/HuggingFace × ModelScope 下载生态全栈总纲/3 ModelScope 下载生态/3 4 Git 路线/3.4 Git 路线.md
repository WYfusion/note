## 0. 定位

> 一句话：MS 仓库同样是 Git + LFS 后端，克隆地址以 `https://www.modelscope.cn/` 开头。适用场景与 HF 一致：**仅在需要 git 语义时使用**。

## 1. 克隆地址模板

```bash
# 模型
git clone https://www.modelscope.cn/<owner>/<name>.git
# 例
git clone https://www.modelscope.cn/Qwen/Qwen2.5-0.5B-Instruct.git

# 数据集
git clone https://www.modelscope.cn/datasets/<owner>/<name>.git
```

## 2. 鉴权方式

MS Git 端用 **HTTPS + Personal Access Token**。个人中心 → 访问令牌页 生成。推荐在应用中走 `credential.helper store` 以免重复输入：

```bash
git config --global credential.helper store
git clone https://www.modelscope.cn/Qwen/Qwen2.5-0.5B-Instruct.git
# 首次输入用户名 / token，之后存在 ~/.git-credentials（0600）
```

## 3. LFS 与加速

与 HF 同，需 `git lfs install`。不同点是 MS Git 服务器本身在国内，带宽足够，不需额外加速。

> [!important]
> 
> **在 MS 上 Git 是「仅提交场景」选项**。下载一律走 `snapshot_download` 或 `modelscope download`。
