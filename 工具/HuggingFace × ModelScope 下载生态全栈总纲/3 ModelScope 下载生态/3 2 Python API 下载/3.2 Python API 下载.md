## 0. 定位

> 一句话：MS 的 Python API 与 HF 几乎同构，但在数据集加载上走专用类 `MsDataset.load`。本页贯穿三个入口。

## 1. 三种入口

|API|返回|场景|
|---|---|---|
|`snapshot_download(model_id)`|本地目录路径|拉模型权重|
|`MsDataset.load(dataset_name)`|Dataset 对象或下载目录|加载数据集|
|`AutoModel.from_pretrained(model_id)`|模型实例|隐式下载 + 加载|

## 2. 示例脚本

```python
# ms_python_demo.py —— 三个入口一脚本走透
from modelscope import snapshot_download
from modelscope.msdatasets import MsDataset
from modelscope import AutoTokenizer

# (1) 拉 Qwen2.5-0.5B 整仓。cache_dir 下会产生子目录 Qwen/Qwen2.5-0.5B-Instruct/
p_model = snapshot_download(
    model_id="Qwen/Qwen2.5-0.5B-Instruct",
    cache_dir="./ms_cache",
    # MS 1.10+ 支持；只要权重 + json
    allow_patterns=["*.safetensors", "*.json", "tokenizer.*"],
)
print("模型路径 →", p_model)

# (2) 加载中文小数据集
ds = MsDataset.load(
    "clue",                # 数据集 ID
    subset_name="afqmc",   # 子集名
    split="train",
)
print("训练集大小 =", len(ds))
print("首样本    =", ds[0])

# (3) AutoTokenizer.from_pretrained：隐式下载 + 加载
tok = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-0.5B-Instruct")
print("词表大小 =", tok.vocab_size)
```

## 3. `snapshot_download` 参数对照

|HF|MS|说明|
|---|---|---|
|`repo_id`|`model_id`|仓库标识|
|`local_dir`|`local_dir` (1.16+)|拷贝真文件到该目录|
|`cache_dir`|`cache_dir`|缓存根，实际路径 = cache_dir/<owner>/<name>|
|`revision`|`revision`|commit / tag / branch|
|`allow_patterns`|`allow_patterns` (1.10+)|文件过滤 glob|
|`token`|`HubApi().login(token)` 预登录|鉴权|
