## 0. 定位

> 一句话：`modelscope` 从 v1.10 起提供独立 CLI 子命令 `download`，语义与 `hf download` 高度近似，但**参数名不同**（下划线 vs 连字符）。

## 1. 主要子命令

|命令|用途|
|---|---|
|`modelscope download --model <id>`|下载模型|
|`modelscope download --dataset <id>`|下载数据集|
|`modelscope login`|交互式登录（写入 ~/.modelscope）|
|`modelscope server`|本地拉起推理 server（与下载无关）|

## 2. 最常用三句

```bash
# (1) 下载模型到指定目录
modelscope download \
  --model Qwen/Qwen2.5-0.5B-Instruct \
  --local_dir ./qwen_ms

# (2) 下载指定文件
modelscope download \
  --model Qwen/Qwen2.5-0.5B-Instruct \
  --include "*.safetensors" "tokenizer.*" "*.json" \
  --local_dir ./qwen_ms_partial

# (3) 下载数据集
modelscope download \
  --dataset modelscope/lcsts_test_set \
  --local_dir ./lcsts
```

## 3. 参数名差异提醒

> [!important]
> 
> **MS CLI 主要使用下划线**：`--local_dir` (不是 `--local-dir`)、`--cache_dir` (不是 `--cache-dir`)。习惯 HF 的人最容易踩到。

## 4. CLI 容错与重试

官方 CLI 内置了 HTTP 重试与断点续（基于 `urllib3.Retry`）。表现如下：

- 5xx / TimeoutError → 默认 5 次重试，指数退避。

- 416 (Range 不可满足) → 丢弃已下部分重拉。

- 401 / 403 → 不重试，提示 `modelscope login`。
