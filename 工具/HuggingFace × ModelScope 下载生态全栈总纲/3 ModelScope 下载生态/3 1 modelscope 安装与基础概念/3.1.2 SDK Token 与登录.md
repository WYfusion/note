## 0. 定位

> 一句话：ModelScope 的鉴权令牌叫 SDK token (`MODELSCOPE_API_TOKEN`)。与 HF 类似、但生成位置、调用接口都不一样。

## 1. 获取 token

1. 访问 <[https://modelscope.cn](https://modelscope.cn)> 点头像 > **访问令牌**。

1. 点「创建 SDK 令牌」 → 选作用域 (默认读取下载即可) → 复制。

1. token 格式为十六进制串，如 `ms-1234abcd…`。

## 2. 三种设法

```bash
# A. env 临时
export MODELSCOPE_API_TOKEN=ms-xxxx

# B. 永久
echo 'export MODELSCOPE_API_TOKEN=ms-xxxx' >> ~/.bashrc

# C. 调 CLI 交互式登入 (存到 ~/.modelscope/credentials.json)
modelscope login --token ms-xxxx
```

Python 进程内设：

```python
import os
os.environ["MODELSCOPE_API_TOKEN"] = "ms-xxxx"   # 需在 import 前
from modelscope.hub.snapshot_download import snapshot_download
```

Windows PowerShell：

```powershell
$env:MODELSCOPE_API_TOKEN = "ms-xxxx"
[System.Environment]::SetEnvironmentVariable("MODELSCOPE_API_TOKEN", "ms-xxxx", "User")
```

## 3. Python API 验证身份

```python
# verify_token.py
from modelscope.hub.api import HubApi
api = HubApi()
api.login("ms-xxxx")               # 与 env 二选一
user = api.get_user_info()
print("当前用户 =", user)
```

## 4. 拉需鉴权仓库

```python
# pull_gated.py
import os
os.environ["MODELSCOPE_API_TOKEN"] = "ms-xxxx"

from modelscope import snapshot_download
local = snapshot_download(
    "qwen/Qwen2.5-0.5B-Instruct",
    revision="master",
)
print("拉到", local)
```

CLI：

```bash
modelscope download --model qwen/Qwen2.5-0.5B-Instruct \
    --token $MODELSCOPE_API_TOKEN \
    --local_dir ./qwen
```

## 5. 用户名 / 仓库名约定

> [!important]
> 
> HF 里 'owner/name'。ModelScope 里 **「namespace/name」**：
> 
> - 个人：`user_name/repo_name`、如 `wangrongsheng/MiniGPT-4-LLM`。
> 
> - 组织：`org_name/repo_name`、如 `qwen/Qwen2.5-0.5B-Instruct`。
> 
> - 唯一区别：报错信息里会以「名人/报名」提及。

## 6. 踩过的坊

> [!important]
> 
> **1) HF「点击同意」会「同一状态跨机器生效」。ModelScope 需在网页上点击「接受」、并需 token 同主账号**。
> 
> **2)** `**MODELSCOPE_TOKEN**` **是旧名、已废弃**。请用 `MODELSCOPE_API_TOKEN`。
> 
> **3)** `**modelscope login**` **会明文写入** `**~/.modelscope/credentials.json**`。多用户机器请谨慎。
