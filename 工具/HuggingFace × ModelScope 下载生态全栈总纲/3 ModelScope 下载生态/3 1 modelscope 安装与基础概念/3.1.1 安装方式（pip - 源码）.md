## 0. 定位

> 一句话：`pip install modelscope` 是阶梯的第一步。本页梳理 Python、依赖、GPU、镜像源、中国区加速包。

## 1. 最小安装

```bash
# Linux/macOS/Windows 同例python -m pip install -U modelscope
```

会拉进的依赖：`requests` `tqdm` `urllib3` `oss2` `addict` `simplejson` `gast`。

## 2. 可选 extras

```bash
# 同时拉上三大深度学习依赖pip install "modelscope[framework]"          # numpy/scipy/sklearn
pip install "modelscope[nlp]"                # 加上 transformers / tokenizers
pip install "modelscope[cv]"                 # 加上 opencv / pillow
pip install "modelscope[audio]"              # 加上 librosa
pip install "modelscope[multi-modal]"        # 以上全部
pip install "modelscope[all]"                # 所有 extras
```

## 3. CUDA / PyTorch 组合

```bash
# 先装 PyTorch 与 CUDA 匹配的版本
pip install torch==2.4.1 torchvision==0.19.1 \
    --index-url https://download.pytorch.org/whl/cu121

# 再装 modelscope
pip install -U modelscope
```

## 4. 中国区加速包源

```bash
# 临时使用兰州理工 / 阔农 PyPI镜像
pip install -U modelscope -i https://mirrors.aliyun.com/pypi/simple
pip install -U modelscope -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久写入 ~/.pip/pip.conf
mkdir -p ~/.pip && cat > ~/.pip/pip.conf <<'EOF'
[global]
index-url = https://mirrors.aliyun.com/pypi/simple
trusted-host = mirrors.aliyun.com
EOF
```

Windows：`%APPDATA%\pip\pip.ini` 一块同。

## 5. 验证装的是哪个

```python
# verify_modelscope.py
import modelscope, sys

print("版本 =", modelscope.__version__)
print("位置 =", modelscope.__file__)
print("Python =", sys.version)

# 联网检查
from modelscope.hub.api import HubApi
api = HubApi()
print("endpoint =", api.endpoint)
# 默认 https://modelscope.cn
```

## 6. 安装后出错谱

```python
# diag.py —— 三个常见发现问题的点
import importlib, subprocess

for pkg in ["modelscope", "torch", "transformers", "oss2", "datasets"]:
    try:
        m = importlib.import_module(pkg)
        print(f"{pkg:<14} = {getattr(m, '__version__', '?')}")
    except ImportError as e:
        print(f"{pkg:<14} 未装：{e}")

# pip 上问题看一下subprocess.run(["pip", "check"])
```

## 7. 踩过的坊

> [!important]
> 
> **1)** `**modelscope**` **与** `**transformers**` **版本冲突** — modelscope 会锁较低的 transformers 上限，升级时请看 release notes。
> 
> **2) Apple Silicon 报** `**oss2**` **C 扩展** — `pip install --upgrade pyopenssl`。
> 
> **3) Conda 环境里装后 import 报** `**protobuf incompatible**` — 卸载 Conda 里的 protobuf、走 pip 过装。
