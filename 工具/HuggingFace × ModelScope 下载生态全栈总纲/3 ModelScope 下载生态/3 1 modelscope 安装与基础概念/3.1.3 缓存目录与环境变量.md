## 0. 定位

> 一句话：ModelScope 缓存与 HF 结构类似，但默认位于 `~/.cache/modelscope/hub/`，是「仓库名映射」而非「哈希寻址」。

## 1. 默认位置与结构

```jsx
~/.cache/modelscope/
├── hub/
│   ├── qwen/                     # namespace
│   │   ├── Qwen2.5-0.5B-Instruct/  # repo_name
│   │   │   ├── config.json
│   │   │   ├── model.safetensors
│   │   │   ├── tokenizer.json
│   │   │   └── …
│   └── modelscope/
│       └── …
└── datasets/
    └── …                          # 数据集缓存
```

> [!important]
> 
> 与 HF `models--owner--name/snapshots/<hash>/` 不同，ModelScope 直接以 `namespace/repo_name/` 作为目录名。
> 
> 优点：可读、可手改、手动拷贝快。
> 
> 缺点：多个 revision 会互盖，不能同机保留两份。

## 2. 重定向缓存

```bash
# 临时
export MODELSCOPE_CACHE=/data/modelscope_cache

# Linux/macOS 永久
echo 'export MODELSCOPE_CACHE=/data/modelscope_cache' >> ~/.bashrc

# Windows PowerShell
[System.Environment]::SetEnvironmentVariable("MODELSCOPE_CACHE", "D:\modelscope_cache", "User")
```

Python：

```python
import os
os.environ["MODELSCOPE_CACHE"] = "/data/modelscope_cache"

from modelscope import snapshot_download
local = snapshot_download("qwen/Qwen2.5-0.5B-Instruct")
print(local)
# /data/modelscope_cache/hub/qwen/Qwen2.5-0.5B-Instruct
```

## 3. 检查缓存现状

```python
# cache_stat.py —— 查看仓库与占用
import os
from pathlib import Path

base = Path(os.environ.get("MODELSCOPE_CACHE",
    Path.home() / ".cache" / "modelscope")) / "hub"

total = 0
for namespace_dir in sorted(base.iterdir()):
    for repo_dir in namespace_dir.iterdir():
        size = sum(f.stat().st_size for f in repo_dir.rglob("*") if f.is_file())
        total += size
        print(f"{size/1e9:6.2f} GB  {namespace_dir.name}/{repo_dir.name}")
print("-" * 50)
print(f"总计 = {total/1e9:.2f} GB")
```

## 4. 多机器共享缓存

```bash
# NFS 场景
# 机器 A B C 同时设
export MODELSCOPE_CACHE=/mnt/nfs/modelscope_cache

# Docker / k8s
spec:
  containers:
    - env:
        - name: MODELSCOPE_CACHE
          value: /mnt/cache
      volumeMounts:
        - name: ms-cache
          mountPath: /mnt/cache
  volumes:
    - name: ms-cache
      persistentVolumeClaim:
        claimName: modelscope-shared
```

## 5. 清理与迁移

```bash
# 清某个仓库
rm -rf $MODELSCOPE_CACHE/hub/qwen/Qwen2.5-0.5B-Instruct

# 打包迁移到别机器
tar czf modelscope_cache.tar.gz -C $MODELSCOPE_CACHE .
rsync -avh modelscope_cache.tar.gz user@host:/data/

# 几个变量同时生效、优先级为：函数参数 > env MODELSCOPE_CACHE > 默认 ~/.cache/modelscope
```

## 6. 与 HF 缓存并存的布局

```bash
# 拼一个共用父目录
export HF_HOME=/data/.cache/huggingface
export MODELSCOPE_CACHE=/data/.cache/modelscope

ls /data/.cache/
# huggingface  modelscope
```

二者互不干扰、同权重会被拉两次（那是仓库名不同造成）。

## 7. 踩过的坊

> [!important]
> 
> **1) 拷缓存后需保留** `**.mdl**` `**.msc**` **隐藏文件** — SDK 依赖这些判断 revision。
> 
> **2) Windows 上** `**MODELSCOPE_CACHE**` **路径含空格会 500** — 需加引号、推荐用不含空格路径。
> 
> **3) NFS 上多机同时拉会产生文件锁冲突** — 推荐「在一个机器上拉、其他机器只读」。
