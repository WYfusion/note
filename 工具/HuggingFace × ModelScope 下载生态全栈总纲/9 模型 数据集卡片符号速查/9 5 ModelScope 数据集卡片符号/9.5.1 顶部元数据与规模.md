> ModelScope 数据集页头部带「下载 / 喜欢 / 大小 / 样本数 / 更新时间」五个热度徽标，与模型侧大致一致，但多了 `样本数` `子集` 两个专属字段。

## 0. 定位

本节讲清 ModelScope 数据集的热度徽标、规模表达、子集徽标、以及与 HF size_categories 的映射。

## 1. 顶部元数据徽标

|徽标|含义|API 字段|
|---|---|---|
|下载|累计下载数（samples + files）|downloads|
|喜欢|点赞|likes|
|大小|总体积（压缩后）|storage|
|样本数|总记录数|record_count|
|更新时间|最后提交|updated_time|

## 2. 规模胶囊表达

MS 最近推出了与 HF size_categories 相近的**胶囊化表达**，但中文化：

|胶囊|含义|对应 HF|
|---|---|---|
|微型|&lt; 1K|n&lt;1K|
|小型|1K–10K|1K&lt;n&lt;10K|
|中型|10K–1M|10K&lt;n&lt;100K / 100K&lt;n&lt;1M|
|大型|1M–10M|1M&lt;n&lt;10M|
|超大|≥ 10M|10M&lt;n&lt;100M+|

## 3. API 读取

```python
import requests
r = requests.get(
    "https://www.modelscope.cn/api/v1/datasets/modelscope/chinese-fineweb-edu/info"
).json()
print(r["Data"]["DatasetCard"]["Storage"])      # 体积
print(r["Data"]["DatasetCard"]["RecordCount"])  # 样本数
```

## 4. 子集徽标

与 HF `configuration` 同义，是一个数据集下的多个「变体」（例如语言 / 任务 / 采样量）。模型页中会列出胶囊：

```python
from modelscope.msdatasets import MsDataset
ds = MsDataset.load("modelscope/chinese-fineweb-edu",
                    subset_name="sample-10BT",
                    split="train")
print(ds)
```

未指定 `subset_name` 时默认取首个。

## 5. streaming 模式

MS datasets >= 1.16 后支持与 HF 类似的 streaming：

```python
ds = MsDataset.load("modelscope/chinese-fineweb-edu",
                    subset_name="sample-10BT",
                    split="train",
                    use_streaming=True)
for i, ex in enumerate(ds):
    if i >= 3: break
    print(ex["text"][:80])
```

## 6. 推理本地磁盘

```python
from modelscope.msdatasets import MsDataset
b = MsDataset.load("modelscope/clue", subset_name="afqmc")
print(b.builder.info.dataset_size // 1024**2, "MB cached")
print(b.builder.info.download_size // 1024**2, "MB raw")
```

## 7. 与 HF `datasets` 互操

MS 上的数据集能被 `datasets` 加载吗？**不能直接**。两者 backend 不互通，需先下本地再 `load_dataset("path/to/local")`。
