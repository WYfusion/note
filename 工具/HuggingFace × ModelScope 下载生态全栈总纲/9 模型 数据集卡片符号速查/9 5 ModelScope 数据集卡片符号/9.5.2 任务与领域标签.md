## 0. 定位

本节补充 ModelScope 数据集独有的子标签、URL 筛选、常见数据集举例。

## 1. 与模型侧同词典

领域 / 任务 枚举参见 [[9.4.2 领域与任务标签]]。数据集上 `tasks` 表示「该数据集适用于哪些任务」。

## 2. 数据集独有子标签

|标签|含义|典型数据集|
|---|---|---|
|预训练|pretrain corpus|modelscope/chinese-fineweb-edu|
|SFT|指令微调|swift/COIG-CQIA-full|
|偏好对齐 / DPO / RLHF|偏好对|opencompass/UltraFeedback|
|评测|benchmark|opencompass/C-Eval|
|多轮对话|multi-turn|damo/MS-Bench|
|代码|code corpus|codefuse-ai/...|
|数学|math|OpenAI/gsm8k 镜像|
|Agent|tool-use|damo/MS-Agent-Bench|
|OCR|OCR 专用|damo/ocr_recognition…|
|护栏 / 红队|安全数据|damo/safety-prompts|

## 3. URL 筛选

```jsx
https://modelscope.cn/datasets?domain=nlp&tasks=text-generation
https://modelscope.cn/datasets?tags=SFT
https://modelscope.cn/datasets?tags=偏好对齐
```

## 4. 词典差异提醒

同一个概念在两站可能不同词：

|ModelScope|HuggingFace|
|---|---|
|预训练 / pretrain|task_categories: text-generation|
|SFT|task_categories: text-generation 下 `instruction-tuning` tag|
|偏好对齐|tag: rlhf / dpo|
|评测|tag: evaluation|
|多轮对话|task_ids: dialogue-generation|

## 6. API 拼接查询

```python
import requests
r = requests.post(
    "https://www.modelscope.cn/api/v1/dolphin/datasets",
    json={"PageSize": 20, "SortBy": "Downloads",
          "Domain": "nlp", "Tasks": ["text-generation"],
          "Tags": ["SFT", "中文"]}
).json()
for d in r["Data"]["Datasets"]:
    print(d["Path"], d["Downloads"], d.get("Tags"))
```
