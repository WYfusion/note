## 0. 定位

本节讲清 ModelScope 数据集的格式徽标、预览能力、streaming 支持、与 HF 的区别。

## 1. 格式徽标全表

|胶囊|真实文件|streaming|在线预览|典型场景|
|---|---|---|---|---|
|parquet|`*.parquet`|✅|✅|2024+ MS 推荐默认|
|arrow|`*.arrow`|✅|部分|与 datasets cache 互通|
|json / jsonl|`*.json` / `*.jsonl`|✅|✅|SFT / 对话|
|csv|`*.csv`|✅|✅|表格|
|text|`*.txt`|✅|✅|预训练语料|
|自定义脚本|`*.py` builder|取决作者|多数❌|早期数据集|
|tar / zip|压缩包|需解压|❌|图像 / 音频 / OCR|
|多模态 ROOT|目录结构 + meta.csv|限制|部分|OCR / VQA|

## 2. 在线预览体验

默认 ModelScope 对以下格式可在线预览：

- parquet/arrow/json/csv：默认展示前 100 行 + 字段检查。

- 图像 / 音频：提供缩略图 + 试听。

- 文本量大时（>2GB 单文件）：仅预览 schema。

## 4. streaming 与 HF 的差异

```python
from modelscope.msdatasets import MsDataset
ds = MsDataset.load("modelscope/chinese-fineweb-edu",
                    subset_name="sample-10BT",
                    split="train",
                    use_streaming=True)
```

- MS streaming 后端使用 OSS 的范围分片请求；与 HF 类似。

- MS 的 `use_streaming=True` 后返回 `IterableDataset`，不能 `len()`、不能 `shuffle(seed)` 随机访问。

## 5. 与 datasets 互操

MS 提供了 `to_hf_dataset` 转接：

```python
from modelscope.msdatasets import MsDataset
from datasets import Dataset

ms_ds = MsDataset.load("swift/COIG-CQIA-full", split="train")
hf_ds = ms_ds.to_hf_dataset()
print(type(hf_ds), hf_ds.column_names)
```

## 6. 上传自制数据集的格式建议

- 首选 parquet（默认 100MB 分片）。

- 多个 split（train/dev/test）放在各自子目录。

- README 在 frontmatter 填「任务 + 样本数 + license」。
