> 数据集卡片右下角的 `parquet · 12 files · 4.2 GB` 这类小字徽标，决定了你能否用 `load_dataset(..., streaming=True)`、能否被 datasets-server 自动预览。

## 0. 定位

本节把 HF 上 7 类常见格式的徽标讲清，并给出每种格式对应的下载/加载/预览特性。

## 1. 格式徽标全表

|徽标|真实文件|streaming|HF Viewer 预览|典型用途|
|---|---|---|---|---|
|parquet|`*.parquet`|✅ 高效|✅|HF 推荐默认|
|arrow|`*.arrow`|✅|✅|本地已 prepare 后的 cache|
|json|`*.jsonl` / `*.json`|✅|✅|小数据集 / 调试|
|csv|`*.csv` / `*.tsv`|✅|✅|表格数据|
|text|`*.txt`|✅|✅|纯文本语料|
|webdataset|`*.tar` 分片|✅|部分|大规模多模态|
|imagefolder / audiofolder|目录结构 + 元数据|有限|✅|分类任务|
|script|`<dataset>.py` 自定义|取决脚本|多数❌|2024+ 已弃用|

## 2. parquet：HF 的「金标准」

2024 起 HF 强烈推荐 parquet。理由：

- **列式存储**：只读特定列时 IO 仅一小部分。

- **分片天然**：默认 ~500 MB/file，配合 streaming 极快。

- **被 datasets-server 自动转换**：即使作者上传的是 csv，HF 后端也会自动转 parquet 缓存供 Viewer / streaming。

streaming 示例：

```python
from datasets import load_dataset
ds = load_dataset("HuggingFaceFW/fineweb", "sample-10BT", split="train", streaming=True)
first = next(iter(ds))
print(first.keys())  # ['text', 'id', 'url', ...]
```

## 3. webdataset：大规模多模态首选

```jsx
LAION-5B/laion2B-en/00000.tar
├─ 00000001.jpg
├─ 00000001.txt
├─ 00000001.json
├─ 00000002.jpg
...
```

下载 + 加载：

```bash
huggingface-cli download laion/laion2B-en --repo-type dataset --include "*.tar" --local-dir ./data
```

```python
import webdataset as wds
ds = wds.WebDataset("./data/{00000..00100}.tar").decode("pil").to_tuple("jpg", "txt")
for img, txt in ds:
    ...
```

## 4. imagefolder / audiofolder

目录结构隐含 label：

```jsx
food101/
├─ apple_pie/
│   ├─ 0001.jpg
│   └─ ...
├─ baby_back_ribs/
│   └─ ...
```

```python
from datasets import load_dataset
ds = load_dataset("imagefolder", data_dir="./food101")
print(ds["train"].features)  # {'image': Image(...), 'label': ClassLabel(...)}
```

## 5. script 数据集（旧）

HF 在 2024 起逐步禁用「带 `<dataset>.py` 脚本」的数据集（安全考虑）。如果看到旧数据带 script 徽标：

```python
ds = load_dataset("old-dataset", trust_remote_code=True)
```

但**最佳**实践是查作者是否已提供 parquet 镜像（HF 自动转换的版本通常在 `refs/convert/parquet` 分支）：

```python
from datasets import load_dataset
ds = load_dataset("old-dataset", revision="refs/convert/parquet")
```

## 6. 文件 explorer 里的特殊徽标

在数据集的 Files & versions 标签下，每个 `*.parquet` / `*.arrow` 文件旁边会显示一枚小尺度数字（如 `4.2 GB`、`120,432 rows`）—— 这是 HF Viewer 解析 parquet header 得到的样本数与字节数，**不消耗你的本地资源**。

## 7. 下载 + 预览

```python
from huggingface_hub import snapshot_download

# 只取 parquet（跳过原始压缩包）
snapshot_download(
    "HuggingFaceFW/fineweb", repo_type="dataset",
    allow_patterns=["sample-10BT/*.parquet"],
    local_dir="./fineweb-sample"
)
```
