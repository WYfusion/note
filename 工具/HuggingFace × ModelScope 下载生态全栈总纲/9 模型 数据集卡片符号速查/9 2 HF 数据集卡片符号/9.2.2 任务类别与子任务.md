> 数据集卡片左上的 `Text Classification · Question Answering · Summarization` 这类徽标来自 `task_categories` 与 `task_ids`，决定了它在 `?task_categories=...` 筛选器里的归属。

## 0. 定位

本节列全 HF 数据集 task_categories 枚举，并展示如何用筛选器精确定位「NLP / CV / 多模态评测集」。

## 1. 两层结构

```yaml
task_categories:        # 大类（决定主徽标）
  - text-classification
task_ids:               # 小类（决定二级徽标）
  - sentiment-classification
  - intent-classification
```

task_categories 与模型侧的 `pipeline_tag` 词典**部分重合但不完全相同**——模型用 `text-generation`，数据集用 `text-generation`/`text2text-generation`；模型用 `image-text-to-text`，数据集用 `visual-question-answering` 居多。

## 3. URL 筛选模板

```jsx
# 中文情感分类
https://huggingface.co/datasets?task_categories=text-classification&language=zh

# 中文翻译
https://huggingface.co/datasets?task_categories=translation&language=zh

# 大规模预训练（语言建模）
https://huggingface.co/datasets?task_categories=text-generation&size_categories=10B<n<100B

# 多模态 VQA
https://huggingface.co/datasets?task_categories=visual-question-answering
```

## 4. API 列表

```python
from huggingface_hub import HfApi
for d in HfApi().list_datasets(filter="task_categories:text-classification",
                                language="zh", sort="downloads",
                                direction=-1, limit=10):
    print(d.id, d.downloads)
```

## 5. 阅读卡片的 4 个关键

看到一个新数据集，按以下顺序确认：

1. `task_categories` —— 这数据是不是我要的任务

1. `size_categories` —— 我能不能存

1. `language` —— 语种对不对

1. `license` —— 是否能商用（同 9.1.4）

## 6. 自检

```python
import yaml, pathlib
meta = yaml.safe_load(pathlib.Path("README.md").read_text().split("---")[1])
for k in ["task_categories", "size_categories", "language", "license"]:
    assert k in meta, f"缺 {k}"
print("OK")
```
