> ModelScope 模型页的顶部会看到：`下载 1.2M · 喜欢 5.3k · 评论 234 · 收藏 1.8k · 最近更新 5 天前 · 🔥推荐`。与 HF 对比，多了 `评论` `收藏` `推荐` 三个中国社区特色字段。

## 0. 定位

本节讲清 ModelScope 顶部 7 个热度徽标的含义、统计口径、以及从 API 里如何读出。

## 1. 热度徽标全表

|徽标|含义|API 字段|统计口径|
|---|---|---|---|
|下载|贯穿统计的下载次数|downloads|**历史累计**（与 HF 的 30 天不同）|
|喜欢|点赞数|likes / stars|累计|
|评论|评论数|comments|累计|
|收藏|收藏数（类似 book）|favorites|累计|
|最近更新|最后 commit 时间|updated_time|任意文件改动都算|
|🔥热门|7 天下载增量进前 5%|is_hot|后端算法|
|⭐推荐|官方运营筛选|is_recommended|人工打标|

## 2. 与 HF downloads 的口径差异

- **HF**：过去 30 天 successful API 下载。

- **MS**：历史累计 successful 下载（含 SDK / git / curl）。

同一个模型常见「MS 数字是 HF 数字的 30–7×」，不是因为频率高，是统计窗口不同。不要直接拿两站数字叠加。

## 3. API 读取

```python
from modelscope.hub.api import HubApi
api = HubApi()
info = api.get_model("qwen/Qwen2.5-7B-Instruct")
print(info)
# {'Name': '...', 'Path': '...', 'Description': '...', 'Visibility': 5, 'License': 'apache-2.0', ...}
```

`Visibility` 的枚举：1 = 私有，5 = 公开。

热度指标需走 REST API：

```python
import requests
r = requests.get("https://www.modelscope.cn/api/v1/models/qwen/Qwen2.5-7B-Instruct").json()
d = r["Data"]
print(d["Downloads"], d["Stars"], d["Comments"], d.get("Recommended"))
```

## 4. 「推荐 / 热门 / 首页」三个位置的差别

- **推荐**：运营手动选择，出现在首页 hero 位。

- **热门**：后端算法按「最近 7 天下载增量」筛。

- **首页·最新**：纯按 updated_time 倒序。

选型时优先看「热门 + 下载超 10w」避免遇上个人玩具项目。

## 5. 筛选 URL

```jsx
https://modelscope.cn/models?sort=Default      # 默认推荐
https://modelscope.cn/models?sort=Downloads    # 按下载
https://modelscope.cn/models?sort=Stars
https://modelscope.cn/models?sort=GmtModified  # 最近更新
```

## 6. 常见需求脚本

```python
import requests
def trending_zh_text_gen(limit=10):
    r = requests.post(
        "https://www.modelscope.cn/api/v1/dolphin/models",
        json={"PageSize": limit, "SortBy": "Downloads",
              "Tasks": ["text-generation"], "Tags": ["Chinese"]}
    ).json()
    for m in r["Data"]["Model"]["Models"]:
        print(m["Path"], m["Downloads"])
trending_zh_text_gen()
```
