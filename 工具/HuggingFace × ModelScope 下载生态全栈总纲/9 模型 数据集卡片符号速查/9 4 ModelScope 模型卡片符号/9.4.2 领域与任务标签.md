> ModelScope 模型卡片的「领域」与「任务」两级标签是**中文词汇**，与 HF 的 pipeline_tag 不是一一对应。本节提供完整对照。

## 0. 定位

本节讲清 ModelScope 的「领域 / 二级任务」枚举、与 HF pipeline_tag 的映射、URL 筛选参数。

## 1. 一级「领域」

|中文名|API tasks 前缀|HF 大致对应|
|---|---|---|
|自然语言处理|nlp / 文本生成类|text-generation, text-classification…|
|计算机视觉|cv|image-classification, object-detection…|
|语音|audio|automatic-speech-recognition, text-to-speech…|
|多模态|multi-modal|image-text-to-text, visual-question-answering…|
|科学计算|science|生物医药 / 化学|
|AIGC|aigc|text-to-image / text-to-video|
|其他|other|表格 / RL|

## 2. 二级任务枚举（主要领域）

### NLP

- text-generation（文本生成 / 会话）

- text-classification

- token-classification

- nli / paraphrase / similarity

- question-answering

- summarization

- translation

- information-extraction

- text-ranking

- text-embedding

### CV

- image-classification

- object-detection

- image-segmentation

- ocr / table-recognition

- image-to-image

- image-captioning

- face-recognition

- pose-estimation

### Audio

- speech-recognition / automatic-speech-recognition

- speech-synthesis / text-to-speech

- audio-classification

- voice-activity-detection

- speaker-verification

### Multimodal

- visual-question-answering

- image-text-retrieval

- text-to-video-synthesis

- multi-modal-embedding

### AIGC

- text-to-image-synthesis

- image-to-image-generation

- text-to-video-generation

- text-to-speech-generation

- text-to-3d

## 3. URL 筛选

```jsx
https://modelscope.cn/models?tasks=text-generation
https://modelscope.cn/models?domain=nlp&tasks=text-generation
https://modelscope.cn/models?domain=aigc&tasks=text-to-image-synthesis
```

两者可叠加，且同类可多选（采 OR 语义）。

## 4. API

```python
from modelscope import snapshot_download
import requests

r = requests.post(
    "https://www.modelscope.cn/api/v1/dolphin/models",
    json={"PageSize": 20, "SortBy": "Downloads",
          "Domain": "nlp", "Tasks": ["text-generation"]}
).json()
for m in r["Data"]["Model"]["Models"]:
    print(m["Path"], m["Downloads"], m.get("Tasks"))
```

## 5. 特色子标签

ModelScope 在任务下面还有**中文场景标签**，例如：

- text-generation 下：`会话` `代码` `数学` `函数调用` `Agent`

- text-to-image 下：`中文描述` `动漫风` `写实` `设计`

- ASR 下：`中文普通话` `粵语` `多语种`

这些标签仅限 ModelScope，HF 上可能需要用 `?other=chinese` 近似。
