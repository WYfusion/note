> Spaces 卡片左上有一枚 SDK 徽标：`Gradio` / `Streamlit` / `Static` / `Docker`。这决定了它的运行方式与你 fork 后能改的内容。

## 0. 定位

本节把 4 类 Space SDK 讲清，并给出每种 SDK 的入口文件、本地复现命令、克隆模板。

## 1. 四类 SDK 对照

|SDK|入口文件|frontmatter|本地运行|
|---|---|---|---|
|Gradio|`app.py`|`sdk: gradio`|`python app.py`|
|Streamlit|`app.py`|`sdk: streamlit`|`streamlit run app.py`|
|Static|`index.html` • 资源|`sdk: static`|任意静态服务器|
|Docker|`Dockerfile`|`sdk: docker`|`docker build .` • `docker run`|

[README.md](http://README.md) frontmatter 示例：

```yaml
---
title: My Chat Demo
emoji: 🤖
sdk: gradio
sdk_version: 4.44.0
app_file: app.py
pinned: false
---
```

## 2. Gradio Space 复现

```bash
git clone https://hf-mirror.com/spaces/ysharma/Chat-with-Llama-3-8b
cd Chat-with-Llama-3-8b
pip install -r requirements.txt
python app.py
# 自动启动 http://127.0.0.1:7860
```

常见坑：

- `sdk_version` 与你本地 gradio 不一致：用 `pip install gradio==4.44.0`。

- Space 用了 ZeroGPU（@spaces.GPU）：本地无 ZeroGPU 环境，把装饰器删去即可。

## 3. Streamlit Space

```bash
git clone https://hf-mirror.com/spaces/<user>/<space>
cd <space>
pip install -r requirements.txt
streamlit run app.py --server.port 8501
```

## 4. Static Space

本质是 HF 给你 host 一个静态站。fork 后改 `index.html` 即可。常见用途：transformers.js demo / Gradio Lite 浏览器内推理。

```bash
git clone https://hf-mirror.com/spaces/Xenova/whisper-web
cd whisper-web
python -m http.server 8000
# 访问 http://localhost:8000
```

## 5. Docker Space

企业级最常用。Dockerfile 必须满足：

- 监听 `7860` 端口（HF 默认）

- 以 `user: 1000` 运行

```docker
FROM python:3.11-slim

RUN useradd -m -u 1000 user
USER user
ENV PATH="/home/user/.local/bin:$PATH"

WORKDIR /app
COPY --chown=user requirements.txt .
RUN pip install -r requirements.txt
COPY --chown=user . .

CMD ["python", "app.py"]
EXPOSE 7860
```

本地：

```bash
docker build -t myspace .
docker run -p 7860:7860 myspace
```

## 6. SDK 筛选 URL

```jsx
https://huggingface.co/spaces?sdk=gradio&sort=likes
https://huggingface.co/spaces?sdk=docker
```

## 7. API 端

```python
from huggingface_hub import HfApi
for s in HfApi().list_spaces(filter="sdk:gradio", sort="likes",
                              direction=-1, limit=10):
    print(s.id, s.likes)
```

## 8. 「duplicate」按钮

所有 Space 顶部都有一个「⤴ Duplicate this Space」按钮。点击后 HF 会**复制全部代码 + Dockerfile + 配置**到你账号下，但**不会**复制硬件钱包——你需要自己挂硬件（见 [[9.3.2 硬件徽标]]）。
