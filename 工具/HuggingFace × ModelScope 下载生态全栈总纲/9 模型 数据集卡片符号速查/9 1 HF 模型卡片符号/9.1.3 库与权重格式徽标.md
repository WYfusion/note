> 模型名下方一排灰色胶囊 `Transformers · Safetensors · GGUF · 8 languages · llama · text-generation-inference` 就是「库与权重格式徽标」。它决定了**你能用哪个推理框架去加载这份权重**。

## 0. 定位

本节把 HF 上 12 类常见徽标按「推理库 / 权重格式 / 配套工具」分类，给出每一种**徽标 ↔ 加载代码 ↔ 显存峰值**的对照。

## 1. 推理库徽标

|徽标|含义|加载代码|
|---|---|---|
|Transformers|HF transformers 库可直接加载|`AutoModel.from_pretrained(...)`|
|Diffusers|HF diffusers 库（扩散模型专用）|`StableDiffusionPipeline.from_pretrained(...)`|
|Sentence Transformers|嵌入模型专用封装|`SentenceTransformer(...)`|
|PEFT|这是一个 LoRA / Adapter 而非完整权重|`PeftModel.from_pretrained(base, ...)`|
|timm|视觉模型 timm 库|`timm.create_model(...)`|
|TF|原生 TensorFlow / Keras 权重|`TFAutoModel.from_pretrained(...)`|
|JAX|Flax/JAX 权重|`FlaxAutoModel.from_pretrained(...)`|
|MLX|Apple Silicon 专用 mlx 框架|`mlx_lm.load(...)`|
|ONNX|ONNX 中间表示|`onnxruntime.InferenceSession(...)`|
|TensorRT-LLM|NVIDIA 编译过的引擎|tensorrt_llm.runtime|
|vLLM|已通过 vLLM 兼容性测试|`vllm.LLM(model=...)`|
|text-generation-inference|HF TGI 服务化推理|`text-generation-launcher --model-id ...`|

## 2. 权重格式徽标

|徽标|含义|文件后缀|加载注意|
|---|---|---|---|
|Safetensors|HF 推的安全张量格式（默认）|`.safetensors`|零反序列化攻击面，推荐|
|PyTorch|传统 `pytorch_model.bin`（pickle）|`.bin`|`from_pretrained` 默认仍能加载；`weights_only=True` 仅 safetensors 支持|
|GGUF|llama.cpp / Ollama 用的量化打包|`.gguf`|用 llama-cpp-python 或 Ollama 加载，**不能** transformers 直接吃|
|GGML|GGUF 的前身（已弃用）|`.ggml`/`.bin`|转 GGUF 再用|
|AWQ|权重 4bit 量化 (Activation-aware)|`.safetensors`|需 `autoawq`|
|GPTQ|权重 4bit/8bit 量化 (post-training)|`.safetensors`|需 `auto-gptq` / `optimum`|
|EXL2|ExLlamaV2 量化|`.safetensors`|需 exllamav2|
|MLX-quantized|Apple MLX 4bit/8bit 量化|`.safetensors`|需 mlx_lm|

## 3. 不同徽标的下载体积差异

以 Llama-3-8B 为例：

```jsx
safetensors fp16:  ~16 GB
GGUF Q4_K_M:        ~4.8 GB
AWQ 4bit:           ~5.7 GB
GPTQ 4bit:          ~5.4 GB
MLX 4bit:           ~5.1 GB
```

## 4. 加载代码速查

```python
# safetensors fp16
from transformers import AutoModelForCausalLM
m = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.1-8B",
                                          torch_dtype="auto", device_map="auto")

# GGUF
from llama_cpp import Llama
m = Llama(model_path="./llama3-8b.Q4_K_M.gguf", n_gpu_layers=-1)

# AWQ
from transformers import AutoModelForCausalLM
m = AutoModelForCausalLM.from_pretrained("casperhansen/llama-3-8b-instruct-awq",
                                          device_map="auto")
# 注意：transformers 4.45+ 内置 AWQ；老版本要 import awq

# GPTQ
from transformers import AutoModelForCausalLM
m = AutoModelForCausalLM.from_pretrained("TheBloke/Llama-3-8B-Instruct-GPTQ",
                                          device_map="auto")

# MLX (mac)
from mlx_lm import load, generate
m, tok = load("mlx-community/Meta-Llama-3.1-8B-Instruct-4bit")
```

## 5. 怎么在 URL 里筛

```jsx
https://huggingface.co/models?library=gguf&sort=downloads
https://huggingface.co/models?other=AWQ&sort=downloads
```

注意：`library` 是「主推理库」字段，`other` 才能筛量化方案。

## 6. 同一仓库有多种格式

现代社区作者经常**在同一个 repo 里放多套权重**：

```jsx
Qwen/Qwen2.5-7B-Instruct
├─ model-00001-of-00004.safetensors   # fp16
├─ qwen2.5-7b-instruct-q4_k_m.gguf    # 量化（可选）
```

用 `allow_patterns` 仅下你要的：

```python
from huggingface_hub import snapshot_download
snapshot_download("Qwen/Qwen2.5-7B-Instruct",
                  allow_patterns=["*.safetensors", "*.json", "tokenizer*"])
```
