> 模型页头部的 `License: apache-2.0`、上面常有 🔒「This model is gated» 横幅，决定了你是否能**直接下载**、能否**商用**、是否需要点击同意条款。

## 0. 定位

本节梳理 HF 模型的 6 类访问/许可徽标，把每一类对应的下载阻塞点与解锁方法讲清。

## 1. 访问性等级（从开放到封闭）

|等级|页面表现|API 表现|下载是否需要登录|
|---|---|---|---|
|Public|无横幅|repo_info 直接返回|否（匿名可下）|
|Gated · auto|黄色横幅「click to access」|403 直到点同意|需要登录 + 点击同意|
|Gated · manual|黄色横幅「request access」|403 直到作者审批|登录 + 等审批|
|Private|🔒 仅自己可见|404（除非 token 匹配）|必须用 owner 的 token|
|Disabled|红色横幅「disabled by author」|404|不能下|
|DMCA Taken Down|红色横幅|451|不能下|

## 2. 怎么获取 gated 模型

**步骤**：

1. 登录 HF 账号。

1. 打开模型页，看到 banner「You need to share your contact information to access this model」。

1. 填表 → submit。`auto` 型一秒通过；`manual` 型由作者审。

1. 通过后页面 banner 变绿「You have been granted access」。

1. 本地 `huggingface-cli login` 登录同一账号 → `snapshot_download(...)` 立即可下。

常见 gated 库：`meta-llama/*`、`mistralai/Mistral-Large-*`、`google/gemma-*`、部分 `stabilityai/*`。

**用 API 检测**：

```python
from huggingface_hub import HfApi
from huggingface_hub.utils import GatedRepoError
try:
    HfApi().repo_info("meta-llama/Llama-3.1-8B")
    print("OK")
except GatedRepoError as e:
    print("GATED：", e)
```

## 3. 常见 License 取值

|license 字段|可商用|是否需署名 / 共享|额外条款|
|---|---|---|---|
|apache-2.0|✅|署名|专利授权友好|
|mit|✅|署名|最宽松|
|bsd-3-clause|✅|署名|不可用作者名背书|
|cc-by-4.0|✅|署名|—|
|cc-by-sa-4.0|✅|署名 + 同样许可|派生品必须同协议|
|cc-by-nc-4.0|❌|署名|非商用|
|cc-by-nc-sa-4.0|❌|署名 + 同许可|非商用 + 同协议|

|llama2 / llama3 / llama3.1 / llama3.2 / llama3.3|✅（&lt; 7 亿月活）|署名 + 标注 Llama|700M MAU 上限；不可训练他家模型|

|mistral-research-license|❌（仅研究）|—|商用需联系 Mistral|
|qwen / qwen-research / tongyi-qianwen|视版本|—|详见后文|
|other / unknown|—|—|必须读 LICENSE 文件|

## 4. 中文社区高频「特别协议」

- **通义千问协议（Qwen / Qwen2.5）**：72B 以下可商用免费，72B 含起需到阿里云申请商业授权。

- **DeepSeek License**：商用免费 + 输出署名 + 不可与原作者竞争 (V3 起)。

- **InternLM License**：免费但需邮件登记商业使用情况。

- **ChatGLM3-6B License**：免费 + 提交申请表（[https://open.bigmodel.cn](https://open.bigmodel.cn)）。

## 5. License 字段从 API 取

```python
from huggingface_hub import HfApi
for m in HfApi().list_models(filter="text-generation", license="apache-2.0",
                              sort="downloads", limit=10):
    print(m.modelId, m.cardData and m.cardData.get("license"))
```

## 6. URL 筛选写法

```jsx
https://huggingface.co/models?license=apache-2.0&pipeline_tag=text-generation
https://huggingface.co/models?license=cc-by-nc-4.0   # 排除商业项目
```

## 7. 企业合规四问

下载前问：

1. license 是否允许商用？

1. 是否需要署名 / 共享 / 注册？

1. 是否包含 EU AI Act 适用条款？

1. **训练数据集 license** 是否也允许商用？许多模型 weight 是 Apache-2.0，但训练集是 NC（如 LAION），实务上仍受争议。
