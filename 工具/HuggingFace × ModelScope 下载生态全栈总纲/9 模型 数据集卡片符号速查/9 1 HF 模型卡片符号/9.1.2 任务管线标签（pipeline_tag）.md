## 2. 颜色编码

HF 网页 CSS 把 pipeline_tag 按 7 类涂色：

- 文本类：橙色

- 视觉类：青绿

- 音频类：紫色

- 多模态：粉红

- 表格：浅蓝

- 强化学习：黄色

- 其它：灰色

## 3. 在筛选器里使用

URL 模板：

```jsx
https://huggingface.co/models?pipeline_tag=text-generation&sort=downloads
```

多个标签**不可叠加 pipeline_tag**（每个模型只有一个），但可以叠 `library` / `language` / `license`，见 [[9.6.2 按符号筛选的实战配方]]。

## 4. API 一键定位

```python
from huggingface_hub import HfApi
for m in HfApi().list_models(pipeline_tag="text-generation",
                              library="transformers",
                              sort="downloads", direction=-1, limit=10):
    print(m.modelId, m.downloads)
```

## 5. 与 transformers `pipeline()` 的映射坑

- HF 上写 `text-generation` → 调用 `pipeline("text-generation", ...)`。

- HF 上写 `text2text-generation` → 注意必须用 `text2text-generation` 而非 `text-generation`，否则 decoder-only 解析失败。

- HF 上写 `image-text-to-text`（VLM 新名）→ transformers 4.45+ 才支持 `pipeline("image-text-to-text")`；旧版需手动 `AutoModelForVision2Seq`。

## 6. 当一个模型多任务怎么办

pipeline_tag 只能写一个。其余任务通过 `tags` 字段补充：

```yaml
# README.md frontmatter
pipeline_tag: text-generation
tags:
  - chat
  - code
  - math
```

搜索时 `?other=code` 仍能找到。
