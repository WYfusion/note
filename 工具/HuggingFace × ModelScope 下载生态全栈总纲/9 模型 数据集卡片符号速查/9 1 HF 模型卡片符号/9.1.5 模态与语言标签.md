## 0. 定位

本节说明语言（language）与模态（modality）徽标的取值范围、API 抽取方式、筛选 URL 模板，方便你做「中文 LLM」「中英双语 embedding」类需求精确定位。

## 1. 语言标签

- README frontmatter：

```yaml
language:
  - zh
  - en
  - ja
```

- 使用 ISO 639-1 两字母代码；少数语言用 ISO 639-3。

- 模型页显示：`🌐 3 languages` 点开后展示具体语种胶囊。

- 列表筛选 URL：

```jsx
https://huggingface.co/models?language=zh
https://huggingface.co/models?language=zh&language=en   # 并集，不是交集
```

> ⚠️ HF 的 language 筛选是 **并集（OR）** —— 一个 `zh` 和一个 `en` 同时勾选会返回「至少包含 zh 或 en 的模型」，而非「同时包含」。要做 AND 需在 API 端二次过滤。

## 2. API 端 AND 过滤

```python
from huggingface_hub import HfApi

required = {"zh", "en"}
for m in HfApi().list_models(language="zh", pipeline_tag="text-generation",
                              sort="downloads", direction=-1, limit=200):
    info = HfApi().model_info(m.modelId)
    langs = set((info.cardData or {}).get("language", []) or [])
    if required.issubset(langs):
        print(m.modelId, langs)
```

## 3. 模态徽标

模态徽标是 HF 从 pipeline_tag + tags 反推的显示标签：

|徽标|触发条件|
|---|---|
|Text|pipeline_tag 属文本类|
|Image|tags 含 image / pipeline_tag 属视觉类|
|Audio|tags 含 audio / pipeline_tag 属音频类|
|Video|pipeline_tag = text-to-video / image-to-video|
|Multimodal|pipeline_tag = image-text-to-text / any-to-any|
|3D|tags 含 3d / mesh / point-cloud|
|Tabular|pipeline_tag = tabular-*|

## 4. 多模态模型的下载陷阱

多模态权重通常会**同时含视觉编码器与 LLM**，导致体积是同尺寸 LLM 的 1.5–2 倍：

```jsx
Qwen2.5-7B-Instruct        ~15 GB
Qwen2.5-VL-7B-Instruct     ~17 GB（多了 ViT）
```

下载时建议 `allow_patterns=["*.safetensors", "*.json", "tokenizer*", "preprocessor_config.json"]` 防漏 image processor。

## 5. 常见组合 URL 模板

```jsx
# 中文 text-generation Apache-2.0
https://huggingface.co/models?language=zh&pipeline_tag=text-generation&license=apache-2.0

# 中文嵌入模型
https://huggingface.co/models?language=zh&pipeline_tag=sentence-similarity

# 视觉+中文（OCR 类）
https://huggingface.co/models?language=zh&pipeline_tag=image-to-text

# 语音中英文
https://huggingface.co/models?language=zh&pipeline_tag=automatic-speech-recognition
```
