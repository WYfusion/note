> 当你打开 [https://huggingface.co/Qwen/Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct)，正文上方那一行 `♥ 1.2k · ↓ 2.4M · Updated 5 days ago · Xet · 13 Inference Providers` 就是顶部元数据徽标。每一项都对应一个 API 字段。

## 0. 定位

本节解释顶部 5 个标识符的**字段名 / 单位 / API 接口 / 注意事项**，让你能用 `huggingface_hub.HfApi` 一行代码取出同一个值。

## 1. ♥ likes（喜欢）

- **页面位置**：模型名右上「Like」按钮，显示带 ♥ 的数字。

- **API 字段**：`model_info.likes`（整数）。

- **变化频率**：实时；点赞需登录。

- **取值**：

```python
from huggingface_hub import HfApi
print(HfApi().model_info("Qwen/Qwen2.5-7B-Instruct").likes)
```

- **用途**：作为冷启动的「口碑代理」，比 downloads 更难刷。但小众模型可能优秀却 likes 少。

## 2. ↓ downloads（30 天下载量）

- **页面位置**：likes 旁边带 ↓ 箭头的数字。

- **API 字段**：`model_info.downloads`，统计窗口是 **最近 30 天**（不是历史累计）。

- **统计口径**：HF 后端只统计「成功 `from_pretrained` 调用」与 `hf_hub_download` 的 successful HEAD/GET，浏览器单文件下载、`git clone` 不计入。

- **常见误区**：镜像站 [hf-mirror.com](http://hf-mirror.com) 的下载**不会**回流统计，所以国内热门模型在国际榜上看起来「冷清」。

- **API 调用**：

```python
info = HfApi().model_info("Qwen/Qwen2.5-7B-Instruct")
print("downloads(30d):", info.downloads)
print("all-time est :", info.downloads_all_time)  # 0.24+ 才有
```

## 3. Updated N days ago（最后提交时间）

- **页面位置**：downloads 之后。

- **API 字段**：`model_info.last_modified`（ISO8601 UTC）。

- **取值**：

```python
from datetime import datetime, timezone
lm = HfApi().model_info("Qwen/Qwen2.5-7B-Instruct").last_modified
print((datetime.now(timezone.utc) - lm).days, "days")
```

- **注意**：任何 commit（包括 README 修改）都会刷新；**不代表权重更新**。要看权重时间得查 `model-00001-of-00004.safetensors` 的 commit。

## 4. Xet 徽标（蓝色钻石）

- **含义**：该仓库已迁移到 **Xet 存储后端**，是 HF 在 2025 年开始替换传统 LFS 的新底层，支持「内容寻址 + 增量同步」。

- **对下载的影响**：
    
    - 安装 `pip install -U huggingface_hub[hf_xet]` 可走 Xet 协议，**断点续传更稳、相邻版本只下增量**。
    
    - 未安装 `hf_xet` 时会自动 fallback 到 LFS，**不会失败**。
    

- **判断方式**：

```python
info = HfApi().model_info("meta-llama/Llama-3.1-8B", files_metadata=True)
for s in info.siblings:
    if s.lfs:
        print(s.rfilename, "xet=", getattr(s, "xet_hash", None) is not None)
```

详见 [[4.3.3 文件系统大小写敏感坑]]。

## 5. N Inference Providers（推理服务商）

- **页面位置**：Xet 后面一个浅灰胶囊「13 Inference Providers」。

- **含义**：HF 在 2024 末推出的 Inference Providers 系统，把模型接到 Together / Fireworks / Replicate / Cerebras / SambaNova / HF Inference 等第三方推理后端，**点击可直接试用**。

- **数字含义**：可用第三方后端数（不含 HF 自家 Inference Endpoint）。

- **API**：

```python
import requests
r = requests.get("https://huggingface.co/api/models/Qwen/Qwen2.5-7B-Instruct")
print([p["provider"] for p in r.json().get("inference_providers", [])])
```

- **与下载的关系**：完全无关；只是「能在浏览器试玩」的入口。

## 综合速查示例

```python
from huggingface_hub import HfApi
import datetime as dt

def summarize(repo):
    api = HfApi()
    i = api.model_info(repo)
    age = (dt.datetime.now(dt.timezone.utc) - i.last_modified).days
    return {
        "♥ likes": i.likes,
        "↓ downloads(30d)": i.downloads,
        "Updated": f"{age} days ago",
        "Xet": any(getattr(s, "xet_hash", None) for s in (i.siblings or [])),
        "providers": len(getattr(i, "inference_providers", []) or []),
    }

print(summarize("Qwen/Qwen2.5-7B-Instruct"))
```
