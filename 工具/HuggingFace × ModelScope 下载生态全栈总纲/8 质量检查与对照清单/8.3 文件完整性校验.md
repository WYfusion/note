> 下载完不等于完整。本节讲三件事：**SHA256 / etag 对拍**、**safetensors 贴响响验**、**加载反裆测试**。

## 为什么要校验

- 代理护身某些文件返回 HTML 404 页，HTTP 状态仕是 200，hfd / aria2 不报错。

- 镜像同步不完全：etag 能对但实际是上个版本。

- 磁盘損坏 / 写断电。

- 手动拷贝过的文件被别的进程截断。

## 黑菜右侧：HF API 是启包含哈希的

```python
from huggingface_hub import HfApi
api = HfApi()
info = api.repo_info("Qwen/Qwen2.5-7B-Instruct", files_metadata=True)
for s in info.siblings:
    print(s.rfilename, s.size, s.lfs.sha256 if s.lfs else "-")
```

输出：

```jsx
config.json                                  651 -
generation_config.json                       243 -
model-00001-of-00004.safetensors        4839183296 8e3bc7...
model-00002-of-00004.safetensors        4731334984 92ab14...
...
```

`s.lfs.sha256` 仅在文件走 LFS 时填充。小文件（config.json）不是 LFS，需其他方式校验。

## 本地计算 SHA256

```bash
sha256sum ./models/qwen2.5-7b/model-00001-of-00004.safetensors
# 8e3bc7...  model-00001-of-00004.safetensors
```

Windows PowerShell：

```powershell
Get-FileHash .\model-00001-of-00004.safetensors -Algorithm SHA256
```

macOS：

```bash
shasum -a 256 ./model-00001-of-00004.safetensors
```

## 一键校验脚本

```bash
#!/usr/bin/env bash
# verify.sh——对比官方 LFS sha256 与本地文件
set -euo pipefail
REPO="$1"
LOCAL="$2"

python - <<PY > /tmp/expected.tsv
from huggingface_hub import HfApi
api = HfApi(endpoint="${HF_ENDPOINT:-https://hf-mirror.com}")
info = api.repo_info("${REPO}", files_metadata=True)
for s in info.siblings:
    if s.lfs and s.lfs.sha256:
        print(f"{s.lfs.sha256}\t{s.rfilename}")
PY

echo "file\tofficial\tlocal\tstatus"
while IFS=$'\t' read -r SHA F; do
  if [ -f "$LOCAL/$F" ]; then
    LOCAL_SHA=$(sha256sum "$LOCAL/$F" | awk '{print $1}')
    if [ "$LOCAL_SHA" = "$SHA" ]; then
      echo "$F\t$SHA\t$LOCAL_SHA\tOK"
    else
      echo "$F\t$SHA\t$LOCAL_SHA\tMISMATCH"
    fi
  else
    echo "$F\t$SHA\t-\tMISSING"
  fi
done < /tmp/expected.tsv
```

跑：

```bash
bash verify.sh Qwen/Qwen2.5-7B-Instruct ./models/qwen2.5-7b
```

## safetensors 贴响响验（企业必偼）

safetensors 格式能被 Python 独立检验，不依赖服务端 hash：

```python
from safetensors.torch import load_file
from pathlib import Path

for p in Path("./models/qwen2.5-7b").glob("*.safetensors"):
    try:
        t = load_file(str(p), device="cpu")
        print("OK ", p.name, "params:", sum(v.numel() for v in t.values()))
    except Exception as e:
        print("X ", p.name, e)
```

其余问题：head 8 bytes 是 json header 长度 (little-endian)；header 为 JSON；后面是连续数据区。不合法会报 `HeaderTooLarge` / `MetadataIncomplete`。

## load 验证（最严格）

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

p = "./models/qwen2.5-7b"
tok = AutoTokenizer.from_pretrained(p)
model = AutoModelForCausalLM.from_pretrained(p, torch_dtype=torch.float16, device_map="auto")
out = model.generate(**tok("Hello", return_tensors="pt").to(model.device), max_new_tokens=4)
print(tok.decode(out[0]))
```

能生成文本，则权重 + tokenizer + config 都是完整的。

## 常见问题

- LFS hash 对、但 `load_file` 报 `MetadataIncomplete`：sha256 拼拽对上但 LFS 对贺装错了“贵拷”映射。重下。

- `s.lfs is None`：该文件不是 LFS（如 config.json），其哈希依赖 etag 而非 sha256。可用 etag 判重：

```python
import requests
r = requests.head(f"{api.endpoint}/{REPO}/resolve/main/config.json")
print(r.headers["etag"], r.headers.get("x-linked-size"))
```
