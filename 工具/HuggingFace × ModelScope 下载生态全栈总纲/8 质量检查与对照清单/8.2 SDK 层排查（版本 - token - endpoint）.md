版本底线：

- `huggingface_hub >= 0.24`：snapshot_download 支持 `local_dir_use_symlinks=False`；hf_transfer 1.x 适配。

- `transformers >= 4.40`：Llama3 / Qwen2.5 架构原生支持。

- `modelscope >= 1.16`：hub 与数据集 API 统一。

- `hf_transfer >= 0.1.6`：需匹配 glibc。2.17 老环境需 `--no-binary`。

## token

```bash
# HF
huggingface-cli whoami           # 应返回你的用户名
cat ~/.cache/huggingface/token   # 文件权限 600
# MS
python -c "from modelscope.hub.api import HubApi; HubApi().get_token()"
```

问题与处方：

- `Invalid user token`：token 过期或被 Revoke。`huggingface-cli login` 重新交变。

- Gated 403：仓库需去页面「请求访问」后才能下载。

- token 被环境 cache 锁定：jupyter 内改了 token 但内核未重启 → `import importlib, huggingface_hub; importlib.reload(huggingface_hub)`。

## 常见错误梳理

|报错|原因|处方|
|---|---|---|
|RepositoryNotFoundError|repo_id 拼错 / 隐私 / 已刪除|检查官网、huggingface-cli repo-info|
|RevisionNotFoundError|tag/branch 不存在|使用 main 或备件 commit sha|
|EntryNotFoundError|仓库里没该文件|在页面 Files 看|
|LocalEntryNotFoundError + offline|OFFLINE=1 且本地无缓存|先改 offline=0 拉一次|
|HFValidationError: Repo id must be in the form 'repo_name'|repo_id 多了斜杠 / 缺了 owner|填完整 owner/repo|
|OSError: not a directory|HF_HOME 被指到一个文件上|重设 HF_HOME|

## ModelScope 专有

- `modelscope.utils.config_ds` 报 yaml 详析错：MS SDK 升级后零件不兼容。`pip install -U modelscope datasets`。

- `Errno 13: Permission denied: '~/.cache/modelscope/log/...'`：多用户共备 cache 时权限冲突，参考 [[4.2.2 多用户共享缓存与权限]]。
