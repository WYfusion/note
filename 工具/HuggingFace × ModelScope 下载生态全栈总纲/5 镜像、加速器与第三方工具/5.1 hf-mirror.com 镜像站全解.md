> `hf-mirror.com` 是国内社区（「圣火」/AI Studio 等）维护的 HuggingFace 反向代理镜像。原理上会拦住所有 `https://huggingface.co/*` 请求，高保真转发到官站，同时走 CDN 缓存热点文件。

## 一行切换

```bash
export HF_ENDPOINT=https://hf-mirror.com
```

仅需这一行，**不需要重装 huggingface_hub**。所有依赖的 `huggingface-cli`、`from_pretrained`、`snapshot_download`、`datasets.load_dataset` 都会走镜像。

## 镜像揭露的路径表

|官站路径|镜像路径|用途|
|---|---|---|
|[huggingface.co/api/*](http://huggingface.co/api/*)|[hf-mirror.com/api/*](http://hf-mirror.com/api/*)|JSON API（仓库信息、文件列表）|
|[huggingface.co/owner/repo/resolve/main/file](http://huggingface.co/owner/repo/resolve/main/file)|[hf-mirror.com/owner/repo/resolve/main/file](http://hf-mirror.com/owner/repo/resolve/main/file)|单文件下载|
|[huggingface.co/datasets/](http://huggingface.co/datasets/)...|[hf-mirror.com/datasets/](http://hf-mirror.com/datasets/)...|数据集|
|[cdn-lfs.huggingface.co](http://cdn-lfs.huggingface.co)|[hf-mirror.com](http://hf-mirror.com)（自动 rewrite）|LFS 大文件|

## 验证镜像可用

```bash
curl -sI https://hf-mirror.com/api/models/bert-base-uncased | head -1
# HTTP/2 200 即可用

huggingface-cli download bert-base-uncased --revision main \
  --include "*.json" --local-dir /tmp/bert-test
```

## 带 token 的场景

镜像 **不提供**「受控访问」（Gated）模型的本地鉴权；Gated 模型（如 meta-llama 系列）**必须**手持官站 token 走原站：

```bash
# 临时取消镜像，带 token 走官站
HF_ENDPOINT=https://huggingface.co \
huggingface-cli download meta-llama/Llama-3.1-8B --token hf_xxxxx
```

智能脚本：默认走镜像，判断到 401/403 后回退到官站。详见 [[7.1 一键脚本：HF 优先，失败回退 MS]]。

## 与 hf_transfer 携手

镜像站仅提供简单 HTTP，要启用 hf_transfer：

```bash
pip install 'huggingface_hub[hf_transfer]'
export HF_HUB_ENABLE_HF_TRANSFER=1
export HF_ENDPOINT=https://hf-mirror.com
# 现在下载由 hf_transfer Rust 多线程获取，能吃满 100Mbps+。
```

## 镜像限制与变数

- **不同步实时**：镜像老版本有几十分钟到几小时的同步延迟；刚发布的模型可能需要等。

- **不托管讨论区**：`/discussions` 路由可能不走镜像。

- **作者 push 不能走镜像**：push / 修改仓库一律走官站。

- **取消镜像**：只需 `unset HF_ENDPOINT` 或者明示 `HF_ENDPOINT=https://huggingface.co`。

## 与代理 / VPN 的互动

- 如果你所在环境能直连官站且带宽状况好，实测官站 + hf_transfer 可能比镜像快。

- 代理 + 镜像 **不要以同时启用**：https_proxy 包住镜像请求后走代理绕出去反而更慢。选一个。

## 可能遇到的错误

|报错|原因|处方|
|---|---|---|
|401 / 403|Gated，镜像不受理|换官站 + token|
|404 on file|镜像未同步该文件|等 或 临时 unset HF_ENDPOINT|
|SSL: CERTIFICATE_VERIFY_FAILED|公司代理拦了证书|产品侧加 CA bundle，或 REQUESTS_CA_BUNDLE|
|下载速率狂抖|镜像背后 CDN 节点随机|重试几次；改用 hfd 多线程拉|
