> 纯 `aria2c` 直连 HF / HF 镜像作为「底层拉取」手段，不介入 huggingface_hub。适合：

> - 环境装不了 Python / huggingface_hub

> - 需要集中下载多个不同仓库的文件

> - 未来计划手动部署到严峻环境。

## 造出下载 URL

任何 HF 文件都可表示为：

```jsx
https://<endpoint>/<owner>/<repo>/resolve/<revision>/<path>
```

- `<endpoint>` = `huggingface.co` 或 `hf-mirror.com`

- `<revision>` = `main` / commit-sha / branch / tag

- `<path>` = `model.safetensors` / `tokenizer.json` / `config.json` 等

示例：

```jsx
https://hf-mirror.com/Qwen/Qwen2.5-7B-Instruct/resolve/main/model-00001-of-00004.safetensors
```

## 获取仓库文件清单

```bash
# JSON API走镜像也可
curl -s https://hf-mirror.com/api/models/Qwen/Qwen2.5-7B-Instruct \
  | python -c "import sys,json; [print(s['rfilename']) for s in json.load(sys.stdin)['siblings']]"
```

## 一个脚本走完

```bash
#!/usr/bin/env bash
set -euo pipefail
REPO="Qwen/Qwen2.5-7B-Instruct"
REV="main"
DEST="./models/qwen2.5-7b"
ENDPOINT="https://hf-mirror.com"

# 1. 列出所需文件
FILES=$(curl -s "$ENDPOINT/api/models/$REPO" \
  | python -c "import sys,json; [print(s['rfilename']) for s in json.load(sys.stdin)['siblings']]" \
  | grep -E '\.(safetensors|json|txt|model|tiktoken)$')

# 2. 生成 aria2 input 清单
mkdir -p "$DEST"
INPUT=$(mktemp)
while read -r f; do
  printf '%s/%s/resolve/%s/%s\n    out=%s\n' "$ENDPOINT" "$REPO" "$REV" "$f" "$f" >> "$INPUT"
done <<< "$FILES"

# 3. aria2c 拉取
aria2c \
  --dir "$DEST" \
  --input-file "$INPUT" \
  --max-concurrent-downloads=4 \
  --max-connection-per-server=16 \
  --split=16 \
  --min-split-size=10M \
  --continue=true \
  --auto-file-renaming=false \
  --console-log-level=warn

rm -f "$INPUT"
echo "Done. $DEST"
```

## Gated 模型

```bash
TOKEN="hf_xxxxxxxxxxxxx"
aria2c \
  --header "Authorization: Bearer $TOKEN" \
  --dir ./models/llama \
  -x 16 -s 16 \
  "https://huggingface.co/meta-llama/Llama-3.1-8B/resolve/main/model.safetensors"
```

> ⚠️ Gated **不能走镜像**，endpoint 必须是 `huggingface.co`。

## 与 huggingface_hub 接轨

aria2 拉下来是**纯文件目录**，不是 hf_hub 缓存格式。两种接法：

1. **直接传本地路径**：

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
model = AutoModelForCausalLM.from_pretrained("./models/qwen2.5-7b")
tok = AutoTokenizer.from_pretrained("./models/qwen2.5-7b")
```

1. **手动复制到 hf_hub 格式**（需了解缓存布局，成本高，不推荐）。

## 常见问题

- aria2 吃 416 错误：服务器不支持 Range。加 `-x 1 -s 1` 退回单连接。

- 下完后“似乎完整但加载报错”：HTTP 200 但实际返回 HTML（代理错误页面）。加 `--check-certificate=true` 以及验证 `file ./model.safetensors` 是 `data`，不是 `HTML`。

- 误拉到 README：路径里区分 `blob` / `resolve`。`/blob/` 是页面，`/resolve/` 才是二进制。
