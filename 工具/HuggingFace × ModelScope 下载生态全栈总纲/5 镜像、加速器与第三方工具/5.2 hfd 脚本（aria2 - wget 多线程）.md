> `hfd` 是 [hf-mirror.com](http://hf-mirror.com) 社区提供的 Bash 脚本，背后套 **aria2c**（首选）或 **wget**，为 HF 仓库增加多连接、断点续传、选择性下载能力。适合 hf_transfer 不能跑或者需要精细控制下载子集的场景。

## 安装

```bash
wget https://hf-mirror.com/hfd/hfd.sh -O ~/.local/bin/hfd
chmod +x ~/.local/bin/hfd
# 依赖
sudo apt install aria2 git git-lfs    # Debian / Ubuntu
sudo dnf install aria2 git git-lfs    # RHEL / Rocky
brew install aria2 git-lfs            # macOS
```

## 默认下载整仓

```bash
hfd Qwen/Qwen2.5-7B-Instruct
```

会在当前目录生成 `Qwen2.5-7B-Instruct/`。所有文件多连接拉，并行度默认 16。

## 常用参数

|参数|作用|
|---|---|
|--tool aria2c|明示使用 aria2c（默认）|
|--tool wget|回退到 wget（环境装不了 aria2 时）|
|-j 32|并发连接数，默认 16；镜像状况好时可加到 32|
|--include "_.safetensors" "_.json"|只拉指定模式|
|--exclude "*.bin"|跳过 pytorch_model.bin（仅要 safetensors 时常用）|
|--dataset|拉 datasets/owner/repo 而非 models/owner/repo|
|--hf_username / --hf_token|授权（Gated）|
|--local-dir DIR|指定落地|
|--revision REF|commit / tag / branch|

## 实战示例

```bash
# 1. 仅下 safetensors + config + tokenizer，跳过 .bin
hfd Qwen/Qwen2.5-7B-Instruct \
  --include "*.safetensors" "*.json" "*.txt" "*.model" \
  --exclude "*.bin" \
  --local-dir ./models/qwen2.5-7b -j 24

# 2. 只拉 dataset 的某个分片
hfd HuggingFaceH4/ultrachat_200k --dataset \
  --include "data/train_sft-00000-of-00006.parquet" \
  --local-dir ./data/ultrachat

# 3. 拉 Gated 模型
hfd meta-llama/Llama-3.1-8B \
  --hf_username your_user --hf_token hf_xxxxx \
  --local-dir ./models/llama3.1-8b

# 4. 指定 commit
hfd Qwen/Qwen2.5-7B-Instruct --revision abc1234 --local-dir ./models/qwen_v1
```

## aria2c 参数调优

如果起作状况不理想，创建 `~/.aria2/aria2.conf`：

```
max-connection-per-server=16
split=16
min-split-size=10M
continue=true
disk-cache=64M
file-allocation=falloc
rpc-secret=secret-token
```

## 与 hf_transfer 的差异与选型

|场景|选 hf_transfer|选 hfd|
|---|---|---|
|原生 Python、整仓下|✅ 隱式启用 1 个 env||
|需选择性过滤||✅ --include / --exclude|
|不能装 Rust wheel 的 glibc 老环境||✅ 纯 bash + aria2c|
|要跟踪进度 / RPC 控制||✅|
|需 token 鉴权 Gated|✅✅ 原生逆授权|✅ 手动传参|

## 常见问题

- `aria2c: command not found` → 装 aria2 双镜像包（`apt install aria2`）。

- 下载完问「hashes match?」→ hfd 只会验证 etag，水紧 LFS 文件请手动 `sha256sum` 对比。

- 跨机同步仓库：hfd 拉出来的是「纯文件」目录，不是 hf_hub 缓存格式。要让 `from_pretrained` 读到，传路径而非 repo_id。
