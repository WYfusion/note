> GPT-SoVITS / FunASR 两个项目里面的权重被「硬编码路径」提及的地方很多：GitHub Release 、ModelScope、HuggingFace、豆瓣 / 百度云如烟火。这里梳理一份「何处取什么」与「接入脚本」。

## GPT-SoVITS

### 官方可以下载的需素

|项|来源|备注|
|---|---|---|
|GPT 预训 / SoVITS 预训|HF lj1995/GPT-SoVITS|~3GB|
|UVR5 人声分离|HF Anjok07/ultimatevocalremovergui|点高到 6GB|
|HuBERT (Chinese)|HF lj1995/GPT-SoVITS 中的子目录||
|BERT (Chinese)|HF hfl/chinese-roberta-wwm-ext-large||
|Whisper 转录（可选）|HF openai/whisper-large-v3|3GB|

### 一键拉到项目默认路径

```bash
#!/usr/bin/env bash
# fetch-sovits.sh——在 GPT-SoVITS 项目根路径下跑
set -euo pipefail
export HF_ENDPOINT=${HF_ENDPOINT:-https://hf-mirror.com}
export HF_HUB_ENABLE_HF_TRANSFER=1

mkdir -p GPT_SoVITS/pretrained_models tools/uvr5/uvr5_weights tools/asr/models

huggingface-cli download lj1995/GPT-SoVITS \
  --local-dir GPT_SoVITS/pretrained_models --local-dir-use-symlinks False

huggingface-cli download Anjok07/ultimatevocalremovergui \
  --include "models/*" \
  --local-dir tools/uvr5/uvr5_weights --local-dir-use-symlinks False

huggingface-cli download hfl/chinese-roberta-wwm-ext-large \
  --local-dir GPT_SoVITS/pretrained_models/chinese-roberta-wwm-ext-large --local-dir-use-symlinks False

# Whisper 可选
huggingface-cli download Systran/faster-whisper-large-v3 \
  --local-dir tools/asr/models/faster-whisper-large-v3 --local-dir-use-symlinks False
```

## FunASR

### 需要的模型

FunASR 默认从 **ModelScope** 拉取。常用 ID：

- ASR 主模型：`iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch`

- VAD：`iic/speech_fsmn_vad_zh-cn-16k-common-pytorch`

- 标点：`iic/punc_ct-transformer_cn-en-common-vocab471067-large`

- 说话人识别：`iic/speech_eres2net_sv_zh-cn_16k-common`

- 时间戳预测：`iic/speech_timestamp_prediction-v1-16k-offline`

### 拉取脚本

```bash
#!/usr/bin/env bash
set -euo pipefail
MODELS=(
  iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch
  iic/speech_fsmn_vad_zh-cn-16k-common-pytorch
  iic/punc_ct-transformer_cn-en-common-vocab471067-large
  iic/speech_eres2net_sv_zh-cn_16k-common
)
for m in "${MODELS[@]}"; do
  python -c "from modelscope import snapshot_download; print(snapshot_download('$m'))"
done
```

### 代码里手动指定本地路径

```python
from funasr import AutoModel

model = AutoModel(
    model="iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch",
    model_revision="v2.0.4",
    vad_model="iic/speech_fsmn_vad_zh-cn-16k-common-pytorch",
    punc_model="iic/punc_ct-transformer_cn-en-common-vocab471067-large",
)
# 推理
result = model.generate(input="audio.wav", batch_size_s=300)
print(result)
```

## 统一接入点

推荐在项目根放一个 `Makefile`：

```makefile
.PHONY: sovits funasr
sovits:
	bash scripts/fetch-sovits.sh
funasr:
	bash scripts/fetch-funasr.sh
all: sovits funasr
```

## 常见坑

- GPT-SoVITS 加载报 `BertModel not found`：`chinese-roberta-wwm-ext-large` 未下全，检查子目录。

- UVR5 weights 拼拽一下载不全：镜像可能对 LFS 大文件抱怨，加一个 `for i in 1 2 3; do ... done` 重试。

- FunASR `model_revision` 不匹配：查看 ModelScope 页面「版本」面板，使用 hash 或者 tag。

- ModelScope 拉取 hf 镜像模型：需 USE_HF=1，不是默认。
