> [ms-swift](https://github.com/modelscope/ms-swift) 是阶氏社区对接 ModelScope 生态的训练框架，默认从 MS Hub 拉取权重。本节讲如何让 swift **复用你个人环境里已经下好的 HF 模型**，以及如何控制训练产出上传到哪里。

## 安装

```bash
pip install 'ms-swift[llm]'
# 或从源代
pip install -e .
```

## 默认行为与三个变量

swift 会读这些变量：

- `USE_HF=1`：从 HF / hf-mirror 拉取而非 MS（与 ms-swift 2.0+）。

- `HF_ENDPOINT`：HF 镜像。

- `MODELSCOPE_CACHE`：MS 本地缓存。

- `MODELSCOPE_API_TOKEN`：私有 / Gated MS 模型。

## 例 1：SFT 从本地 HF 缓存加载 Qwen

```bash
export HF_ENDPOINT=https://hf-mirror.com
export USE_HF=1
export HF_HUB_ENABLE_HF_TRANSFER=1

swift sft \
  --model Qwen/Qwen2.5-7B-Instruct \
  --dataset AI-ModelScope/alpaca-gpt4-data-zh \
  --train_type lora \
  --num_train_epochs 3 \
  --learning_rate 1e-4 \
  --lora_rank 8 \
  --output_dir ./output/qwen-sft
```

流程：

1. swift 检查 HF_HOME 里是否已有 `Qwen/Qwen2.5-7B-Instruct@<commit>`；有则复用。

1. 数据集走 MS 拉取并缓存到 MODELSCOPE_CACHE。

1. 训练产物写到 output_dir。

## 例 2：以 ModelScope 为主，数据集走 HF

```bash
unset USE_HF
export HF_ENDPOINT=https://hf-mirror.com
swift sft \
  --model qwen/Qwen2.5-7B-Instruct \
  --dataset HuggingFaceH4/ultrachat_200k:hf \
  --train_type lora
```

后缀 `:hf` 表示该 dataset 走 HF，其他他项走 MS。适合「模型在 MS、数据集在 HF」的混合场景。

## 推理阶段

```bash
swift infer \
  --model Qwen/Qwen2.5-7B-Instruct \
  --adapters ./output/qwen-sft/checkpoint-1000 \
  --infer_backend vllm \
  --max_model_len 8192
```

swift 会检查本地是否有 vllm 可用，没有则提示 `pip install vllm`。

## 合并 LoRA 后推送

```bash
swift export \
  --adapters ./output/qwen-sft/checkpoint-1000 \
  --merge_lora true \
  --output_dir ./output/qwen-merged
```

## 将产物推上应用仓库

```bash
swift export \
  --adapters ./output/qwen-sft/checkpoint-1000 \
  --push_to_hub true \
  --hub_model_id your-ns/qwen-7b-sft-v1 \
  --hub_token ms_xxxxxxxxx
```

MS 的 `push_to_hub` 需要 `MODELSCOPE_API_TOKEN`。推到 HF 需要 `huggingface-cli login` 且 swift CLI 足够新，采用 `--use_hf_hub` 参数。

## 与 [[7.1 一键脚本：HF 优先，失败回退 MS]] 接轨

推荐流程：

1. 用 `get-model.sh` 预拉模型到 `./models/qwen2.5-7b`。

1. swift sft 里传 `--model ./models/qwen2.5-7b`，跳过重拉。

1. 上传脚本独立跑。

## 常见坑

- swift 报 `OSError: We couldn't connect to`…——`USE_HF` 未设，默认走 MS 但你环境 MS 不通。加 `USE_HF=1`。

- 训练中途断后重启：加 `--resume_from_checkpoint <path>`。

- ZeroGPU / 多机：swift 默认走 accelerate launch，在 deepspeed 场景下加 `--deepspeed default-zero3`。
