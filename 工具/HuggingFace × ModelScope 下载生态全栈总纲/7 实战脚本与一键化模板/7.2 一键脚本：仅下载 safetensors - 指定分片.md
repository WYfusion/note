> 大模型仓库里常并存 `*.safetensors` 与 `pytorch_model.bin`，二者只需一个。Sharded 大模型常达 100+ 个分片，你可能只想下某些。脚本提供两个子命令：`only-safetensors` 与 `shard`。

## 只下 safetensors

```bash
#!/usr/bin/env bash
# only-safetensors.sh
set -euo pipefail
REPO="$1"
OUT="${2:-./models/$(basename "$REPO")}"
export HF_ENDPOINT=${HF_ENDPOINT:-https://hf-mirror.com}
export HF_HUB_ENABLE_HF_TRANSFER=1

huggingface-cli download "$REPO" \
  --include "*.safetensors" \
           "*.json" \
           "tokenizer*" \
           "*.txt" \
           "*.model" \
           "*.tiktoken" \
           "chat_template.jinja" \
  --exclude "*.bin" \
           "*.h5" \
           "*.msgpack" \
           "*.ot" \
           "*.gguf" \
  --local-dir "$OUT" \
  --local-dir-use-symlinks False

echo "✓ safetensors-only downloaded to: $OUT"
du -sh "$OUT"
```

使用：

```bash
./only-safetensors.sh meta-llama/Llama-3.1-8B
```

## 仅下指定分片

```bash
#!/usr/bin/env bash
# shard.sh——仅拉 model-XXXXX-of-XXXXX.safetensors 中的指定范围
set -euo pipefail
REPO="$1"          # e.g. meta-llama/Llama-3.1-405B-Instruct
FROM="${2:-1}"     # 起始分片号
TO="${3:-4}"       # 结束分片号
TOTAL="${4:-191}"  # 总分片数，看 index.json
OUT="${5:-./models/$(basename "$REPO")}"

export HF_ENDPOINT=${HF_ENDPOINT:-https://hf-mirror.com}
export HF_HUB_ENABLE_HF_TRANSFER=1

# 拼出 --include 参数
INCLUDES=("*.json" "tokenizer*" "*.txt" "*.model")
for ((i=FROM; i<=TO; i++)); do
  N=$(printf "%05d" $i)
  T=$(printf "%05d" $TOTAL)
  INCLUDES+=("model-${N}-of-${T}.safetensors")
done

huggingface-cli download "$REPO" --include "${INCLUDES[@]}" --local-dir "$OUT"
```

使用：

```bash
# 只拉 405B 的前 10 个分片
bash shard.sh meta-llama/Llama-3.1-405B-Instruct 1 10 191 ./models/llama3-405b
```

## Python 版：进一步精细控制

```python
from huggingface_hub import snapshot_download

# allow_patterns / ignore_patterns 与 CLI --include / --exclude 同语义
local = snapshot_download(
    "meta-llama/Llama-3.1-8B",
    allow_patterns=["*.safetensors", "*.json", "tokenizer*", "*.model"],
    ignore_patterns=["*.bin", "*.h5", "*.msgpack"],
    local_dir="./models/llama3-8b",
    local_dir_use_symlinks=False,
    max_workers=8,
)
print(local)
```

## 使用 from_pretrained 加载部分下载的模型

- **只有 safetensors**：HF transformers 会自动选 safetensors，代码无需修改。载入时传 `use_safetensors=True` 可避免 fallback。

- **仅 N 个分片但 index.json 要求全部**：`from_pretrained` 会报 `MissingShard`。两种处方：
    
    - 补全分片。
    
    - 手写「裁剪版」`model.safetensors.index.json`，只保留实际存在的 weight（适合只加载 encoder / 剩事子集场景）。
    

## 与 ModelScope 对齐

ModelScope `snapshot_download` 同样支持 `allow_patterns`、`ignore_patterns`，语义一致：

```python
from modelscope import snapshot_download
path = snapshot_download(
    "qwen/Qwen2.5-7B-Instruct",
    allow_patterns=["*.safetensors", "*.json", "tokenizer*"],
)
```

## 节省空间的额外技巧

- 下完后，**在本地跳不需要的 safetensors 重量量化**（如留 4bit GGUF / AWQ）。

- 中期打包：`tar --use-compress-program=zstd -cf model.tar.zst ./models/qwen`，压缩比 30%。

- 多节点集群同仓：拉取一份后 rsync 到其他节点，避免重复从 HF 拉。
