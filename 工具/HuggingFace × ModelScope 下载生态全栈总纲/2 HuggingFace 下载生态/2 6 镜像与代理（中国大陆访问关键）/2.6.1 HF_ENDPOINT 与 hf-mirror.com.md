## 0. 定位

> 一句话：`HF_ENDPOINT=https://hf-mirror.com` 是国内场景下「一行切镜像」的最快路径。本页讲作用位、限制、验证路径。

## 1. 生效范围

|调用方|是否读 `HF_ENDPOINT`|
|---|---|
|`huggingface_hub` Python SDK|✅ 读|
|`transformers` / `datasets` / `diffusers`|✅ 间接调 hub SDK|
|`hf download` / `huggingface-cli`|✅|
|原生 `git clone https://huggingface.co/…`|❌ 需手动换 URL|
|`hfd` 脚本|✅ 默认已使用|
|`modelscope`|❌ 不相关|

## 2. 三种设法

```bash
# A. Linux/macOS 临时
export HF_ENDPOINT=https://hf-mirror.com

# B. 永久 (追到启动文件)
echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
source ~/.bashrc

# C. Windows PowerShell
$env:HF_ENDPOINT = "https://hf-mirror.com"
[System.Environment]::SetEnvironmentVariable("HF_ENDPOINT", "https://hf-mirror.com", "User")
```

Python 进程内：

```python
import os
# 必须在 import huggingface_hub 之前设
os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"

from huggingface_hub import snapshot_download
snapshot_download("Qwen/Qwen2.5-0.5B-Instruct")
```

## 3. 验证生效

```

```

## 4. 镜像不能做的事

> [!important]
> 
> - **镜像仅提供写代理**。`hf upload` `hf repo create` 都需直连 HF 本站。上传场景请别设 HF_ENDPOINT。
> 
> - **镜像可能有延迟**：作者刚 push 的文件需 0ヂ 2 小时后体现。
> 
> - **gated 仓库 (Llama-3 、Gemma)** 仍需 token，镜像会透传 token 到 HF 鉴权。
> 
> - **不支持 hf_transfer**。设 `HF_HUB_ENABLE_HF_TRANSFER=1` 会 429。

## 5. 多镜像切换

```bash
# 全局默认走镜像
export HF_ENDPOINT=https://hf-mirror.com

# 临时走原站 (仅本命令)
HF_ENDPOINT=https://huggingface.co hf download my-org/private --token $HF_TOKEN

# 同机两项目走不同镜像——项目内放 .env + python-dotenv
```

## 6. 镜像联通性检查脚本

```python
# probe_mirror.py —— 定位故障点
import os, requests, time

MIRRORS = [
    "https://huggingface.co",
    "https://hf-mirror.com",
]

def probe(url):
    t = time.time()
    try:
        r = requests.get(
            url + "/api/models/Qwen/Qwen2.5-0.5B-Instruct",
            timeout=10,
        )
        return r.status_code, time.time() - t
    except Exception as e:
        return "ERR", str(e)[:60]

for m in MIRRORS:
    status, ms = probe(m)
    print(f"{m}\tstatus={status}\telapsed={ms}")
```
