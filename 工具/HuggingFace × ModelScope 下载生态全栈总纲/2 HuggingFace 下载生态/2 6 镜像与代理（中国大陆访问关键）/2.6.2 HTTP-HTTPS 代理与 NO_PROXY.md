## 0. 定位

> 一句话：设 `HTTP_PROXY` / `HTTPS_PROXY` 是「镜像外」那些「须上外网」场景的默认合义路径。但 `requests` 与 `git` 读环境变量的细节不同、踩坊量大。

## 1. requests / huggingface_hub 侧

```bash
# 进程级设
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
export NO_PROXY=localhost,127.0.0.1,hf-mirror.com

# Windows PowerShell
$env:HTTP_PROXY = "http://127.0.0.1:7890"
$env:HTTPS_PROXY = "http://127.0.0.1:7890"
$env:NO_PROXY = "localhost,127.0.0.1"
```

Python 进程内：

```python
import os
os.environ["HTTP_PROXY"] = "http://127.0.0.1:7890"
os.environ["HTTPS_PROXY"] = "http://127.0.0.1:7890"
os.environ["NO_PROXY"] = "localhost,127.0.0.1"

from huggingface_hub import snapshot_download
snapshot_download("Qwen/Qwen2.5-0.5B-Instruct")
```

## 2. git 侧

`git` 不读 `HTTP_PROXY`，需独立设：

```bash
# 全局
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# 仅对 HF 生效
git config --global http.https://huggingface.co.proxy http://127.0.0.1:7890

# 取消
git config --global --unset http.proxy
git config --global --unset https.proxy
```

## 3. 验证代理生效

```python
# probe_proxy.py
import os, requests

print("HTTP_PROXY =", os.getenv("HTTP_PROXY"))
print("HTTPS_PROXY =", os.getenv("HTTPS_PROXY"))

# (1) 护 IP 检测
r = requests.get("https://api.ipify.org", timeout=10)
print("外网出口 IP =", r.text)

# (2) HF 可联
r = requests.head("https://huggingface.co", timeout=10)
print("HF 状态 =", r.status_code)
```

## 4. 代理 + 镜像 组合决策表

|场景|HF_ENDPOINT|HTTP(S)_PROXY|
|---|---|---|
|国内 + 无代理|hf-mirror|不设|
|国内 + 有代理|[huggingface.co](http://huggingface.co)|设|
|国外云机器|[huggingface.co](http://huggingface.co)|不设|
|CI|考虑镜像|不设|

## 5. socks5 代理

```bash
# requests 默认不支持 socks，需装插件
pip install "requests[socks]"

export HTTPS_PROXY=socks5h://127.0.0.1:1080
# 注意 socks5h 才走远端 DNS，socks5 会本地解析后泄露
```

## 6. 踩过的坊

> [!important]
> 
> **1) 镜像与代理同时设 → 多可能反而慢**。镜像本在国内、再走代理会绕一圈。
> 
> **2) 企业代理调 https-中间人** — `requests.exceptions.SSLError`。需设 `REQUESTS_CA_BUNDLE` 指向企业 CA。
> 
> **3)** `**NO_PROXY**` **不识别通配符** — 只识碊后缀。`*.hf-mirror.com` 请写 `hf-mirror.com`。
