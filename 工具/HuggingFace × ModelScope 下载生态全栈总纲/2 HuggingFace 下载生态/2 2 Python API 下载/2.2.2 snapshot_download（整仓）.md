## 0. 定位

> 一句话：`snapshot_download` 是「拉整仓库」的主力 API，**99% 的训练脚本只需调这个**。它本质是 `hf_hub_download` 的多文件并发版本 + 过滤。

## 1. 函数签名与关键参数

```python
snapshot_download(
    repo_id: str,
    repo_type: str = "model",      # model / dataset / space
    revision: str = "main",
    cache_dir: str | None,
    local_dir: str | None,         # 拷真文件到这里
    allow_patterns: list[str] | None,   # glob 白名单
    ignore_patterns: list[str] | None,  # glob 黑名单
    token: str | bool | None,
    max_workers: int = 8,          # 并发下载线程数
    etag_timeout: float = 10.0,
) -> str:                          # 返回本地目录路径
```

## 2. 五个实战片段

```python
# snapshot_examples.py —— 推荐收藏的五个调用模式
from huggingface_hub import snapshot_download

# (1) 默认拷入缓存
d = snapshot_download("Qwen/Qwen2.5-0.5B-Instruct")
print(d)  # 路径位于 ~/.cache/huggingface/hub/…/snapshots/<c>/

# (2) 拷真文件到项目本地目录 (拷贝、不是软链)
d = snapshot_download(
    "Qwen/Qwen2.5-0.5B-Instruct",
    local_dir="./qwen",
)

# (3) 仅拉权重与 tokenizer，跳过示例、README
d = snapshot_download(
    "Qwen/Qwen2.5-0.5B-Instruct",
    allow_patterns=["*.safetensors", "tokenizer.*", "config*.json", "merges.txt"],
)

# (4) 下载指定 commit 锁定可复现
d = snapshot_download(
    "Qwen/Qwen2.5-0.5B-Instruct",
    revision="7f6b3fc1\u2026",
)

# (5) 下载数据集
d = snapshot_download(
    "HuggingFaceH4/MATH-500",
    repo_type="dataset",
)
```

## 3. `allow_patterns` 的匹配规则

glob 类型。常用模式：

|模式|含义|
|---|---|
|`*.safetensors`|任意目录下的 .safetensors|
|`model-*-of-*.safetensors`|多分片权重|
|`pytorch_model*.bin`|老式 bin 权重|
|`tokenizer*`|tokenizer.json / tokenizer_config.json / tokenizer.model|
|`*.json`|所有 json|
|`!*.gguf`|**不支持取反**，取反走 `ignore_patterns`|

## 4. 与训练脚本集成

```python
# train_glue.py —— 一个「下载 → 加载 → 训练」的最小场景
import os
from pathlib import Path
from huggingface_hub import snapshot_download
from transformers import AutoModelForSequenceClassification, AutoTokenizer

REPO = "distilbert/distilbert-base-uncased"

# 1) 明确在下载阶段报错，而非训练可检索中间才报
local = Path(snapshot_download(
    repo_id=REPO,
    allow_patterns=["*.safetensors", "tokenizer*", "*.json", "vocab*"],
))
print("下载至", local)

# 2) 使用本地路径加载——不会再调网络
tok = AutoTokenizer.from_pretrained(local)
model = AutoModelForSequenceClassification.from_pretrained(local, num_labels=2)
print("加载完成")
```

## 5. 性能调优

> [!important]
> 
> **三个旋钮**：
> 
> - `max_workers=8`：不是越高越好，CDN 同机限速会 429。
> 
> - `etag_timeout`：弱网环境下适当调高到 30ー60。
> 
> - `HF_HUB_ENABLE_HF_TRANSFER=1`：启用 Rust 多线程传输（仅直连 HF）。

## 6. 踩过的坊

> [!important]
> 
> **1) 不加过滤 → 拉 50GB 示例数据集**。甚至拉到重复的 `pytorch_model.bin` + `model.safetensors` (同权重两份)。
> 
> **2)** `**revision="main"**` **不保证 reproducible** —— main 会被作者重推。生产请锁 commit hash。
> 
> **3) 同时** `**cache_dir**` **与** `**local_dir**` —— SDK 会先拉到 cache，再拷入 local_dir，磁盘×2。仅需其中一个。
