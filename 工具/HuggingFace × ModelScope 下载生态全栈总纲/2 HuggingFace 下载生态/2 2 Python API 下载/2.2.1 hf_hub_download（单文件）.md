## 0. 定位

> 一句话：`hf_hub_download` 是**最细粒度的单文件下载函数**。它是 `snapshot_download` 的基石，也是「只要拉一个 tokenizer.json」这类场景的首选。

## 1. 函数签名

```python
hf_hub_download(
    repo_id: str,            # "owner/name"
    filename: str,           # 仓库内相对路径，如 "config.json" 或 "vocab/zh.txt"
    subfolder: str | None,   # 可选，在 repo 内的子目录
    repo_type: str = "model",# model / dataset / space
    revision: str = "main",  # branch / tag / commit hash
    cache_dir: str | None,   # 默认 ~/.cache/huggingface/hub
    local_dir: str | None,   # 拷贝真文件到该目录
    token: str | bool | None,
    force_download: bool = False,
    resume_download: bool = True,
) -> str:                    # 返回本地绝对路径
```

## 2. 最小示例

```python
# single_file.py —— 拉单个文件与查看下载到哪里
from huggingface_hub import hf_hub_download

# (1) 拉 tokenizer.json。默认会入三件套缓存 (blobs / snapshots / refs)
path = hf_hub_download(
    repo_id="Qwen/Qwen2.5-0.5B-Instruct",
    filename="tokenizer.json",
)
print("文件路径 =", path)
# 会是似于：~/.cache/huggingface/hub/models--Qwen--Qwen2.5-0.5B-Instruct/snapshots/<c>/tokenizer.json

# (2) 拉某个子目录下的文件
path2 = hf_hub_download(
    repo_id="sentence-transformers/all-MiniLM-L6-v2",
    filename="vocab.txt",
    subfolder="1_Pooling",  # 可选，仓库内路径
)

# (3) 锁定 commit hash，保证完全可复现
path3 = hf_hub_download(
    "Qwen/Qwen2.5-0.5B-Instruct",
    "config.json",
    revision="a8a8a8\u2026",  # 填入实际 commit hash 前几位
)
```

## 3. 是怎么被换名的？

> [!important]
> 
> 底层调用是 `GET /api/{repo_type}s/{repo_id}/resolve/{revision}/{filename}`，HF 服务器返回 302 到 CDN/Xet 上的实质 URL。本地这边用 etag (sha256 前 32 位) 作 blob 名。同一个 etag 发现本地已存在，则跳过下载。

## 4. 断点续与并发

`resume_download=True` 默认启用 HTTP Range 请求。在同一个进程里多线程调同一个 `hf_hub_download` 是安全的，SDK 会在 blobs/ 中写临时 `.<etag>.incomplete` 文件锁。

## 5. 错误处理

```python
from huggingface_hub import hf_hub_download
from huggingface_hub.utils import (
    EntryNotFoundError,
    GatedRepoError,
    RepositoryNotFoundError,
    LocalEntryNotFoundError,
)

try:
    p = hf_hub_download("meta-llama/Llama-3-8B", "config.json")
except GatedRepoError:
    print("该仓库需接受協议，请在网页上点 'Agree and access repository'")
except RepositoryNotFoundError:
    print("仓库不存在或需在鉴权 token")
except EntryNotFoundError as e:
    print("文件名错：", e)
except LocalEntryNotFoundError:
    print("在离线模式下未命中缓存")
```

## 6. 踩过的坊

> [!important]
> 
> **1)** `**filename**` **带** `**/**` **使用癹丝路径**，不用 `subfolder` 也可，但不要二者同时传。
> 
> **2)** `**local_dir**` **会产生「拷贝」而非「软链」**，多次调用同一个文件到不同 `local_dir` 会占多份磁盘。
> 
> 3) `revision` 填 `main` 与填 commit hash 表现不同：前者会频繁检查远端 etag，后者在本地查到即可。
