## 0. 定位

> 一句话：透三个安装渠道 · 三类 extras · 常见坍场，让你在任何环境里一次装对。

## 1. 三个安装渠道

|渠道|适用场景|例句|
|---|---|---|
|**pip**|默认、广谱适用、CI 首选|`pip install -U "huggingface_hub[cli,hf_xet,hf_transfer]"`|
|**conda**|conda 环境与其他编译包 (如 cudatoolkit) 同住|`conda install -c conda-forge huggingface_hub`|
|**uv**|现代 Rust 实现的超快装包器、monorepo lock 场景|`uv pip install -U "huggingface_hub[cli,hf_xet]"`|

## 2. extras 拆解

|extras|拉入包|作用|
|---|---|---|
|`[cli]`|`InquirerPy`|`hf` 交互式 CLI 打印表格与进度条|
|`[hf_xet]`|`hf_xet` (Rust wheel)|启用 Xet CAS 块级去重|
|`[hf_transfer]`|`hf_transfer` (Rust wheel)|多线程 HTTP 加速|
|`[inference]`|aiohttp、Pillow|`InferenceClient` 异步推理|
|`[tensorflow]` / `[torch]`|合适的深度学习依赖|供某些帮助函数使用|

## 3. 一个「项目初始化」脚本

```bash
#!/usr/bin/env bash
# bootstrap_hf_env.sh —— 一键初始化 HF 下载环境
set -e

# 1) 创建独立虚拟环境避免污染全局
python -m venv .venv
source .venv/bin/activate

# 2) 升级 pip、使用中国内镜像加速 pypi
python -m pip install -U pip
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/

# 3) 装下载生态三件套
pip install -U "huggingface_hub[cli,hf_xet,hf_transfer]"

# 4) 验证位于 PATH
which hf && hf --version
python -c "import huggingface_hub, hf_transfer; print(huggingface_hub.__version__, hf_transfer.__version__)"
```

## 4. 踩过的坊

> [!important]
> 
> **1) 仅装** `**hf_transfer**` **但未设 env**—— 装包后不会自动生效，需 `export HF_HUB_ENABLE_HF_TRANSFER=1`。
> 
> **2) Apple Silicon 上装** `**hf_xet**` **报错** —— 某些旧版仅提供心 manylinux。升级 `huggingface_hub>=0.27` 后已有 universal2 wheel。
> 
> **3)** `**pip install --no-deps**` **后 CLI 不能用** —— 缺 `InquirerPy`，重装则需 `[cli]` extras。

## 5. 多版本并存

```bash
# 在同一台机器上点试多版本
pip install "huggingface_hub==0.24.*" -t ./vendor/hf024
pip install "huggingface_hub==0.27.*" -t ./vendor/hf027
# 训练脚本里选择版本
PYTHONPATH=./vendor/hf027 python train.py
```
