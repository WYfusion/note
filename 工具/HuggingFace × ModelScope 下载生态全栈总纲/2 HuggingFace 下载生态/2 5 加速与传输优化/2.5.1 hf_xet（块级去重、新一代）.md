## 0. 定位

> 一句话：`hf_transfer` 是个用 Rust 写的传输后端，能把 HF 高带宽机器从 **80MB/s** 拉到 **2GB/s**。本页讲原理、启动、限制。

## 1. 启动三步

```bash
# 1) 装
pip install -U hf_transfer        # 或拼入 huggingface_hub[hf_transfer]

# 2) 启用 env
export HF_HUB_ENABLE_HF_TRANSFER=1

# 3) 验证装上的是 Rust wheel
python -c "import hf_transfer; print(hf_transfer.__file__)"
# .../site-packages/hf_transfer/hf_transfer…so
```

## 2. 为什么会快

> [!important]
> 
> - **Python** `**requests**` **是单线程、GIL 锁动**，很难跨越 200MB/s。
> 
> - `hf_transfer` 用 `tokio` 在 Rust 里多线程同时拉多个 HTTP Range，并使用内存映射写盘。
> 
> - 在同一个文件上拉 8 个 Range 並并拼接，能接近机器网卡上限。

## 3. 启与不启的性能对比

示例场景：Qwen2.5-0.5B (~1GB)、机器位于 AWS us-east-1、100Gbps。

|场景|耗时|实际速率|
|---|---|---|
|默认 requests|≊ 12s|≊ 85 MB/s|
|HF_HUB_ENABLE_HF_TRANSFER=1|≊ 0.6s|≊ 1.7 GB/s|

```python
# bench.py —— 自己跑个对照
import os, time, shutil
from huggingface_hub import snapshot_download

REPO = "Qwen/Qwen2.5-0.5B-Instruct"

def run(label, env_value):
    os.environ["HF_HUB_ENABLE_HF_TRANSFER"] = env_value
    target = f"./bench_{label}"
    shutil.rmtree(target, ignore_errors=True)
    t = time.time()
    snapshot_download(
        REPO,
        local_dir=target,
        allow_patterns=["*.safetensors", "*.json", "tokenizer*"],
    )
    print(f"{label}: {time.time()-t:.1f}s")

# 注意：调 snapshot_download 之前设 env
run("plain", "0")
run("transfer", "1")
```

## 4. 快反不是越快越好

> [!important]
> 
> - **走镜像时不建议启用 hf_transfer**。镜像服务器 (如 hf-mirror) 不一定支持多连接、可能会 429。需在镜像文档里查。
> 
> - **家庭带宽 <100Mbps 场景下提升不明显**。到底是带宽限、不是 Python 限。
> 
> - **出错后错误信息会较付** — `RuntimeError: ...rust panic`，难以从 Python 栈定位。调试时先闭。

## 5. 状态检查脚本

```python
# probe_transfer.py
import os, importlib

print("env =", os.getenv("HF_HUB_ENABLE_HF_TRANSFER"))
try:
    mod = importlib.import_module("hf_transfer")
    print("装上的 =", mod.__version__)
except ImportError:
    print("未装 hf_transfer, 请 pip install hf_transfer")
```

## 6. 踩过的坊

- **「装了但没启」**——只装包不设 env 会默认走默认 requests。必设 env。

- **「启了但报 Rust 动态库问题」**—— 多为 Linux glibc 版本过低。升级到 Ubuntu 22.04 或最近。

- **「在 docker 里不生效」**—— 检查是否在 `ENTRYPOINT` 之后设了 env，或是否被 `Dockerfile` 仅在 build 阶段设了。
