## 0. 定位

> 一句话：`max_workers` `concurrent_chunks` `etag_timeout` 是 Python API 面上「可越调越快」的三个旋钮，但**需意识到 CDN 限速**。

## 1. 三个参数职责

|参数|位于|默认|作用|
|---|---|---|---|
|`max_workers`|`snapshot_download`|8|**多个文件**同时拉的线程数|
|`HF_HUB_DOWNLOAD_TIMEOUT`|env|10s|单个 HTTP 超时|
|`etag_timeout`|`snapshot_download`|10s|检查远端 etag 超时|
|`HF_HUB_ENABLE_HF_TRANSFER`|env|0|**单个文件**内多 Range|

> [!important]
> 
> 两类并发是互補的：
> 
> - `max_workers=N` 控制**跨文件并发**，适合许多小文件 (tokenizer.json + config.json + 多分片权重)。
> 
> - `hf_transfer` 控制**单文件上多 Range**，适合少量超大文件 (几 GB 的 safetensors)。
> 
> - 二者能麱郁。

## 2. 调优着手点

```python
# tuning.py —— 不同场景下的推荐参数
import os
from huggingface_hub import snapshot_download

# 场景 A: 机器在 AWS、直连 HF、带宽 10Gbps
os.environ["HF_HUB_ENABLE_HF_TRANSFER"] = "1"
snapshot_download(
    "meta-llama/Meta-Llama-3-8B",
    max_workers=4,        # 文件不多、重点是单文件加速
)

# 场景 B: 走镜像 hf-mirror、家庭带宽 200Mbps
os.environ["HF_HUB_ENABLE_HF_TRANSFER"] = "0"    # 镜像常不支持多 Range
os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"
os.environ["HF_HUB_DOWNLOAD_TIMEOUT"] = "30"     # 弱网提高超时
snapshot_download(
    "Qwen/Qwen2.5-0.5B-Instruct",
    max_workers=16,        # 靠多文件并发凑带宽
    etag_timeout=30,
)

# 场景 C: CI、只要趋于稳
os.environ["HF_HUB_DOWNLOAD_TIMEOUT"] = "60"
snapshot_download(
    "google/gemma-3-1b-it",
    max_workers=2,         # 陕 429
)
```

## 3. 测量脚本

```python
# tune_search.py —— 扫描不同 max_workers 下的实际速率
import os, time, shutil, statistics
from huggingface_hub import snapshot_download

REPO = "Qwen/Qwen2.5-0.5B-Instruct"
PATTERNS = ["*.safetensors", "*.json", "tokenizer*"]

def bench(workers, transfer):
    os.environ["HF_HUB_ENABLE_HF_TRANSFER"] = str(transfer)
    target = f"./_bench/w{workers}_t{transfer}"
    shutil.rmtree(target, ignore_errors=True)
    t0 = time.time()
    snapshot_download(REPO, local_dir=target, allow_patterns=PATTERNS,
                      max_workers=workers)
    return time.time() - t0

for w in [1, 2, 4, 8, 16]:
    for t in [0, 1]:
        durs = [bench(w, t) for _ in range(3)]
        med = statistics.median(durs)
        print(f"workers={w:>2} transfer={t}  median={med:.2f}s")
```

示例输出 (AWS us-east-1, 10Gbps)：

```jsx
workers= 1 transfer=0  median=11.4s
workers= 1 transfer=1  median=0.8s
workers= 4 transfer=0  median=3.2s
workers= 4 transfer=1  median=0.7s
workers= 8 transfer=0  median=2.1s
workers=16 transfer=0  median=1.9s     # 达到线速上限、进一步加不动
```

## 4. 不是越高越好的信号

> [!important]
> 
> **出现以下任一现象就取指限低并发**：
> 
> - 报 `HTTP 429 Too Many Requests`
> 
> - 报 `ConnectionResetError` / `RemoteDisconnected`
> 
> - CPU 95% 但网卡 < 20%
> 
> - 多个 Range 下载后默认 hash 校验失败

## 5. 推荐默认参数表

|场景|workers|HF_TRANSFER|timeout|
|---|---|---|---|
|个人机 / 走镜像|8|0|30s|
|云机器 / 直连 HF|4|1|10s|
|CI (GitHub Actions)|4|0|60s|
|同机多 Pod 拉|2|0|60s|
