## 0. 定位

> 一句话：「可复现」意思是「同一份训练脚本 + 同一份锁文件下 → 拉到同一重权重 / 同一份数据」。本页讲三种锁手段。

## 1. 锁 commit hash 是最强锁

```python
# pin_commit.py —— 生产脚本推荐写法
from huggingface_hub import HfApi, snapshot_download

REPO = "Qwen/Qwen2.5-0.5B-Instruct"
PIN = "7f6b3fc1234567890abcdef"     # 锁 commit hash

local = snapshot_download(REPO, revision=PIN)
print("路径 =", local)
# 多机器多时候拉、都能拉到同一份
```

查询可锁的 hash：

```bash
# 查看仓库最近 commits
hf repo refs Qwen/Qwen2.5-0.5B-Instruct
# 或用 API
curl -s https://huggingface.co/api/models/Qwen/Qwen2.5-0.5B-Instruct | jq '.sha'
```

## 2. 锁所有文件哈希

```python
# lockfile_gen.py —— 产出一份文件级 lockfile
import hashlib, json
from pathlib import Path
from huggingface_hub import HfApi, snapshot_download

REPO = "Qwen/Qwen2.5-0.5B-Instruct"
local = Path(snapshot_download(REPO, local_dir="./pinned"))

lock = {"repo": REPO, "files": {}}
for p in sorted(local.rglob("*")):
    if p.is_file():
        h = hashlib.sha256(p.read_bytes()).hexdigest()
        lock["files"][str(p.relative_to(local))] = h

Path("hf.lock.json").write_text(json.dumps(lock, indent=2))
print("写出 hf.lock.json")
```

```python
# lockfile_verify.py —— 出产机上验证不被篡改
import hashlib, json
from pathlib import Path

lock = json.loads(Path("hf.lock.json").read_text())
base = Path("./pinned")
for rel, want in lock["files"].items():
    got = hashlib.sha256((base / rel).read_bytes()).hexdigest()
    assert got == want, f"不一致：{rel}"
print("✅ 哈希全检查通过")
```

## 3. 锁依赖版本

```toml
# pyproject.toml
[project]
dependencies = [
    "huggingface_hub==0.27.1",
    "transformers==4.46.0",
    "datasets==3.1.0",
    "safetensors==0.4.5",
]
```

不锁 SDK 版本会造成「同一重权重、但被不同版 SDK 读为不同结果」。例如 tokenizer 本身是同一份、但 0.13 与 0.15 版 tokenizers 包对 BPE 处理会有置同。

## 5. 三锁拼接决策表

|必选|场景|
|---|---|
|commit hash|**任何严肃场景**|
|SDK 版本|**任何严肃场景**|
|文件 hash|有外部篡改风险时 + 金融/医疗场景|

## 6. 踩过的坊

> [!important]
> 
> **1)** `**revision="main"**` **不锁** — 作者可重推 main。请锁 commit hash。
> 
> **2)** `**latest**` **tag 也会被重指** — 只有 commit hash 是不可变的。
> 
> **3) 作者删除仓库后 commit hash 也拉不到** — 生产需同步一份到内部 S3 / Artifactory。
