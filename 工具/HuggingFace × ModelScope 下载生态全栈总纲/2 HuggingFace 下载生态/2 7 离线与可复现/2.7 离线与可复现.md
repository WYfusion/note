## 0. 定位

> 一句话：本页讲「一旦文件拉完、后续 CI / 内网集群不受网络影响」的两个关键能力：**离线模式**、**预热缓存**。

## 1. 离线模式两详环境变量

|环境变量|语义|作用范围|
|---|---|---|
|`HF_HUB_OFFLINE=1`|SDK 任何网络调用会抛 `LocalEntryNotFoundError`|SDK 全局|
|`TRANSFORMERS_OFFLINE=1`|`from_pretrained` 仅读缓存，不调网络检查 etag|`transformers` 局部|
|`local_files_only=True`|`from_pretrained` 函数参数，与上同作用|单次调用|

> [!important]
> 
> **三者区别**：`HF_HUB_OFFLINE` 是**底层 SDK 总开关**；`TRANSFORMERS_OFFLINE` 是`**transformers**` **专用的简化版**；`local_files_only` 是**函数参数粒度**。生产一般同时设前两个 env。

## 2. 预热脚本模板

```python
# prewarm.py —— CI / 镜像构建阶段跱所有训练会用的仓库
import os
from huggingface_hub import snapshot_download

REPOS = [
    ("Qwen/Qwen2.5-0.5B-Instruct", "model"),
    ("sentence-transformers/all-MiniLM-L6-v2", "model"),
    ("HuggingFaceH4/MATH-500", "dataset"),
]
CACHE = os.getenv("HF_HOME", "/data/hf-cache")
os.environ["HF_HOME"] = CACHE

for repo_id, repo_type in REPOS:
    print(f"warming {repo_id} ({repo_type}) ...")
    snapshot_download(repo_id=repo_id, repo_type=repo_type, cache_dir=CACHE)
print("prewarm done. cache size:")
os.system(f"du -sh {CACHE}")
```

## 3. 集群零网络启动

```bash
# 训练节点上
export HF_HOME=/shared/hf-cache         # NFS 挂载点
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
python train.py                          # 仅从 /shared/hf-cache 读
```

## 4. 常见坍场

> [!important]
> 
> **「明明下了但 OFFLINE 报不存在」** —— 90% 是「合适的 `HF_HOME` 未随转」。`HF_HOME` 默认 `~/.cache/huggingface`，跳机或换用户后需重新指。
