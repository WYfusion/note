## 0. 定位

> 一句话：`HF_HUB_OFFLINE=1` 是「不报错会走本地缓存」的开关。与 `local_files_only=True` 是双重保险、公用。

## 1. 三种「离线」设法

|位置|作法|生效粒度|
|---|---|---|
|env|`HF_HUB_OFFLINE=1`|全进程|
|env (老)|`TRANSFORMERS_OFFLINE=1`|仅 transformers|
|Python 参数|`local_files_only=True`|单次调用|

## 2. 最小可跑路径

```bash
# 1) 在能联网的机器上拉权重存入缓存
hf download Qwen/Qwen2.5-0.5B-Instruct

# 2) 拷贝整个 $HF_HOME 到离线机器
rsync -av ~/.cache/huggingface/ offline-machine:~/.cache/huggingface/

# 3) 离线机器上启用离线模式export HF_HUB_OFFLINE=1
```

## 3. Python 离线加载

```python
# offline_load.py —— 不联网也能加载模型
import os
# 必须在 import 之前设
os.environ["HF_HUB_OFFLINE"] = "1"

from transformers import AutoModelForCausalLM, AutoTokenizer

# (1) 隐式走缓存
model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen2.5-0.5B-Instruct",
    # local_files_only=True   # 与 env 二选一即可
)
tok = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-0.5B-Instruct")
print("加载 OK")

# (2) 明练出缓存路径后加载——推荐生产用法
from huggingface_hub import snapshot_download
local = snapshot_download("Qwen/Qwen2.5-0.5B-Instruct", local_files_only=True)
print("在", local)
```

## 4. 报错说明与恢复

```python
# error_offline.py —— 未命中缓存时的典型报错
import os
os.environ["HF_HUB_OFFLINE"] = "1"

from huggingface_hub import snapshot_download
from huggingface_hub.utils import LocalEntryNotFoundError

try:
    snapshot_download("openai-community/gpt2")   # 不在缓存里
except LocalEntryNotFoundError as e:
    print("未命中缓存\n", e)
    # 提示：当前缓存下未查到 commit
```

恢复调试：临时取消离线模式、补拉该仓、重启。

## 5. 训练节点场景

```bash
# k8s job: 默认集群里不出公网、走 PVC 挂载的 hub
spec:
  containers:
    - name: trainer
      env:
        - name: HF_HUB_OFFLINE
          value: "1"
        - name: HF_HOME
          value: /mnt/hf_cache
      volumeMounts:
        - name: hub-cache
          mountPath: /mnt/hf_cache
  volumes:
    - name: hub-cache
      persistentVolumeClaim:
        claimName: hf-hub-shared
```

## 6. 与「跨机器同步」结合

```bash
# 在联网机器 (puller)
hf download Qwen/Qwen2.5-0.5B-Instruct
hf download Qwen/Qwen2.5-1.5B-Instruct

# 打包镜像拷贝 (rsync 会保留硬连接)
rsync -avhH --info=progress2 ~/.cache/huggingface/ /mnt/usb/hf_cache/

# 在离线机器上创造 (loader)
rsync -avhH --info=progress2 /mnt/usb/hf_cache/ ~/.cache/huggingface/
export HF_HUB_OFFLINE=1
```

## 7. 踩过的坊

> [!important]
> 
> **1)** `**HF_HUB_OFFLINE=1**` **但仍联网查 etag** — 是老版本。升级 huggingface_hub≥0.20。
> 
> **2)** `**rsync**` **不加** `**-H**` **拷贝后占多三倍** — hub 里用了硬连接，需 `-H` 保留。
> 
> **3) 跨主机拷后 revision 指针丢失** — 需同时拷 `refs/` `snapshots/` `blobs/` 三个子目录。
