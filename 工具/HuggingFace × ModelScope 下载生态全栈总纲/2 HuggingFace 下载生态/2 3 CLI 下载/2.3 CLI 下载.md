## 0. 定位

> 一句话：`hf` 是 `huggingface_hub >= 0.26` 推出的新 CLI，**子命令更清晰、默认不进软链接坑**。老版 `huggingface-cli` 仍可用，但推荐统一语义。

## 1. CLI 子命令一览

|新版 `hf`|老版 `huggingface-cli`|用途|
|---|---|---|
|`hf download`|`huggingface-cli download`|下载 repo / 文件|
|`hf upload`|`huggingface-cli upload`|上传|
|`hf auth login/logout/whoami`|`huggingface-cli login/logout/whoami`|认证|
|`hf cache scan/delete`|`huggingface-cli scan-cache/delete-cache`|缓存管理|
|`hf jobs`|无|运行 HF Inference Job|

## 2. 最常用三条

```bash
# (1) 拉整仓 + 过滤 .safetensors / .json
hf download Qwen/Qwen2.5-0.5B-Instruct \
  --include "*.safetensors" "*.json" "tokenizer.*" \
  --local-dir ./qwen --local-dir-use-symlinks False

# (2) 拉单文件
hf download Qwen/Qwen2.5-0.5B-Instruct config.json

# (3) 拉 dataset仓库
hf download HuggingFaceH4/MATH-500 --repo-type dataset --local-dir ./math500
```

## 3. 参数漂移完全手册

> [!important]
> 
> **老版变新版勿口误**：
> 
> - `--local-dir-use-symlinks` 默认变 `False`（新版）。
> 
> - `--include / --exclude` 取代 `--allow-patterns / --ignore-patterns`。
> 
> - `--token <T>` 仍可用，但会在 history 里留下明文，推荐 `HF_TOKEN` env。

## 4. 与Shell 组合示例

```bash
# 批量拉多个仓库到同一个外存。需 GNU parallel 或 xargs
cat repos.txt | xargs -I{} -P 4 hf download {} --local-dir /data/hf/{}/
```
