## 0. 定位

> 一句话：三种 HF 环境变量变身法，设错会「看似什么都是」但人谁都不郁问。

## 1. 三种作用域

|作用域|作法|适用|
|---|---|---|
|当前 shell|`export HF_TOKEN=...`|临时调试|
|当前用户|写 `~/.bashrc` / `~/.zshrc` / PowerShell `$PROFILE`|个人机默认|
|进程内设|`os.environ["HF_TOKEN"] = ...`|需在 `import` 前|

## 2. Linux/macOS bash/zsh

```bash
# 临时设 (仅本终端生效)
export HF_TOKEN=hf_xxx
export HF_ENDPOINT=https://hf-mirror.com
export HF_HUB_ENABLE_HF_TRANSFER=1
export HF_HOME=/data/hf_cache         # 重定向缓存根
export HF_HUB_OFFLINE=0

# 永久：追到配置文件
cat >> ~/.bashrc <<'EOF'
export HF_TOKEN=hf_xxx
export HF_ENDPOINT=https://hf-mirror.com
export HF_HUB_ENABLE_HF_TRANSFER=1
export HF_HOME=/data/hf_cache
EOF
source ~/.bashrc

# fish
set -Ux HF_TOKEN hf_xxx
set -Ux HF_ENDPOINT https://hf-mirror.com
```

## 3. Windows PowerShell

```powershell
# 临时 (仅本会话)
$env:HF_TOKEN = "hf_xxx"
$env:HF_ENDPOINT = "https://hf-mirror.com"
$env:HF_HUB_ENABLE_HF_TRANSFER = "1"
$env:HF_HOME = "D:\hf_cache"

# 永久：当前用户级别
[System.Environment]::SetEnvironmentVariable("HF_TOKEN", "hf_xxx", "User")
[System.Environment]::SetEnvironmentVariable("HF_ENDPOINT", "https://hf-mirror.com", "User")
[System.Environment]::SetEnvironmentVariable("HF_HUB_ENABLE_HF_TRANSFER", "1", "User")
[System.Environment]::SetEnvironmentVariable("HF_HOME", "D:\hf_cache", "User")

# 检查
Get-ChildItem Env: | Where-Object Name -like "HF_*"
```

## 4. Windows CMD

```bash
:: 临时
set HF_TOKEN=hf_xxx
set HF_ENDPOINT=https://hf-mirror.com

:: 永久 (需重启终端)
setx HF_TOKEN hf_xxx
setx HF_ENDPOINT https://hf-mirror.com
```

## 5. Python 进程内设的重要细节

```python
# good_env.py —— 「读环境变量是在 import 时」这个事实特别重要
import os

# ✅ 正确：在调 huggingface_hub 之前设
os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"
os.environ["HF_HUB_ENABLE_HF_TRANSFER"] = "1"

from huggingface_hub import snapshot_download
snapshot_download("Qwen/Qwen2.5-0.5B-Instruct")
```

```python
# bad_env.py —— 错误示范
from huggingface_hub import snapshot_download   # 会读一次 env、那时还是默认 endpoint

import os
os.environ["HF_ENDPOINT"] = "https://hf-mirror.com"   # 太晚了，下面调不生效
snapshot_download("Qwen/Qwen2.5-0.5B-Instruct")
```

## 6. 全列表常用变量

|变量|默认值|作用|
|---|---|---|
|`HF_TOKEN`|空|鉴权令牌|
|`HF_ENDPOINT`|`https://huggingface.co`|镜像/主服务器|
|`HF_HOME`|`~/.cache/huggingface`|缓存与配置根|
|`HF_HUB_CACHE`|`$HF_HOME/hub`|仅指 hub 下载缓存|
|`HF_HUB_OFFLINE`|`0`|1 则走本地缓存不联网|
|`HF_HUB_ENABLE_HF_TRANSFER`|`0`|1 启用 Rust 加速|
|`HF_HUB_DISABLE_PROGRESS_BARS`|`0`|CI 里干净输出|
|`HF_HUB_VERBOSITY`|`warning`|`debug` / `info` / `warning` / `error`|
|`HF_HUB_DOWNLOAD_TIMEOUT`|`10`|弱网调高|

## 7. 踩过的坊

> [!important]
> 
> **1)** `**HF_HOME**` **与** `**HF_HUB_CACHE**` **设不一致** —— `HF_HOME` 默认生成「$HF_HOME/hub」，不要在 `HF_HOME` 上设 `/hub` 后缀。
> 
> **2) IDE 里读不到** —— VS Code、PyCharm 启动时未加载 shell rc。推荐记于 `~/.config/environment.d/` 或在项目下放 `.env` + `python-dotenv`。
> 
> **3) Windows** `**setx**` **后本终端看不到** —— `setx` 仅对后续新终端生效。需重开窗。
