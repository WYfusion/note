## 0. 定位

> 一句话：`hf download` 是 `huggingface_hub>=0.27` 后取代 `huggingface-cli download` 的默认 CLI，等价于 `snapshot_download` 的命令行外壳。

## 1. 命令语法

```bash
hf download [<repo_id>] [<filename>...] \
    --repo-type {model,dataset,space} \
    --revision <branch|tag|commit> \
    --include <glob>... \
    --exclude <glob>... \
    --local-dir <path> \
    --cache-dir <path> \
    --token <hf_xxx | $HF_TOKEN> \
    --max-workers <int> \
    --quiet
```

## 2. 上面该怎么读

|参数|说明|
|---|---|
|`repo_id`|必填。例 `Qwen/Qwen2.5-0.5B-Instruct`|
|「位置参数」`<filename>...`|可选。只拉这些文件，与 `--include` 互排|
|`--repo-type`|默认 `model`，拉数据集需 `dataset`|
|`--local-dir`|拷入该目录，不走缓存软链|
|`--max-workers`|并发线程，默认 8|

## 3. 十条「拷下来能用」示例

```bash
# (1) 拉整仓：默认拷入缓存
hf download Qwen/Qwen2.5-0.5B-Instruct

# (2) 拷真文件到项目录
hf download Qwen/Qwen2.5-0.5B-Instruct --local-dir ./qwen

# (3) 只拉一个文件
hf download Qwen/Qwen2.5-0.5B-Instruct config.json

# (4) 拉多个文件
hf download Qwen/Qwen2.5-0.5B-Instruct config.json tokenizer.json

# (5) 使用 glob 过滤：仅拉 safetensors 与 tokenizer
hf download Qwen/Qwen2.5-0.5B-Instruct \
    --include "*.safetensors" "tokenizer*" "*.json"

# (6) 锁定 commit
hf download Qwen/Qwen2.5-0.5B-Instruct --revision 7f6b3fc

# (7) 拉数据集
hf download HuggingFaceH4/MATH-500 --repo-type dataset --local-dir ./math500

# (8) 拉 Space
hf download stabilityai/stable-diffusion --repo-type space

# (9) 指定 token与并发
hf download meta-llama/Meta-Llama-3-8B --token $HF_TOKEN --max-workers 16

# (10) 走镜像 + hf_transfer
HF_ENDPOINT=https://hf-mirror.com HF_HUB_ENABLE_HF_TRANSFER=1 \
    hf download Qwen/Qwen2.5-0.5B-Instruct
```

## 4. 与 Python API 的 1:1 对应

```python
# Python 等价写法
from huggingface_hub import snapshot_download
snapshot_download(
    "Qwen/Qwen2.5-0.5B-Instruct",
    local_dir="./qwen",
    allow_patterns=["*.safetensors", "tokenizer*", "*.json"],
    max_workers=16,
)
```

三个变量与参数名有点不同：

|CLI|Python|
|---|---|
|`--include`|`allow_patterns`|
|`--exclude`|`ignore_patterns`|
|`--local-dir`|`local_dir`|

## 5. shell 集成贴士

```bash
#!/usr/bin/env bash
# fetch_models.sh —— 批量拉一组模型
set -e
MODELS=(
    "Qwen/Qwen2.5-0.5B-Instruct"
    "Qwen/Qwen2.5-1.5B-Instruct"
    "google/gemma-3-1b-it"
)
ROOT="$HOME/models"

for m in "${MODELS[@]}"; do
    safe=$(echo "$m" | tr '/' '_')
    echo ">>> 拉 $m"
    hf download "$m" \
        --include "*.safetensors" "tokenizer*" "*.json" \
        --local-dir "$ROOT/$safe"
done
```

## 6. 踩过的坊

> [!important]
> 
> **1) 旧命令** `**huggingface-cli download**` **还能用但会提醒废弃**。生产请全部改为 `hf download`。
> 
> **2)** `**--include "*.safetensors"**` **在 zsh 里会被全局拓展** —— 加双引号避免 shell 拓展。
> 
> **3)** `**--quiet**` **不会隐藏错误只会隐藏进度条** —— CI 里安全使用。
