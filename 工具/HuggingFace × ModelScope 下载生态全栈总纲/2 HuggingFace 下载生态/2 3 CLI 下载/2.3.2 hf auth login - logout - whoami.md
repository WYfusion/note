## 0. 定位

> 一句话：`hf auth` / `hf repo` / `hf upload` 是「你不常用但报错时才发现不会」的三个什么都会的子命令集。

## 1. `hf auth` 家族

```bash
# 登录 (交互式输入 token)
hf auth login

# 登录 (从 env 读)
hf auth login --token $HF_TOKEN --add-to-git-credential

# 查当前身份
hf auth whoami

# 登出
hf auth logout

# 多账号切换 (>=0.27)
hf auth switch
```

> [!important]
> 
> `--add-to-git-credential` 会把 token 写进「仓库 git credential helper」，`git push` 时后台鉰步。适合需上传模型的开发机。

## 2. `hf repo` 家族

```bash
# 创建仓库
hf repo create my-org/my-model --type model --private

# 创建数据集仓库
hf repo create my-org/my-dataset --type dataset

# 看元信息
hf repo info Qwen/Qwen2.5-0.5B-Instruct

# 查看某个仓库所有 commit
hf repo refs Qwen/Qwen2.5-0.5B-Instruct

# 列举所有 branch 与 tag
hf repo tag list Qwen/Qwen2.5-0.5B-Instruct
```

## 3. `hf upload` 家族

```bash
# 上传单个文件
hf upload my-org/my-model ./out/config.json config.json

# 上传整个目录到仓库根
hf upload my-org/my-model ./out/

# 上传到某个子路径
hf upload my-org/my-model ./tokenizer.json tokenizer/tokenizer.json

# 上传到分支
hf upload my-org/my-model ./out --revision dev --create-pr

# 贴必要的 commit message
hf upload my-org/my-model ./out --commit-message "add v0.2 weights"
```

## 4. 辅助子命令

```bash
# 查看下载缓存
hf cache scan

# 删除某个 revision 的缓存
hf cache delete --revision-hash <hash>

# 互交式管理缓存 (需 InquirerPy)
hf cache delete

# 查看环境变量
hf env
```

`hf env` 会输出当前 SDK 看到的所有环境与参数，是**排查网络/缓存问题的首选取调命令**：

```jsx
- huggingface_hub version: 0.27.0
- HF_HUB_CACHE: /home/sion/.cache/huggingface/hub
- HF_ASSETS_CACHE: /home/sion/.cache/huggingface/assets
- HF_TOKEN_PATH: /home/sion/.cache/huggingface/token
- HF_HUB_OFFLINE: 0
- HF_HUB_DISABLE_TELEMETRY: 0
- HF_HUB_ENABLE_HF_TRANSFER: 1
```

## 5. 脚本化 CI 示例

```yaml
# .github/workflows/release.yml
name: release-model
on: [workflow_dispatch]
jobs:
  upload:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: pip install -U "huggingface_hub[cli]"
      - run: hf auth login --token $ secrets.HF_TOKEN  --add-to-git-credential
      - run: hf upload my-org/my-model ./out --commit-message "CI release $GITHUB_SHA"
```

## 6. 踩过的坊

> [!important]
> 
> **1)** `**hf upload**` **后怎么「看不到」**—— 记得加 `--repo-type dataset` 或在网页上点「Files and versions」。
> 
> **2)** `**hf repo create --private**` **后在别人查读全都 404**。请在设置里调为 `public` 或加协作者。
> 
> **3)** `**--add-to-git-credential**` **在多用户机不推荐**，token 会被其他用户读到。
